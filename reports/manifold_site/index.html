怎么读

H(θ,p) = p²/2 + k(1−cos(θ−θ_eq))，k = 1（单位：rad, rad/s, I = 1 kg·m² 归一）
灰细线 = 等能线（不同能量的自然轨道）；青虚线 = 分界线 E = 2k（谷内摆动 / 越顶旋转的分界）；
绿带 = θ 容差 ±1°；橙圈 = 当前相点。
电机做功 ⇒ 相点能量变化 ⇒ 轨迹会在等能线之间横穿（正是「强跨相位线」）。臂静止时相点停在势阱谷底，p≈0。

通道怎么算（每次刷新现算，不取缓存）

z = [ e_pose/tol ; e_vel/vlim ]          无量纲偏离，V=1 正好压在公差上
V = ½‖z‖²                               势能（通道内的"高度"）
τ = −α · τ_lim ⊙ (z_pos + z_vel)        修正：度规定方向，τ_lim 定幅度
α_eff = min(α, λ/2)   ⇒  V̇ ≤ −λV        李雅普诺夫：能量单调下降
