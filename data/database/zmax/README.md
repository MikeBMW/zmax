# Z-MAX 具身智能机器人平台 · 工程数据手册

本文件是 Z-MAX 平台工程数据包（`data/database/zmax/`）的产品说明与使用手册，面向平台集成方、产线工程方与二次开发方。

---

## 1. 产品概述

**Z-MAX 具身智能机器人平台**面向光模块及精密电子制造场景，提供从视觉感知、精密对位到力控插拔的全链路自主作业能力。平台采用三子系统解耦架构，各子系统可独立升级、独立标定、独立诊断，并以统一工程数据包交付，实现"看到—定位—插入"全流程闭环。

### 1.1 产品矩阵

| 型号 | 产品名称 | 适用场景 | 关键指标 |
|---|---|---|---|
| **Z700** | 精细操作机器人 | 光模块、精密件的抓取—对位—插拔作业；精细力控与宏微复合，面向 100G/400G 光模块产线 | 插入成功率 ≥ 99%；头到孔底偏差 < 4 mm |
| **Z100** | 通用操作机器人 | 跨工位通用上下料、流转与抓放；移动即工位，一台上装适配多工序，面向柔性产线与多品种小批量 | 抓取成功率 ≥ 97%；工位流转成功率 ≥ 97% |

### 1.2 核心能力

| 能力项 | 技术指标 |
|---|---|
| 精细对位（头—孔亚毫米对位） | 对位残差 ≤ 0.5 mm |
| 宏微复合作业 | 末端重复性 ≤ 0.05 mm |
| 力控插拔保护 | 插拔力上限可配置，超限即退 |
| L4 专家自主（世界模型预判与恢复） | 稳态推理 101 ms，冷启动 6.7 s（常驻模式） |
| 工位精准对接 | 对接精度 ± 10 mm |
| 举升高度调节 | 0–800 mm，覆盖多层工位 |
| 双形态作业（固定 / 移动） | 切换时间 < 30 s |
| 场景理解与任务拆解 | 视觉语言模型驱动，支持自然语言与工单输入 |
| 视触觉质量检测 | 外观缺陷检出率按 AOI 口径执行 |
| 标定与主参数 M 现场可配 | 写入幂等、范围校验、回读确认 |
| 安全与急停（平台级） | 急停、力阈值、关节限位、光幕多层防护，任务不可覆盖 |
| 边学边练（数据闭环自升级） | 采集—训练—部署闭环可无人值守运行 |

## 2. 系统架构

平台由三个执行子系统与一个跨层支撑域构成，各子系统功能由**配置（CFG）、标定（CAL）、诊断（DIA）**三轴完整定义。

| 子系统 | 层级 | 职责 |
|---|---|---|
| **System 2 认知决策** | L4 / L5 | 云端智能体、任务拆解与调度；世界模型预判与恢复；记忆筹划 |
| **System 1 动作执行** | L3 | 视觉—语言—动作模型（VLA-T）与流式引导（Z-Flow）；长程规划与技能序列编排 |
| **System 0 基石执行** | L2 | 安全层、硬件抽象层（HAL）、EtherCAT 总线、运动学正逆解、原子技能库、分段感知/控制小模型、肌肉记忆 |
| **平台支撑（跨子系统）** | PLAT | 数据源供给、Feature/Test 质量门、观察器与可视化，由平台统一治理 |

架构原则：**上层只给意图与条件，执行由最底层收口**——可行域逐层收窄，稳定性由 L2 安全势函数兜底。

## 3. 工程数据模型：一个文件 = 一套工程

平台的全部结构化工程数据收敛于**单一数据库文件**，控制台（GUI）与工程数据完全解耦：更换数据库即更换整套工程，同名控制台可直接加载，无需改动任何代码。

### 3.1 交付物清单

| 文件 | 说明 |
|---|---|
| `zmax_engineering.db` | **唯一工程数据库**（SQLite 单文件，约 0.9 MB，24 张表）。承载平台、产品、产品特征、子系统、功能、模块、模块代码、能力、接口、验证项、标定参数、状态空间工程七段与关系图 |
| `zmax_space.proj` | **状态空间总工程**（v2 格式，七段）。在控制台「文件 → 打开总工程」中一次加载，集成式回填画布、标定、主参数、任务与面板 |
| `archive/` | 历史工程快照（只读留档，含按版本自动存档与按需导出件） |

### 3.2 数据库规格

数据库共 24 张表，主要数据规模如下（实测）：

| 数据域 | 表 | 规模 |
|---|---|---|
| 平台与产品 | `platform` / `products` / `product_features` | 1 / 2 / 18 |
| 子系统与三轴 | `subsystems` / `subsystem_axes` | 4 / 48 |
| 功能与功能三轴 | `functions` / `fn_axes` | 74 / 1263 |
| 模块与代码定位 | `modules` / `module_code` | 74 / 74 |
| 能力与接口 | `capability_dbc` / `interfaces` | 31 / 62 |
| 验证与诊断项 | `verification_features` | 57 |
| 标定参数 | `calib_params` | 41 |
| 状态空间工程 | `projects` / `project_sections` | 1 / 27 |
| 工程画布 | `canvas_nodes` / `canvas_links` | 74 / 184 |
| 参数中心 | `params` / `param_links` | 162 / 375 |
| 测量—标定—诊断（MCD） | `mcd` | 5 |
| 运行事件 | `param_events` | 运行时写入 |

工程画布真源为 89 节点、184 连线，其中功能区节点 74 个（其余为行带背景）。

### 3.3 状态空间总工程（七段）

`zmax_space.proj` 采用 `zmax.statespace.project/2` 格式，包含以下段落：

| 段 | 内容 |
|---|---|
| `canvas` | 状态空间画布（节点、连线、层级结构） |
| `calibration` | 站点标定与流形标定 |
| `master_param` | 主参数 M、等效惯量等结构参数 |
| `measure` | 测量量清单 |
| `tasks` | 任务配置与任务 × 画布节点绑定 |
| `panel` | 控制台面板与运行开关状态 |
| `meta` | 版本、时间戳、真源指纹（指纹用于漂移检测） |

配套任务配置覆盖五类标准作业：FW Loading 与 EEPROM 校验、料盘/治具上下料搬运、BI 老化箱模块插拔、柜体电口+光口插拔、线外检测插接（ATS）。

### 3.4 真源与生成物关系

工程数据库为**生成物**，其真源为可人工编辑并纳入版本管理的文本文件；修改真源后重建数据库，判据全绿方视为同步。

```
config/platform/zmax_platform.json     平台 / 产品 / 产品特征 / 子系统三轴定义
config/calib/*.json                    标定真源与主参数
feature.dbc                            能力数据库（能力条目与输入输出接口）
config/platform/param_spec.json        可改参数注册表
flows/state_space_obs.json             状态空间画布真源
src/.../verification_layer.py          诊断项断言真源
src/.../nodes/library.py               模块 ↔ 代码文件与行号映射
config/library_curation.json           模块库删改名单
```

## 4. 数据接口

数据库提供只读 JSON 服务，供控制台、外部系统与二次开发方消费。服务默认监听本机 8798 端口。

| 端点 | 返回内容 |
|---|---|
| `/summary` | 全库规模概览 |
| `/platform` | 平台定义 |
| `/products`、`/product/<id>` | 产品清单与单品详情 |
| `/systems`、`/system/<id>` | 子系统清单与详情 |
| `/functions`、`/function/<id>` | 功能清单与详情 |
| `/modules` | 模块与代码定位 |
| `/capabilities` | 能力数据库条目 |
| `/calib` | 标定参数 |
| `/project`、`/project/<section>` | 状态空间工程及分段内容 |
| `/graph` | 关系图（功能—模块—系统） |
| `/sync` | 库与真源一致性状态 |

调用示例：

```bash
curl -s 127.0.0.1:8798/summary
curl -s 127.0.0.1:8798/product/Z700
curl -s 127.0.0.1:8798/function/<id>
```

## 5. 部署与运维

### 5.1 运行环境

- 数据库引擎：SQLite（进程内嵌入式，**无需安装数据库服务器**），随 Python 标准库提供；
- 运行时依赖：Python 3.11 及以上，无第三方数据库驱动要求；
- 单库文件可直接复制、备份、迁移。

### 5.2 常用操作

```bash
# 由真源重建工程数据库
python3 tools/engineering_db.py build

# 一致性体检（特征—子系统、功能—模块、三轴覆盖、工程段完整性、库与真源一致）
python3 tools/engineering_db.py check

# 查询
python3 tools/engineering_db.py query "product Z700"
python3 tools/engineering_db.py query "system sys2"
python3 tools/engineering_db.py stats

# 启动只读数据服务
python3 tools/engineering_db.py serve --port 8798

# 迁移：将整套工程复制到目标位置，同名控制台直接加载
python3 tools/engineering_db.py migrate <目标路径>/zmax_engineering.db
```

### 5.3 工程迁移

工程数据包与代码解耦：复制 `data/database/zmax/` 目录即可将整套工程带到另一台机器，由同一控制台加载。工程文件默认目录由 `tools/gui/project_file.py::project_dir` 定义，数据库默认路径由 `tools/engineering_db.py::DB_DEFAULT` 定义。

## 6. 数据治理与质量保证

1. **单一数据源**：所有结构化工程数据由真源单向生成，禁止直接修改数据库内容。
2. **一致性判据**：`engineering_db.py check` 按九大类共 15 项判据逐条核验，包括产品特征至子系统零悬空、功能至模块零悬空、功能三轴覆盖率、特征至能力命中率、工程七段完整性、模块与源码链完整性、参数真源可用性与 MCD 三轴一致性，全部通过方视为同步。
3. **变更留痕**：参数中心每一次参数修改均直接写入数据库 `param_events` 表（时间、参数、旧值、新值、真源位置、写入结果）。该表为运行时表，重建数据库时不清空，保证审计链完整。
4. **代码类参数保护**：涉及源码常量与函数默认值的修改必须通过语法校验，校验失败自动回滚，越界值与非法档位一律拒绝。
5. **版本与快照**：总工程记录真源指纹（SHA-256），可随时检测数据漂移；历史工程按版本归档于 `archive/`。

```

└── zmax/                     Z-MAX 平台标准产品数据路径
```

## 8. 术语

| 术语 | 说明 |
|---|---|
| 三轴（CFG / CAL / DIA） | 功能的三维定义方式：配置项、标定项、诊断项 |
| 能力（Capability） | 按能力视角定义、不含算法实现细节的最小可交付能力单元 |
| 模块（Module） | 能力的实现载体，与源码文件及行号一一映射 |
| 主参数 M | 状态空间工程的结构参数（等效惯量），现场可配置 |
| 真源 | 可人工编辑、纳入版本管理的数据文件，为数据库的上游 |
| MCD | 测量（Measure）、标定（Calibration）、诊断（Diagnosis）数据面 |
