# 配置中心左侧栏「适配宽度」(2026-10-12 老倪上报)

> 老倪原话: 「你看现在的配置中心，左侧栏，无法更改宽度，字体都挡住了。改适配宽度」

## 现场症状

配置中心页左栏(域树)文字被截, 而且拖动分隔条改不了宽度。

## 真因 (真机 192DPI 实测, 不是猜)

| 量 | 值 |
| --- | --- |
| 左栏文本需求 (最长条目 `perf.anomaly_recovery` = 337px + 缩进/箭头/滚动条) | **393px** |
| 左栏当时的固定/初始宽度 (`sp.setSizes([230, 1000])` + 无最小宽度) | **230px** ⇒ 337px 的字挤进 230px ⇒ **字被截** |
| 右侧 QTabWidget 最小宽度 | **2653px** |
| 整页最小宽度 = 393 + 2653 | **3046px** |
| 窗口可用宽度 = 窗口 3068px − 主侧栏 240px | **~2828px** |

⇒ 整页最小宽 (3046) **大于**可用宽 (2828) ⇒ 分割条被两侧最小值**顶死**: 左栏被挤到最小值(**字被截**),
且**没有任何余量可拖动**("无法更改宽度")。

**2653px 是谁贡献的?** 页1「⚙️ 工程配置」里一条 **2621px 的单行 QLabel**(`任务 TASK-07-AOI…真源 reports/aoi_points…`
那行说明), QLabel 默认按全文撑宽, 把所在页、进而把整个页签的最小宽度顶了起来
(`QLabel min=2621` → `页1 min=2649` → `tabs min=2653`)。同类还有页0 的 `状态空间工程(主工程): …` (2078px)。

## 改法 (三处, 都在 `tools/gui/veh6_config_page.py`)

1. **左侧栏按内容实测定宽** — `_tree_need_width()`: 遍历树(含子项)取 `缩进×层级 + fontMetrics 文本宽` 的最大值,
   再加箭头/图标 22 + 边框 4 + 滚动条 18 + 余量 12, 得到需求宽度; 把它同时当**初始宽度**和**最小宽度**
   (挤不没)。用 fontMetrics ⇒ **DPI 自动适配**: 96DPI 算出 230, 真机 192DPI 算出 393。
2. **真能拖 + 记得住** — 句柄 4→8px(`setHandleWidth(8)`)、`setChildrenCollapsible(False)`(不许拖成 0 宽),
   拖动结果写 `QSettings("ZMAX","Console")` 的 `config_center/tree_width`, 下次开页面沿用
   (只在 ≥ 需求宽度时恢复, 且不超过页面 50%, 防止把右栏挤没)。
3. **超宽说明行自动换行(治本)** — `_wrap_wide_labels()`: 右侧页签里任何 `minimumSizeHint().width() > 520px` 的
   QLabel 改 `setWordWrap(True)`。全文**一字不删**(换行显示, 照样可复制), 但右侧最小宽度回落到表格本身:
   **tabs 最小宽 2653 → 1924, 整页最小宽 3046 → 2325 < 可用 2828** ⇒ 分割条**终于有余量可拖**。
   构造时扫一遍 + `showEvent` 再扫一遍(有的页内容是后填的), 幂等。

## 判据 (真跑, 两套 DPI 口径)

`tools/verify_config_tree_width.py` — **10/10 PASS (96DPI 离屏)** 与 **10/10 PASS (QT_FONT_DPI=192 真机口径)**:

① 需求宽度=按内容实测(≥150 且 ≥ 最长条目+56) · ② 初始左栏=需求宽度 · ②b 初始不截字 ·
③ 强压 `setSizes([1,50])` 后仍 ≥ 需求宽度(挤不没) · ④ 拖宽到 需求+60 生效 · ④b 宽度落盘 ·
④c 拖到比内容窄(100) **被拒**, 仍 ≥ 需求 · ⑤ 新开页面沿用记过的宽度 · ⑥ 右栏仍 ≥400px · ⑦ 拖后仍不截字。

真机(192DPI, 真 X 渲染, `WA_DontShowOnScreen` 不打扰现场): 左树需求 393 · tabs 最小宽 **2653→1924** ·
整页最小宽 **3046→2325** · 摆到 2828 后拖到 473 生效、拖到 80 被拒(停在 393) · 页1 最小宽 **2649→553**。
截图 `/tmp/cc_real192.png`(+ 左栏裁图 `/tmp/cc_real192_left.png`) 已用 `tesseract -l chi_sim+eng` 读回:
`模型配置 1/6 · 工程配置 6/9 · 功能配置 1/3 · 性能配置 51/64 · 文档配置 0/3 · TASK-01-FW … TASK-07-AOI` 全部完整、无省略号。

## 生效方式

GUI 改动要**重启控制台**才生效: `env -u QT_QPA_PLATFORM bash tools/studio_ctl.sh restart --force`
(重启后核窗口标题里的版本号, 只看 pid 会漏"起的是旧版本")。
