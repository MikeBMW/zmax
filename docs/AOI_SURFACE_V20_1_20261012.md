## 1. 改动一: 取像参数 settle(治"改完曝光紧跟的第一张抓帧失败")

真实现象(10-12 实测): `POST /exposure` 改完档, **紧跟的第一次取图/检测会 500「图像抓取失败」**, 第二次才好
—— 那次失败被丢给了页面/技能(观感就是"改了曝光之后画面半天不出来")。

改法(`_apply_expo` ④): 参数写成功后**主动 settle 一帧** —— `_warmup_grab()` **只抓帧并丢弃**,
不动 `_LAST_PIC`/`_MEM`(绝不拿废帧污染显示), 回执里如实报 `warmup: true/false`。
重连策略: **只在第一次失败时** Close+ensure(实测"重开后的首抓也会失败一次"), 之后再失败原地重试 ——
如果每次失败都 Close/Open, 相机会被推进"关了又开⇒首抓必失败"的死循环(离线测试里真的复现了这个死循环)。
开关: `AOI_EXPO_SETTLE_S`(默认 0.25s)。

离线判据(桩按现场症状建模: 采集态写参数 ⇒ 下一抓失败; Close 过的流重开 ⇒ 首抓失败):
```
✅ ① POST /exposure → 200 · ok · warmup=True
✅ ② 紧跟 GET /picture?kind=origin&grab=1 第一次就 200 (88284 字节, 该请求只真抓 1 次)
✅ ③ 负对照(关掉 settle, 同桩条件): 第一次 500 · 第二次 200 —— 复现现场症状 ⇒ 证明②的通过来自 settle
✅ ④ POST 不动显示帧 · ④b 改档后内存帧已清(不拿旧档帧糊弄)
✅ ⑤ 相机未开 → 不 settle 且回执如实("待首次取帧生效", 不假装 ok)
```

## 2. 改动二: 判据阈值相对化(治"降曝光 ⇒ 判据垮")

真因(10-12 实测): 表面判据 v12.1 是**靠找"过曝亮条"→取上边缘/台阶量厚度**的, 而阈值是**绝对常量**
`JUDGE_TH_BAR=200 / JUDGE_TH_MOD=170`。这两个数只在"模块壳体过曝到 ≥200"时成立 ⇒ 相机一降曝光
(80000→40000)画面里没有 ≥200 的亮条了, `judge_ok` 连垮 3/3, 理由正是「亮条上边缘点太少(0)」。

改法: 阈值**跟着本帧走** —— `bg` 取 ROI 两侧竖条中位, `lvl` 取 ROI 99.5 分位,
`th = bg + 0.5×(lvl−bg)`(模块并集阈 `bg + 0.33×(lvl−bg)`), 夹下限 25。阈值写进 `/crop_info`
(`th_mode/th_bar/th_mod/bg_lvl/th_bar_rot`)可审。回老街口: `AOI_SURFACE_JUDGE_TH=abs`(逐位等于改前)。
**模型输入一字未动**(仍是 1280 letterbox 那张)。

同帧 A/B(同一份代码, 切 `th_mode` 前后对比; 同一时刻同一帧 = 口径同源):

| 帧 | λ(亮度缩放, 离线等效降曝光) | rel(新) | abs(旧) |
|---|---|---|---|
| No_1(zmax_data) | 1.00 | ok · thick 240 | **失败** |
| No_5/6/7 | 1.00 | ok · thick 64 | ok · thick 64 |
| No_1(_v12_1test) | 1.00 | ok · thick 179 · 右界 **1505** | ok · thick 177 · 右界 **1504** |
| 全部 5×2 暗档(λ=0.60/0.40) | 0.60 / 0.40 | **8/10 通过** | **0/10 通过** |
| 同上, abs 的失败理由 | | | 「亮条上边缘点太少(0)」= 现场指纹 ✅ |

判据: **λ=1.00 正常档不退化**(abs 成功处 rel 也成功 · 厚度/右界一致 ≤2px) · **暗档 rel 8/10 vs abs 0/10**。

⚠️ **两条如实声明**(不粉饰):
1. 上面用的 5 张是**离线桩帧**(早期离线测试产物: 平场块+亮条), **不是产线真帧** —— 它们只够证
   "阈值相对化在 abs 垮掉的地方不垮", **真帧验收必须在工控机上**(用产线那份真原图 2448×2048 跑同一条试验)。
2. λ 亮度缩放只是**离线等效**(代理), 不等于真相机的 40000us 档; 真验收要看真档位下的判据几何量。
