# 7-瑶光 · 记录追溯

本层管**"当时为什么这么定、出了什么事"**。是记忆，不是规范 —— 规范在 `0-总纲/`。

## 分区

| 子目录 / 文件 | 放什么 |
|---|---|
| `incidents/INCIDENT-INDEX.md` | ⚠️ 事故台账（真源，代码按此路径读）。出事先登记，再修 |
| `memory/` | ⚠️ `~/.hermes` 记忆镜像 + **引擎真读的工程记忆**（`src/lerobot/memory/eng_memory.py`）。**要改改源，别改名** |
| `notes/` | 交接、复盘、踩坑手记 |
| `handoff_*.md` | 会话交接（谁在什么时候接到什么状态） |
| `v5.x.y_summary.txt` | 各版本小结（版本号只听老倪；仓 `VERSION.md` 为准） |
| `STATE_SPACE_RETROSPECTIVE_20260926.md` | 状态空间工程的阶段回顾 |

## 三条规矩

1. **写事实不写判断**：「几点几分看到什么」可以，「应该是 XX 问题」要标成推测。
2. **事故先登记后修复**：`INCIDENT-INDEX.md` 是台账真源，别人靠它避坑。
3. **`memory/` 只读**：改了会被 `eng_memory.py` 读到错误内容，也会被下次同步覆盖。

## 出口

- 沉淀成规范 → `0-总纲/`
- 沉淀成可复用流程 → `~/.hermes/skills/`（技能，不是文档）
