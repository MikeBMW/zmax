# 3DGS 插口提质 · 横线补采 + 550C 训练 (2026-11-19)

## 一句话
插口在 1280×720 全幅里只占几十像素 ⇒ 模糊不是步数不够。用真机沿 **base y ±120mm 横线**补采
(240mm 视差基线)，在 **550C** 上重训；留出视角 PSNR 从 18.16 dB 提到 **20.88 dB**。

## 为什么是横线
| 维度 | 旧数据 (177 帧) | 本次 (4451 帧) |
|---|---|---|
| 视点 | 全部挤在成功入点一个姿态 | 同一条横线上 240mm 视差 |
| 姿态变化 | 0 | 0（rpy 锁定，实测 ≤0.003°） |
| 用途 | 只能复现同一张图 | 3DGS 可解出插口立面几何 |

## 真机执行（都是实跑，有逐段日志）
```
脚本   tools/rokae/sweep_y.py  （前置 power=on/automatic/idle + 授权 armed）
规划   tools/port_sweep_plan.py（URDF+MuJoCo 核验：IK 全收敛、离工装 302.9mm）
范围   y 136 ~ 376 mm（中心 256）· x 恒 653.0 · z 恒 171.9 · rpy 锁定
速度   12~20 mm/s · 11 点 × 24mm
实测   每段目标偏差 0.00~0.01mm · 姿态变化 ≤0.003° · ΔF 0.5~5.9N（无接触）
收尾   每遍都回起点 TCP 653.0/256.0/171.9（与出发一致）
安全   |ΔF|>25N / 偏差>1.5mm / 姿态>1.0° 任一触发即停（全程未触发）
```
> ±200mm 做不了：固定姿态下腕关节到限位，IK 在第 9 点跳构型（122°/215°）。
> ±120mm 是连续上限（单步 ≤8.8°），要 ±200mm 需允许腕部随动旋转或先后撤 10cm。

## 上线口径
`gs_render_loop.sh`（550C, 8816）每 `LIFE=900s` 按 PSNR 重挑最优资产，目录命名
`out_sweep_b → ds_sweep_b` 正好命中它的推导规则 ⇒ 新模型落盘即自动切流，无需人工。
判据：PSNR > 18.16 dB 且在役不退化，才留在默认档。
