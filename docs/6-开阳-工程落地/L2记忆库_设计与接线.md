# L2 记忆库 · 设计与接线（2026-11-02）

老倪要求：技能点的定义、功能接口 → L2 肌肉记忆技能库；固定轨迹点、工艺编排好的工艺卡 → L2 肌肉记忆操作；
需要记忆的工程配置、操作、点位都放 L2 记忆节点，其它节点只调用查询。

## 1. 两层库，一个只读入口

| 库 | 节点 | 文件 | 存什么 |
|---|---|---|---|
| 技能库 | `n_l2_muscle`（💪 L2 肌肉记忆技能库） | `data/memory/l2_store/skills.json` | 技能点定义 + 功能接口（ros 接口、参数 schema、前置条件、判据、步骤引用） |
| 操作库 | `ss_mem_l2`（🔧 L2 肌肉记忆操作） | `ops_cards.json` / `ops_points.json` / `ops_seq.json` | 工艺卡（工艺编排）、固定轨迹点（示教 tcp 位姿）、段序列与节拍口径 |
| 记忆体 | `ss_mem_l2` | `champs.json` / `ledger.json` | 固化标杆（练出来的 u 序列）、实测台账（mean_t / plan_t） |

`index.json` 是目录：每份库的 sha 指纹 + 条目数 + 构建时间。所有条目带 `src`（原文件）、`sha`（内容指纹）、
`at`（入库时间）—— 可回溯到真源，不是手抄。

## 2. 写只在记忆节点，读谁都可以

```python
from lerobot.memory.l2_store import query, stats          # 只读：任何节点/工具/页面
query({"skill": "L2.lift"})          # 技能点定义
query({"iface": "L2.lift"})          # 功能接口（ros=line_rel, 参数 schema, 判据）
query({"card": "SCN-07-AOI"})        # 工艺卡（按场景号取主工单；也可用工单号精确查）
query({"point": "slot_pick_place"})  # 固定轨迹点
query({"champ": [104, "插入"]})       # 固化标杆 u 序列
query({"measured": "pull"})          # 实测 vs 计划时长
stats()                              # 一句话摘要（两个节点输出、大屏、报告同源）
```

写接口 `put_skill / put_card / put_point / put_champs / put_ledger` 只接受 `writer="n_l2_muscle"` 或
`writer="ss_mem_l2"`，传别的直接 `PermissionError` —— 权限在代码里，不靠自觉。

## 3. 已接线的调用方（都改成查询，不再直读原始 json）

- `n_l2_muscle.compute()`：PURE 由 False → **True**，输出 = 技能库摘要（106 条 / 分类计数 / 指纹）；
  入参 `{"skill": id}` 时回单个技能的功能接口。不动作。
- `ss_mem_l2`（实现 `memory/mem_nodes.py:node_ss_mem_l2`）：PURE → **True**，输出操作库视图
  （cards/points/champs/ledger + 实测 bench）；入参可带 card/point/champ/measured/seq/iface 查询。
- 执行层 `engineering/exec/daemon.py::_load_points()`：点位**先查记忆库**，老库只补缺。
- 真机入口 `tools/l2_ros2_bridge.py`：`--skill L2.MUSCLE.OPEG_CYCLE.v1` 直接按 id 从库取技能
  （旧的文件路径调用仍兼容）。

## 4. 建库 / 刷新 / 自检

```bash
./gui-venv311/bin/python tools/l2_mem_build.py     # 重建（回真源现算，旧库自动备份，标杆三份收敛成一份）
./gui-venv311/bin/python tools/l2_mem_verify.py    # 15 项自检（含引擎 seed104 零回退）
PYTHONPATH=src ./gui-venv311/bin/python -m lerobot.memory.l2_store --stats
```

真源：`data/skills/l2_atomic/registry.json`（99 原子 + 3 组合）、`data/skills/l2_muscle/*.json`（5 示教）、
`data/datasets/points/*.json`（示教点位）、`config/orders/BS_*.json`（12 张工艺卡）、
`data/muscle_memory.json` + `src/data/muscle_memory.json`（标杆并集）、`data/memory/ar_muscle.json`（台账）。

## 5. 边界（如实）

- 技能执行 `SK01~SK07` 的限速常量与 `geo_plan._seg_time()` 的梯形速度模型还在各自代码里，没改成查库；
  台账 `ratio`（pull 2.96 等）目前只用于显示，不参与节拍计划。
- 记忆库是**副本 + 索引**，不是唯一物理存储：改真源后要跑 `l2_mem_build.py` 同步（sha 会报过期）。
- `PURE=True` 只让节点真读库并输出，不下发任何运动；真机仍走 L3 → `l2_ros2_bridge`。
