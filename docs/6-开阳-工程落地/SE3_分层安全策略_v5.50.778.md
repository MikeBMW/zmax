# SE(3) 分层安全策略 · 训练与影子验证 (v5.50.778+)

> 目标: 把"位置 ℝ³ / 姿态 S²+S¹ / 相位 S¹ / 速度 TQ"的分层口径落进状态空间工程,
> 并保证模型输出**不比固定轨迹更危险** —— 即"训练结果能跟固定轨迹一样, 输出安全轨迹"。

## 一、分层契约(与现有 action 契约对齐)

| 层 | 通道 | 维度 | 职责 | 输出对象 |
|---|---|---|---|---|
| L4 | `u[4:6]` swing + `u[6]` twist | 2+1 | 姿态: 摆开工具轴(S²) / 绕轴滚转(S¹) | `ΔR = exp(swing + twist)` |
| L3 | `u[7]` | 1 | 相位推进 `Δs ∈ T S¹` | 弧长参数 s, 决定"走到哪" |
| L2 | `u[0:3]` | 3 | 位置残差 `e_p`, 限幅到管半径 `r_t` | 把末端钉在管内 |
| — | `u[3]` | 1 | 夹爪 | 不变 |

**现状缺口(如实记录)**: `action_bus.from_ss()` 目前写死"姿态 = 真机真值原样带过来, `u` 不动姿态",
即 L4 姿态通道在链路里是**空白**。本方案补的就是这一块, 但只补到"影子"级别(见第四节)。

## 二、训练(数据 = 真机 215 帧录制)

```
样本     214 个转移 (= 帧数 − 1)
特征     19 维: 6 关节角(归一) + TCP xyz + 四元数(x,y,z,w) + (sin2πs, cos2πs) + s + 上一拍增量
标签     3 维相对旋转向量 r = log(R_tᵀR_{t+1})(度) + 1 维相位增量 Δs(换算 mm)
网络     MLP 19-64-64-4, tanh, Adam 3e-3, 600 epoch, CPU 单线程 9 s
```

### 🔴 评估纪律(这轮踩过的坑都在这)

1. **必须按连续段分折**。相邻帧 dt 中位 0.2s、转角中位 2.5°, 随机划分 = 把测试帧的邻居喂给训练 = 泄漏。
   用 5 折 block CV(每折 ~43 个连续转移)。
2. **误差口径必须是"两个旋转的物理夹角"**: `‖log(exp(r_pred)ᵀ exp(r_true))‖`。
   第一版用了"两个旋转向量的方向夹角", 小角度下符号一翻就是 180°, 实测把模型误差虚报成 62°(中位) —— 纯口径病。
3. **必须有平凡基线**: 零动作(Δ=0)、平均增量、上一拍外推(Δ_t = Δ_{t-1})。赢不过它们就等于没学到。
4. **必须有上界参照**: 直接取录制下一帧(= 固定轨迹), 误差恒 0。

### 结果(留出段, 单位 °)

| 方案 | 中位 | P95 | max |
|---|---|---|---|
| **模型** | 4.883 | 14.267 | 21.319 |
| 零动作 | 2.530 | 14.661 | 24.290 |
| 平均增量 | 2.695 | 14.944 | 23.703 |
| **上一拍外推** | **1.768** | **9.865** | **14.647** |
| 固定轨迹参考 | 0 | 0 | 0 |

相位增量误差(占整圈比例): 模型 中位 0.004 / P95 0.014; 零基线 中位 0.004 / P95 0.009。

**结论(不粉饰)**: 在"单轨迹 214 个转移"上, 训练出的增量模型**打不过"照上一拍外推"**, 相位也没赢过零基线。
这不是网络/调参问题: 214 个样本、一条轨迹, 模型只能学成"平均增量"。加 prev2/prev3 历史(25 维)更差(中位 5.229°), 已回退。
⇒ 按"未证明提升不得进默认档"的规矩, 模型**只能待在影子**, 不能进执行链。

## 三、安全收口(输出为什么"跟固定轨迹一样安全")

模型不直接产生坐标。真正下发的是**录制轨迹按弧长插值出来的点**, 模型只提议相位推进:

```
① 相位  s_cmd = s_now + clip(Δs, ±0.02)                  ← 环绕((s2−s1+0.5) mod 1)−0.5
② 目标  p_cmd, q_cmd = interp(traj, s_cmd)                 ← 位置线性 + 姿态 slerp
③ 闸门  单拍位移 ≤ 15mm(= V_max·dt·1.5, 与速度上限同源)
        lateral(到折线垂距) ≤ r_t = min(20mm, 1/(2κ))
        swing ≤ 10° · twist ≤ 12°(相对当前工具轴做 swing-twist 分解)
        真值帧龄 > 1.0s ⇒ 直接拒(无真值不出位姿)
④ 超闸  不是"停", 而是**就地折半降速**重算(最多 4 次), 折到 20% 仍超才判"真跳变"拒绝
```

两个旧版概念错, 已修:
- 拿"增量旋转向量的方向"去和 k 轴比来算轴误差 —— 增量方向 ≠ 工具轴偏离。已改 swing-twist。
- 偏轨用"到下一个参考点的距离"比管半径 —— 那天然等于一个步长(33~157mm), 把 96% 正常步判越界(实测 172/214 被拦)。
  已改**横向垂距**。

## 四、影子验证(离线, 不碰真机; 控制节拍 100ms, V_max 100mm/s)

| 模式 | 拍数 | 拦截 | 仿真时长 | 末相位 s | 指令点 vs 录制轨迹 | 姿态偏差 |
|---|---|---|---|---|---|---|
| 参考相位(运动学给 s) | 882 | **0** | 88.2 s | 0.99952 | 0.005 mm(P95 0.007) | 0.0001° |
| 模型相位(模型给 s) | 1200 | **0** | 181.8 s | 0.99976 | 0.005 mm(P95 0.007) | 0.0001° |

两种模式下**每一个指令点都严格落在录制轨迹上**(亚微米级), 且 0 次拦截 —— 这就是"跟固定轨迹一样"的
结构性保证: 轨迹本身是安全基准, 模型只能改变"走多快", 不能改变"走哪儿"。

## 五、顺带量出的一个硬事实

同一条轨迹: 真机逐点伺服 **475.9 s**, 而按弧长连续推进的仿真 **88.2 s**(同为 100mm/s 上限)。
差 **5.4 倍**, 差额不是速度, 是**逐点伺服的固定开销**(每点约 1.2 s: 下发+等待到位到 0.6° 内)。
⇒ 提速的正确方向是"沿弧长连续流式下发", 而不是继续调 speed 档。这条需要真机验证, 未做。

## 六、结论与下一步

已落地(S1 影子):
- `tools/train_se3_predictor.py` 训练 + block-CV 同源评估(指标落 `se3_predictor_metrics.json`)

- `tools/test_se3_safe_policy.py` 闸门回归 5 例

下一步(按风险从低到高):
1. **S2**: 残差限幅(L2)接进 `action_bus/execution`, 姿态仍用真值 —— 风险最低, 可直接上真机。
2. **多轨迹数据**是模型能进环的前提: 单轨迹 214 转移不足以训练增量模型(已实测打不过外推)。
3. **S3**: 相位推进进环(运动学给 s, 模型只做修正), 速度抑制沿用 flow 四档。
4. **S4**: L4 姿态通道替换真值直通, 每拍球面归一 + 重锚。
