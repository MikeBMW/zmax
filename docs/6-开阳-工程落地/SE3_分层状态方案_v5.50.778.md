# SE(3) 状态分层方案 · 技术描述 (v2 · 2026-11-18)

> 老倪口径: 位置留在 ℝ³(底), 姿态走 S³ 再 Hopf 拆 S² 轴 + S¹ 滚转, 速度放 TQ, 相位用 S¹。
> 本文件是这套方案的唯一技术描述, 落地程度按"已实现 / 半实现 / 未实现"如实标注。

## 0. 一句话

固定几何不动, 只沿相位重新参数化: **位置定"到哪", 轴定"朝哪", 滚转定"拧多少", TQ 定"多快", S¹ 定"第几成"** —— 五项各有唯一职责, 判据互不借用。

## 2. 数学定义

### 2.1 位置 (底空间)
`p ∈ ℝ³` 直接取真值。工作空间包围盒实测 `636 × 922 × 884 mm`, 绕几何中心半径中位 `300 mm`、最大 `775 mm`。
**不平移到底流形**: 工作空间是箱体不是球; 硬映射到 S³ 会引入度量因子 `4/(1+r²)²`(中心 4、边缘 1), 弧长/曲率/管半径全部失真 1~4 倍。

### 2.2 姿态 (S³ → S² + S¹)
单位四元数 `q=(w,x,y,z) ∈ S³`, `SO(3) = S³/{±1}` (二重覆盖)。实测 215 帧 `|q| ∈ [0.999999, 1.000001]`。

Hopf 纤维化 `π: S³ → S²`, 纤维 `S¹`:
```
n = ( 2(xz + wy) , 2(yz − wx) , w² + z² − x² − y² )   ∈ S² ,  |n| = 1
φ = 2·atan2(z, w)                                      ∈ S¹
π(q) = q·k·q̄ = n     (k = 单位纯四元数)
```
性质(已数值验证): `|n|=1.000000`; 右乘 `e^{iθk}` 后轴变化 `1.1e-16`(只改 φ, 不动 n)。

**为什么拆**: 插孔只约束轴, 完全不管滚转。混在一个总角里, "轴偏 3°"与"滚转偏 3°"判据相同, 无法分别处置。

### 2.3 速度 (TQ)
`Q = T⁶` 为带限位关节环面(注意 j4 表示可超 ±180°, 不作 S¹ 商处理)。速度控制的状态是 `(q, q̇) ∈ TQ`(12 维), 不是位姿空间。
速度抑制实现为切向量的标量调制:
```
q̇ = α(s) · q'(s) · ṡ_ref ,   α ∈ {100, 85, 70, 60}/100  (按块离散)
```
笛卡尔侧等价写法: 平凡化 `T SE(3) ≅ SE(3) × se(3)`, `ξ = g⁻¹ġ = (ω, v)`。

### 2.4 相位 (S¹)
几何弧长参数化: `s = ∫|dp| / L`, `L = 7.862 m`。
- 环绕差(唯一正确算法): `Δs = ((s₂ − s₁ + 0.5) mod 1) − 0.5`
- 首末实测差 `3.91 mm / 1.20°` ⇒ 近似闭环, 存在 seam, 禁止在 seam 附近线性插值
- 自交(为什么必须用相位而非位姿定位): 相隔 ≥6 帧的点里 **22 对关节差 <1°**, 最小 `0.0020°`(`#36 vs #108`, 平移差 0.0 mm)

## 4. 执行链

```
录制真值 (p, q, j, t)
   │
   ├─ Hopf 分解 → n, φ, Δn, Δφ        (tools/se3_hopf.py 权威 / arm_step_traj.py 同源副本)
   │
   ├─ 分类 _plan_flow(优先级从高到低)
   │     操作区(夹爪/AOI 停留点 ±3)  → 60 档 · 3 点 · 到点 dwell
   │     关节断层(单帧 >20°)        → 70 档 · 4 点
   │     轴断层(S² 单帧 Δn >10°)     → 70 档 · 4 点
   │     滚转跳变(S¹ 单帧 |Δφ| >12°) → 85 档 · 4 点
   │     常规                        → 100 档 · 12 点
   │
   ├─ 块间 S 曲线: 新块速度 ≤ 上一块 × 1.6
   │
   ├─ 每块下发前「真值重锚」: 与上一块终点的关节差
   │     3°~8° → 该块降速 30%   |   >8° → 直接停(零下发)
   │
   ├─ 块内闸: 单帧关节跳变 >40° → 拒; 单帧轴漂 >25° → 停
   │
   ├─ 下发: 一次 moveAppend(多条 MoveAbsJ) + 一次 moveStart, 等最后一点
   │
   └─ 块后校验: err_deg ≤ 0.6° 视为到位(pass); >2° → 停, 不重发
         到点动作: #9 close(hold 2000ms) · #125/#151 AOI 10082 · #172 AOI 10083 · #205 open(hold 2600ms)
```

## 6. 不变量(方案保证什么)

1. **几何不被改**: 下发的始终是录制帧的关节角; 调速只改"多快", 不改"到哪"。
2. **无真值不出位姿**: 每块前读真值重锚, 偏差超 8° 零下发。
3. **轴与滚转不共用一个阈值**: 轴走 S² 大圆角, 滚转走 S¹ 环绕差。
4. **误差不混口径**: `err_deg` 只表示关节到位误差; 轴/滚转误差是独立字段。
5. **失败即停不重发**: 任何闸不满足当场停, 留现场判断。

## 7. 落地程度(如实)

**已实现**
- p / n / φ 三项坐标与判据全落(含逐帧留证 json)
- 四类分块 + S 曲线 + 真值重锚 + err 闸
- 真机验证: 215/215 点 · 40 块 · 479.1 s · err max 0.14° · 轴 max 16.28° · 滚转 max 39.10°

**半实现**
- `q̇`(TQ): 只有"块速度指令"这一层标量调制, **没有速度闭环**(控制器只收位置指令, 每点固定开销 ~1.2 s)
- `s`(S¹): 用整数索引 `start+done` + 每轮 reset, **不是弧长环绕坐标**; seam 靠 reset 掩盖

**未实现**
- `branch` IK 分支标签
- SE(3) 上的管(tube)执行层: `r_t/r_r` 只算过(残差 P95 1.25 mm, κ 中位 4.28/m), 未进执行链
- 轴对齐纠偏闭环(块前算 `axis_err_deg` 并在 S² 上补修正量)
- 相对 SE(3) 记忆 `T_tool←module`(抓取偏移可迁移), 现全部是绝对位姿记忆

## 8. 验证方法

- **离线(零运动)**: 假 SDK(`ZMAX_SDK_DIR=<stub>`)+ 合成 cmd, 判块边界、`flow:true`、轴/滚转列、大跳变拒发; `_plan_flow` 可直接对 `real_traj_joints.json` 出计划(40 块, 轴/滚转分层 8 / 11 / 21)。
- **真机**: 整轮 215 点, 核对 `err_deg ≤0.6°`、`anchor_deg`、`axis_dn_max <25°`、末点关节差 ≤0.12°、臂回起点(`665.2/-29.0/296.1`)。
- **姿态自洽校验**: 插入段 `#20~#40` 平均轴 `[0.995, −0.029, 0.097] ≈ +X`, 与"X 从 761 单调增到 811"一致 ⇒ `q` 存的是 `(w,x,y,z)`。
