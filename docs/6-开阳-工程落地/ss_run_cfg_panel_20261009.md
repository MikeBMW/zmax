## 2. 整合落法（零回退的关键）
- **同一个控件对象搬家**：`model_tree.attach_run_switches({...})` 把 6 个 `QCheckBox` 从工具栏 `addWidget` 处摘除后 `addWidget` 进右面板
  （Qt 的 re-parent 语义）⇒ 运行路径里 `self.chk_engine_demo.isChecked()` / `getattr(self, "chk_intact_exec")` 等**全部照旧**。
- 工具栏只留 `⚙️ 运行开关` 一个按钮 → `_show_run_cfg()`：把右面板下拉切到最后一页 + 刷新 + 终端报一行。
- 新增页 `RunConfigWidget`（🔧 配置 · 运行开关），按 4 组排（运行方式 / 任务链 / 策略 / 模型接管），每行给：
  **开关本体 · 适用档位 chip · 作用 · 生效位置(文件:行) · 实测代价/边界**（风险行橙色）；底部**诊断行**（可复制）+ `↺ 恢复默认` + `📋 复制当前配置`。
- 档位 chip 会按画布「能力档位」节点 `cap_level` 判定命中：L2 档下 ③④⑤⑥ 会显示 `(本档无效)`，一眼看出"这个勾现在管不管用"。

## 6. 坑
1. **`hdr = QHBoxLayout()`**：改下拉条目时手一抖把 hdr 两行删了（Pyright 立刻报 `hdr is not defined`）—— 改布局代码后必须看 LSP/真跑，别只看 diff。
2. 每行开关各在自己的**行容器**里 ⇒ 判据不能再比较 `parent()` 相等，要比"往上找到的页面容器是不是同一个"（老 verify 脚本已按此修正）。
3. Qt 控件**只能有一个父**：想在两处显示同一开关是不行的 —— 所以是"搬"不是"复制"，也因此天然保证零回退（没有两份状态可不同步）。
4. 页面里出现的数字必须与源码一致（如 0.42→6.82mm、`state_space_sim_real.py:435`）—— 老倪会拿页面上的数去对代码，写错就是"造假"。
