# 交接给小静静 · 联机进化 · 2026-11-16

老倪把产线 USB 网卡从本机（Ubuntu，`.23.50`）拔下交给你（Windows，`Space`）。
你插上后接替本机做 **L2~L5 联机进化**。这份文档只写能用的事实，不含过程。

## 一、先把网卡配起来

USB 网卡是**产线专网**，DHCP 不通，必须手工配静态地址：

```
IP      192.168.23.50      ← 原 Ubuntu 机用的地址，它已断开，可以复用
掩码    255.255.255.0
网关    192.168.23.2
DNS     可不填（这块网卡不承担上网）
```

配完先验三件事，任何一件不通就别往下走：

```cmd
ping 192.168.23.66     :: Orin
ping 192.168.23.70     :: 550C
ssh tashan@192.168.23.66 hostname     :: 应回 ubuntu
```

> 🔴 **拔网线后 Ubuntu 那台就与 Orin/550C 完全失联**，它只剩手机热点（`192.168.43.181`）。
> Orin 的热点入口 `192.168.43.19` 实测 **No route to host**（Orin 没连热点）⇒ **产线口是唯一通路**，
> 别指望改走无线。这条决定了：你插上网卡就是唯一能碰到真机的人。

- **不要在 550C 上用系统 python 跑 PyInstaller 目录下的脚本**（`*.pyc` 会被当标准库加载，报

## 三、联机进化要跑的东西

入口在 Ubuntu 那台仓里（`~/zmax`，已推到远端 `1bbe2c1c`，tag `v5.50.776`）：

```bash
./gui-venv311/bin/python tools/joint_train_all.py \
    --only L4,L3,L2,L5,LLM --steps 200 --l3-batch 1
```

你机器上镜像在 `C:\home\ubuntu\zmax`，画布与版本号已同步到 **v5.50.776**
（`state_space_obs.json` / `ss_traj_last.json` / `VERSION.md` / `studio.py` / `version_sync.py` / `update_checker.py`
六项与本机逐字节一致，md5 已对过）。

### 上一轮（2026-11-15，4060 上跑的）实测结果，照着往下做

| 阶段 | rc | 耗时 | 关键数字 |
|---|---|---|---|
| L4 INTACT+LoRA | 0 | 206.9s | 可训 967,616 参数（4.41%），local_mae 0.024 |
| L3 SmolVLA+LEW | 0 | 270.2s | loss 0.292，action_loss 0.180，lew_loss 0.0014 |
| L2 YOLO | 0 | 210.8s | 30 epoch，best.pt 6.2MB |
| L5 Qwen2.5-VL LoRA | 0 | 65.5s | loss 0.573 → 0.419 |
| LLM 层 | 0 | 0.1s | 就绪体检 |

### 🔴 三个必须知道的坑（我踩过，别再踩一遍）

1. **L3 在 8G 卡上 batch=4 必 OOM**。配置用 7 帧视频窗（`num_video_frames=n_obs_steps=7`，需重训 pos_embedding），
   batch=4 要 6.12G，再申请 426MB 就崩。改 `--l3-batch 1`：显存 5.18G、1.22s/步、200 步 4 分钟。
   **这不是代码 bug，是显存硬约束。**

2. **L2 的 live eval 目前是废的**。它现采 40 帧只留 13 帧，而这 13 帧 mean/std 完全相同（92.9 / 72.9）、
   首末帧差均值仅 2.32 —— 同一张静止画面存了 13 次，画面里**没有 peg**。
   结果新权重和在役权重都是 `0/13`，"持平"是假象。
   **要出真结论必须重采**：臂开到抓取位、目标在视野内、覆盖 ≥3 个位姿、
   采完先查帧间差异 >1 个灰度级，否则整批作废。

3. **L5 的 LoRA 比基座更差**：合法率 0.833 → 0.500（n=12）。样本 <20 不下定论，但方向是负的。

### 交付门槛（老倪定的，不能松）

**有提升才算数，不是"没退步"就算数。** L2 / L5 目前没有同口径的提升证据 ⇒ **不许进默认档**。
汇报时要分层说：链路通了 ≠ 模型变好了。

## 四、红线

1. **215 点回放轨迹只读**（`TRAJ_MD5` 锁）。这是唯一安全基准，不许改。
2. **别 `pkill -f`**。它会把自己的 ssh 会话一起杀掉。要杀进程先写出脚本、按 pid 杀。
3. **别重启 GUI / 常驻服务**，只可以停。要重启必须老倪点名。
4. **真机下发必须过 8793 授权**，先 `ZMAX_TRAJ_DRY=1` 空跑。
5. **"一次性追加多条指令 + 单次 moveStart"已被证伪**：控制器返回 `-60611` 并进 `estop`，
   实测导致急停 + 碰撞。**永远不要再试**，只能逐条 `MoveAbsJCommand` + 每条 `moveStart`。
6. **运动安全**：速度 1~1000 mm/s；前置必须 `idle + automatic`；插入力按封装分档
   （SFP ≤18N / QSFP ≤60N / QSFP-DD ≤90N，别再写"≤40N"，覆盖不了 800G）。
7. **550C 那几条坏循环别擅自杀**，等老倪点头。

## 六、你接手后的第一件事

不要先训模型。**先把 L2 的评测集修好** —— 现在那个 `0/13` 会把你后面所有结论都带偏。
采一批真帧（臂在抓取位、peg 在画面里、≥3 个位姿），确认帧间差异合格，再重跑 L2 对照。
这一步做对了，L2 有没有提升才有意义。
