## 2. 层 → 引擎类型映射

| 层 | 物理量 | 引擎 `manifold_type` | 表示 | 度量 | 测地线 |
|---|---|---|---|---|---|
| A | 位置 p ∈ ℝ³ | `euclidean` | `[x,y,z]` mm | 欧氏 | 直线 |
| B | 轴 n ∈ S² | `sphere` | 单位 3 向量 | 大圆角 `arccos(n₁·n₂)` | 球面 slerp |
| C | 四元数 q ∈ S³ | `su2` | 单位 4 向量 `(x,y,z,w)` | SU(2) 双覆盖 `2·arccos|q·q̂|` | S³ slerp |
| D | 滚转 φ ∈ S¹ | `torus` | `[φ, 0]` ⊂ T² | T² 环绕距离 | 最短弧 |
| E | 相位 s ∈ S¹ | `torus` | `[2πs, 0]` ⊂ T² | T² 环绕距离 | 最短弧 |
| TQ | 速度 | — (切空间) | 6 关节 δ/δt + TCP 速度 | — | — |

三处口径必须说清(不是实现细节):

1. **C 的投影用 S³ 恒等归一, 不用引擎的 `su2` 投影器**。引擎 `su2` 分支走
   `SU2Element.from_rotvec(bounded_rotvec(v, gain=2.0))` —— 那是**有界控制器映射**(转角被
   gain 压缩), 拿它当"投影"会把四元数本身改掉。C 的几何口径 = 单位化; 引擎 `su2` 的**度量**
   (`e8ds`) 照用, 所以 C 与引擎仍然是同一条度量链。
2. **D / E 是 S¹, 引擎只有 T²**。用退化切片 `[θ, 0]`, 距离自动等于圆上的环绕距离
   (第二角恒 0 不贡献), 不是"近似"。
3. **B 的 n 是 `R·e₃`(工具接近轴)**, 不是四元数旋转轴, 也不是 `R·e₁`。
   `tools/se3_hopf.py` 头部注释写 "R·e₁" 是笔误, 代码本身算的是第三列; 本次以实测为准
   (与 R 第 3 列夹角 1.5e-06°, 与第 1 列 90°), 已在包内实现里写明。

## 3. 接进引擎的两处

- `manifold_engine.MANIFOLD_REGISTRY["se3_layers"]` = `ready`, 复合类型(逐层自身约束/度量/测地线)。
- `ManifoldEngine.se3_layers()` 惰性构造 `SE3Layered`(5 个引擎实例), **不用就不建** ⇒ 老路径逐位零回归。
- `ss_engine_loop.py`: `ZMAX_SE3_LAYERS=1` 时每拍算快照 → `rec["se3"]` + `/dev/shm/se3_layers.json`;
  真值优先(`tcp_out/latest.json` 帧龄 ≤2 s), 取不到回落轨迹末帧并**明写 src**, 不静默冒充真值。
  **默认关**: 常驻服务要生效需带该环境变量重启一次 `zmax-ss-engine-loop`(未擅自重启)。

## 8. 五流形 → flow-matching 的条件编码 + 流形感知噪声 (2026-11-19)

**结论先说**: 接法确定、已跑出自检 (`ok=true`), 但**还没进训练目标** ⇒ 现在只能说"能接、判据清楚",
不能说"有提升"。要进默认档必须同口径训练+对照。

### 8.1 条件向量 (20 维, `se3_flow_cond.SE3FlowCond.encode`)
```
A p/1000 (3) | B n (3) | C q(x,y,z,w, 统一 w≥0) (4) | D (cosφ,sinφ) (2) | E (cos2πs,sin2πs) (2) | TQ dq/100 (6) = 20
```
S¹ 一律用 (cos, sin) 编码: 裸角度在 0/2π 处会跳变 (上一轮实测 S¹ 环绕 179°→−179° 线性相减得 358°)。

### 8.2 噪声不是 N(0,I), 而是在各自流形上采
```
A: p + σp·N(0,I3)                      σp=20 mm
B: v⊥n 切平面, θ=‖v‖ ⇒ n'=cosθ·n+sinθ·v̂  σ=8°
C: q ⊗ exp(½σω), ω~N(0,I3)              σ=12°
D: φ + σN, wrap 到 [0,2π)               σ=10°
E: s + σN, wrap 到 [0,1)                σ=0.02
TQ: v·(1+N(0,σ))                        σ=0.10
```
实测对照 (2000 样本, 40 帧真机姿态):

| | 欧氏直接加噪 | 流形上采 |
|---|---|---|
| B 出球面比例 | **100%** | 0% |
| B 范数平均误差 | 0.111 | 1.1e-16 |

| | 欧氏直线插值中点 | 测地线中点 |
|---|---|---|
| C 范数 均值 / 最小 | 0.772 / **0.0175** (几乎零四元数) | 误差 1.1e-16 |

⇒ 在欧氏里插值/加噪, 中段会跑到流形外 (S³ 上范数 0.0175 等于姿态信息全丢), 去噪网络得先学"回到流形"。

### 8.3 注入点 (仓里已有的 flow matching, 不新造头)
```
multi_task_dit   src/lerobot/policies/multi_task_dit/modeling_multi_task_dit.py:135
                 conditioning_vec = observation_encoder.encode(batch)  ← 拼 20 维 c, conditioning_dim += 20
                 :196 compute_loss(...) / :136 conditional_sample(...) 不用改
smolvla          src/lerobot/policies/smolvla/modeling_smolvla.py:812 sample_actions(noise=...) ← 直接吃 sample_noise()
L3 节点          src/lerobot/engineering/nodes/flow_matching_impl.py   走上面两个模型
```
速度场输入形状 `[x_t(20), t(1), cond(20)] = 41` 维 (`vector_field_input`), 条件段逐位不被噪声污染 (实测 `cond_tail_identical=true`)。

### 8.4 自检判据 (`python3 se3_flow_cond.py`, `ok=true`)
```
编码        40 帧全部 20 维, w≥0 (双覆盖统一), 无 NaN
噪声        40 样本: B/C 范数偏差 0, D/E 值域 0 越界
插值        t=0 误差 0.0 mm, t=1 误差 0.0 mm, 中点出流形 0 次
网络输入     41 维, 条件段逐位一致

```
顺手修了引擎一个真缺陷: `geodesic("B")` 的 slerp 分支没把输入归一, json 里 6 位小数的 n (‖n‖=1±1e-7)
会让插值结果范数回不到 1 (实测中点偏 1.7e-7) ⇒ 归一后 0。

### 8.5 落地门槛 (老倪口径)
同数据/同折/同评估函数对照: 动作误差与成功率**有提升**才进默认档, 仅"不回退"只能留影子。
建议顺序: S1 只加条件向量(噪声仍在欧氏) → S2 加流形噪声 → S3 流形插值路径 → 每步单独报同口径对照。

## 11. 边界(不夸大)

- **s 仍未进控制回路**: 五流形是观测/闸门; 执行器逐点伺服, 相位只描述/留证。模型只提议 `Δs`,
  安全由"目标点永远从录制轨迹按 s 插值"保证(影子实测偏差 0.005 mm / 0.0001°)。
- **L4 位姿模型打不过"上一拍外推"基线**(4.883° vs 1.768° 中位) ⇒ 只能影子, 不进默认档。
- **B 的 `n` 是接近轴**: 插入段准静态(0.24°/帧), 轴是常量约束而不是跟踪量; 判据要轴/滚转分开。
- 五层快照是**只读观测**, 不产生任何真机指令; 本次全程零下发。
