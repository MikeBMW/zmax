# Z-MAX 5.50.1 变更说明（开发版本）

日期: 2026-10-13
上一版本: 5.49.4
本版本类型: 中版本升级 · 开发版（正式发布版 5.50.A 随本版本一并出交付工程）

## 一、本版本新增

### 1. 流形引擎 · 自动光学检测（AOI）
- `docs/design/流形引擎_自动光学检测_架构设计_v0.1.md`：AOI 的流形化架构设计（相机参数流形 / 扫描路径流形 /
  缺陷特征流形 / 势场层 / 控制层），并给出与状态空间「🔍光学质量检测」节点的旁路接入方式。
- `src/lerobot/manifold/aoi_manifold.py`：可运行核，含 `--selftest`（5/5 通过）与 `--calibrate`（只读标定在役相机）。
- **标定须过噪声底**：判据为 `跨度 > max(3σ, 1% 基准Φ)`。实测在役 10083 相机跨度 0.0191 < 噪声底 0.8591，
  判定为「当前档位暴露不可控」，避免把帧噪当成控制响应。

### 2. 侧面检测相机（工控机 OPT 10083）
- 曝光写入链路修正：`GET /exposure` 只读，**写必须 `POST /exposure?us=&gain=`**（此前用 GET 静默无效）。
- 在役档位由 `80000us / gain1.8` 降至 `20000us / gain1.0`：饱和像素(≥250) 由 **43.09% 降至 4.39%**。
- 交付图像：原图 + 搜索框叠加、以及按框摆正的判据图（纯旋转、零拉伸，与原图同帧同像素、亮度一致）。

### 3. 判据图矩形刚体动态搜索
- 需求口径：模块位置会变 ⇒ 找矩形刚体是**搜索任务**，不使用固定四角。
- 实现：候选 = 画面内每块亮区（不含固定坐标）；评分 = 面积占比 × 矩形度 × 对边平行度；择优 → minAreaRect
  出天然平行的四角 → 旋转摆正裁剪。
- 实测：多档曝光下稳定命中同一刚体（倾角 −61.9°、矩形度 1.00、平行度 1.00）。
- 摆正变换只做旋转(缩放 1.0)+按真实像素裁剪，尺寸与检出框完全一致 ⇒ 无拉伸；亮度一致性经同像素比对验证
  （均值差 −0.08 / 中位差 0.0）。

### 4. RealSense 曝光控制链修复
- `tools/realsense_source.py`：新增待生效档位（`_pend_set`）与在活跃管线上实时应用（`apply_pending`），
  解决 `get_active_profile() can only be called between start() and stop()`（设备后到导致控制路径不可用）。

### 5. 交付工程工具
- `tools/delivery/gen_config_inventory.py`：**从在役系统扫出**「全系统总配置清单」（版本/服务端口/systemd/
  crontab/配置唯一依据 sha256/任务场景/模型权重/相机与 AOI/数据空间/画布规模/运行环境），输出 md + json。
  交付件中的每个数字都可回读复核，不采用手写清单。

- 配置中心驱动不变：任务/场景/档位仍由 `config/ss_task_binding.json` 与 `flows/state_space_obs.json` 决定，
