## 怎么加一份新文档

1. 先问：它支撑哪件专利？找不到就说明它还没想清楚 —— 要么补进某件专利的功能条目，要么放到 `7-瑶光` 当记录。
2. 按主司放进七颗星之一（判定规则见 `docs/README.md`）。
3. 跑一次 `python3 tools/docs_index.py`，三个索引自动更新，文档会出现在 `文档对照.md`。
