## 三、动作：加一层 `0-索引`，不搬家

```
docs/
  0-索引/                ← 新增（目录页，不算第八颗星）
    README.md            总入口：两个轴 + 现状数字 + 新文档怎么加
    专利地图.md           20 件专利 → 挂载功能 → 落地节点 → 源码 → 相关文档
    节点索引.md           79 个节点 → 归哪件专利 / 模块 / 源码；哪些节点没专利覆盖
    文档对照.md           484 份本体文档 → 关联专利（≥2 分才挂）
    index.json           机器可读，给工具和画布用
  1-天枢… 7-瑶光/        原样不动
  README.md              加一行指向 0-索引
```

**为什么是"加一层"而不是"重排"**：484 份文件重排会牵动 243 处代码里的硬编码路径，
收益（看起来整齐）远小于风险（运行时 FileNotFoundError）。而索引层是纯新增，零破坏，两边都能独立合并。

**为什么索引必须现算**：联系一旦手写就会漂移 —— 加了一个节点、改了一件专利权项，索引就骗人。
`tools/docs_index.py` 每次从三个真源现算，谁真源变了跑一遍就同步。
