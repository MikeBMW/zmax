## 二、这一层的四条主线

```
观测            表示              动力学            预测              动作
感知与检测  →   状态空间    →    流形引擎    →    世界模型    →    策略与训练
(YOLO/SAM3)     (43D/SU(2))      (势场/度规)      (INTACT/JEPA)    (VLA/BC/RL)
     ↑                                                                    ↓
     └──────────────────── 数据总线（DDS-MASTER-DATA）────────────────────┘
```

四条不变式（改任何一层都要守住）：

1. **状态只认一套**：43D（39 视觉 + 4 触觉）是唯一表示，其它表示都必须映射进它，不许并行两套。
2. **上层只给条件和意图**：L4/L5 给的是势能、梯度、约束轴、门控，不是具体动作。
3. **执行由最下层收口**：限幅、碰撞、质量门全在执行前统一裁决。
4. **未证明提升不进默认档**：每条新通道必须有同口径对照，且带一键退回开关。
