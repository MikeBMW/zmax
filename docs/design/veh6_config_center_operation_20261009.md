## 0. 先说结论

**"配置中心现在只有模型"不是缺功能，是缺一个壳**：现在这一页（`studio.py` 8634–9350）是
「一组卡片页」，没有"域"的概念，所以塞不进工艺流程。
把它换成「**左侧五域树 + 右侧工作区**」，模型域只是树上一个叶子（现有 9 组卡片原封不动搬进去），
工艺流程就落在新的第五个域「**工艺·工单**」里。

**而且操作面今天就可用**：每个 GUI 动作都有等价命令（`tools/config_center.py`），
GUI 只是它的外壳 —— 一份逻辑两处用，不写两遍。

```
GUI 按钮            →  等价命令
首页·域树            →  config_center.py
参数表(三列)          →  config_center.py list 工程配置
点开一行             →  config_center.py show cam.K
📋 复制真源路径       →  config_center.py open cam.K
工艺域·配方           →  config_center.py recipe
工艺域·工件变体        →  config_center.py variants
工艺域·工单           →  config_center.py orders
生成工单             →  config_center.py order --scene SCN-02-HANDLE
诊断带·全链校验        →  config_center.py check
```

**为什么是"行=参数，列=三轴"而不是十二个页面**：同一个参数在三轴上是三种操作
（测量=只读它、标定=写它、诊断=判它），分十二个页面会把同一件事重复十二遍。
域是分组，不是页面。详见 `veh6_config_center_mcd_20261009.md §2`。

## 2. 操作路径：配一条新的上下料工艺流程（11 步）

> 每一步三列：**点哪里** · **等价命令（现在就能跑）** · **点了出什么结果**

| # | 点哪里（GUI） | 等价命令 | 出什么结果 |
|---|---|---|---|
| 1 | 打开「配置中心」 | `python3 tools/config_center.py` | 五域树 + 各域就绪度 + 缺口 + 工单数 + 模型匹配 |
| 2 | 点左侧「工程配置」 | `config_center.py list 工程配置` | 9 条参数表，缺失项标红（`T_base_cam` / `plane_z` / `cell_geometry`） |
| 3 | 点红行的「现场示教」 | `config_center.py show T_base_cam` | 判据 + 权限 + **真源路径与改法**（现场零运动采 10+ 位姿） |
| 4 | 点「工艺·工单 → 工序配方」 | `config_center.py recipe` | 8 段 25 条配方（段/参数/级/权限/判据） |
| 5 | 改一条配方参数（如穴位坐标/夹持力） | （B2 前用编辑器改真源 → 回读核验） | 判据不过就标红并给根因，不静默接受 |
| 6 | 点「工件变体」 | `config_center.py variants` | 5 个场景的物料/穴位/目标（12槽料盘·4孔治具·单颗18×9×4） |
| 7 | 点「生成工单」→ 选场景 | `config_center.py order --scene SCN-02-HANDLE` | ✅ 落盘 `config/orders/BS_SCN-02-HANDLE.json` + 工单号 + 物料/步骤/就绪 |
| 8 | 点「🔍 全链校验」 | `config_center.py check` | 7 项逐条 ✅/⛔ + 总判 + 共同根因 |
| 9 | 点「试运行(dry)」 | （B3 防错链预演，不下发） | 7 步防错链逐条结果：扫工件码→查工单→选程序→校验资源→下发→安全自检→记录 |
| 10 | 点「✅ 生效」 | （B3 下发 + 回读核验） | 参数写控制器 → 回读逐位比对 → 通过才置"生效" |
| 11 | 点「导出」 | `config_center.py orders --json` | 工单 JSON / Excel / 描述文件（可复制可导出） |

## 5. "点了必出结果"怎么保证（老倪的要求）

1. **每个按钮 = 一个纯函数 + 一个结果面板 + 可导出 JSON**；没有"操作完成"这种空话。
2. **失败给根因行**，不是"操作失败"：如 `⛔ 站点几何未标定 ⇒ 一切「坐标类」参数不可信`。
3. **测量列带时间戳/帧龄**（源停更标失效，不显示成"当前"）。
4. **导出优先**：JSON / Excel / 描述文件 / 工单，都能复制粘贴。
5. **G1 红线没有编辑控件**，只读展示；诊断列只报"是否被违反"。

## 7. 红线

- 工单与描述文件都是**生成物**：改真源 → 重生成；不手改。
- 站点几何未标定 ⇒ 工单**不允许下发**（不是警告，是拦截）。
- GUI 冻结纪律：一次改完再重启；改完必须说明"需重启控制台生效"。
- 本手册命令**全部只读**（`order` 只写生成物目录，不碰标定真值与在役指针）。
