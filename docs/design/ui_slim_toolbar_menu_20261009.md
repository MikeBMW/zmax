## 二、菜单 UI 设计 (老倪: 「你来设计 UI, 看如何显示」)

主窗口菜单栏: `文件(F) · 画布(C) · 视图(V) · 编辑(E) · 帮助文档(H) · 关于(A)`

```
画布(C)
├ 💾 另存为 JSON…            Ctrl+Shift+S     "把当前画布 (节点位置/连线/参数) 存成 JSON"
├ 📂 加载 JSON…              Ctrl+Shift+O     "从 JSON 文件加载画布"
├ ─────────────
├ 💾 保存模型 (固化 ckpt)                    "把当前已训练模型固化 → models/saved/"
├ ─────────────
├ 🔴 开始录制                Ctrl+Shift+R     "录屏: 画布+终端+模型结果, 全程记录"
├ ⏹ 停止录制                                "停止 → ffmpeg 合成 MP4"
├ ─────────────
└ ⛶ 浮动画布 (独立窗口)      Ctrl+Shift+F     "画布独立成可最大化窗口 (关闭自动还原)"
```

设计要点 (为什么这样分):
* **按"文件 / 模型 / 录屏 / 窗口"四段分组** —— 老倪要的是"不常用但要知道在哪"; 四段让他一眼归位。
* 每个菜单项都有 **悬停说明 + 状态栏提示** (不点也能看清点了会发生什么)。
* 高频的东西**没进菜单** (运行/单步/档位/跟随), 菜单不变成垃圾桶。
* **单一真源**: 菜单表写在 `SimulinkModule.CANVAS_MENU`, studio 只负责渲染;
  画布模块建好后用 `attach_canvas_actions()` 接管这 6 个 QAction。
* **属性名沿用** `btn_save / btn_load / btn_save_model / btn_record / btn_stop_rec / btn_float`
  ⇒ 录制状态机 (setText/setEnabled)、气泡定位等既有代码零改动 (QAction 与 QPushButton 这两个 API 同名)。

### QAction 带来的两处必须改 (真踩到)
1. **QAction 没有 `rect()`** → 原来的气泡定位 `mapToGlobal(btn_save.rect().center())` 会炸。
   新增 `_action_anchor(act)`: 取菜单栏里该 action 的关联控件位置, 拿不到就用窗口中心。
2. **QAction 没有 `setStyleSheet()`** → 录制中的"红字呼吸闪烁"不成立。
   改成 **画布横幅报帧数** (`⏺ 录制中 12 帧 ●/○`) —— 比原来按钮变色更显眼, 且帧数可读。
