① 高亮框与渲染同源 (根因 = 两个来源)
   高亮框读场景真源 objects3d.json (metaworld/MuJoCo 实测台面 1.4×0.8×0.054 @ y=0.6),
   而 3D 视图的桌面是遗留硬编码 _TABLE_SIZE = 0.92×0.62×0.024 (当年为插拔场景手搓)
   ⇒ 框比桌子宽 +52% / 深 +29% (两者顶面同高 z=0, 看着就是"框比桌子大一圈")。
   修: 新增 ss_dreamview.scene_table_truth(), 画桌子优先取当前场景真源的台面;
       仅米制仿真场景生效, 现场机位场景 (SCN-01-PEG 台面为毫米深度数据 428.7×653mm) 判定为毫米即不动。
   实测: 绘制盒 = center[0, 0.6, -0.027] size[1.4, 0.8, 0.054] == 真源; 真渲染抓帧绿桌像素 25970 → 53330。

②③ 侧栏 / 视图内面板折叠
   新增 ss_dreamview.CollapsibleSide(name, body): 22px 折叠条 (◂/▶ + 竖排标题) + 原面板内容框。
   折叠 = 内容 setVisible(False) 且 外壳显式钉宽 (22+3 px); 展开 = 22+3+内容框固定宽。
   折叠状态落 QSettings("ZMAX","studio") 的 ui/pane_<名>_folded, 下次开控制台仍是收起的。
   套用: 图层栏 (ss_dreamview) + 场景编辑栏 (dreamview_scene_edit, 插在图层栏之后, 布局 index=1)。
   视图内「🧭 动作调制器 · 八阶段状态机」面板: 右上角 ◂ 折叠成一行
   「🧭 动作调制器 6/8 转移 ██░░░░░░░░░ 13% 预计 0.64s」; 点面板外不误触发; 点它不转视角也不选中对象。
   实测: 图层 255→25px (省 230) · 场景编辑 249→25px (省 224) · 两栏折叠后 3D 视口 614→1068px (+454);
         八阶段面板 14 行/306px → 1 行/33px。

④ 删说明文字
   图层栏「勾选要观察的处理层」、场景编辑栏「列出 objects3d.json 对象 → 选中编辑/隐藏/新增
   (写操作经 scene_edit.py · 备份+回读)」两处删掉 (标题已够, 界面极简)。

⑤ 切场景"看着跟摆盘一样" (根因 = 几何冻在启动那一刻)
   场景专属几何 (插拔=带孔盒/孔口/AOI 相机; 摆盘=料盘+tray盘) 只在 _build_scene() 里按 scene_mode() 建一次,
   而 _switch_scene() 当时只做了 ①设 ZMAX_SCENE_DIR ②换桌面色 ③刷对象列表 —— 没有重建几何
   ⇒ 点「🧩 插拔」桌上那套餐盘件还在, 看着跟摆盘一模一样 (场景**数据**并没有变)。
   修: 切换后 self.scene_id = scene_id; self._build_scene() (本就幂等全量重建) + 重画当前帧。
   实测 (真渲染): 摆盘 18 场景层项含盘件 (可见性差分 1806 采样点) → 插拔 8 项含红盒 (差分 3871)、
       盘件消失、桌面转防静电绿 → 切回摆盘红盒差分 0; 重建项数 8 == 新建视图 8 (不堆叠)。
