## 一、要解决的问题

老倪给定文档《流形引擎 · 用质数约束泛化性》要求: 用质数的不可约性约束系统的原子结构, 让泛化性由结构对称性而非数据量保证; 并且
"运行 L5 状态空间工程时, 在工作同时自主进化用的就是这个结构化理解能力"; "每次系统更新, 都要有个质数结构表示唯一性"。

本设计给出**可运行、可判据、可复核**的落地: 三个互不相交的质数域 (能力 / 产品 / 迭代) + 一个只读的谱偏离量正则。

## 三、四条规则的落地口径 (逐条诚实标注)

**规则2 唯一分解约束技能库 —— 数学严格, 全部采用。**
原子结构 ⇄ 质数; 复杂结构 = 原子结构质数之积 (重复出现计入指数)。由算术基本定理: 该整数与"用了哪些原子、各用几次"**一一对应** ⇒ 可逆分解 (`decompose`), 无冗余、无黑箱。
实测: 30 组随机子集签名→分解往返 30/30 一致; 未知原子结构直接报错 (不静默); 产品质数在能力域分解必失败 (证明域不混叠)。

**规则1 质数间隙约束状态空间 —— 按"锚点稀疏化"落地。**
可固化锚点 (记忆点/示教点) 只允许落在质数索引位, 非质数位只允许插值。实测 n=128 → 31 个可固化位, 密度 0.2422, 与 π(n)~n/ln n (26.38) 同量级。它限制的是"离散化/固化的稀疏性", 不改变连续状态空间的度量。

**规则3 黎曼猜想约束度量张量 —— 原写法数学上错误, 按诚实版交付。**
原文档把特征值实部置到 0.5、虚部按质数间隙裁剪, 再 `np.diag(eigenvalues_real + 1j*eigenvalues_imag)` 重建度量。问题: 实对称正定度量张量的特征值必为实数, 强行复数化会得到**非 Hermite 矩阵**, 直接破坏工程在用的正定闸门与 det G = 1 归一; 且黎曼猜想**未被证明**, 实现不能声称"用了它"。
落地: 两个**只读**指标 —— ①补对称缺口 `symmetry_gap` (谱在 λ̃→1-λ̃ 下是否不变) ②质心偏离 `centroid_asymmetry` (谱质量相对区间中点 1/2 的平衡度)。工程不改写 g (判据实测 max|Δg| = 0.0e+00), 只把偏离量当正则项。
并给出**数学事实**: 归一化后 (和为 1) 谱关于 1/2 精确对称要求特征值成对 (a, 1−a), 每对和为 1 ⇒ 总和 = n/2 ≠ 1, 即 **n>2 时不可达**; 实测 n=2 (`diag[3,7]` ⇒ λ̃=[0.3,0.7]) 缺口 = 1.0 可达, n=6 不可达。在役唯一依据度量 `diag[10,10,50,10,10,10]` 质心 0.6667 (偏离 0.1667, 向单主方向偏) —— 这正是几何形状 G(x) 仍待按带状态实测轨迹标定的直接体现。
**与黎曼猜想无任何证明关系**, 仅借用"对称性正则"的思想。

**规则4 质数计数约束课程 —— 全部采用。**
采样率 = π(step)/step; 实测 sample_rate(1)=1.0, sample_rate(50)=0.30 (π(50)=15); 质数步 (2,3,5,7,11,13,…) 为跳变点。

## 四、版本唯一性: 每次系统更新一个质数结构

\[
F(\text{产品}, \text{迭代}, \text{能力集}) = p_{\text{prod}} \cdot p_{\text{iter}} \cdot \prod_{c \in \text{能力集}} p_c

## 五、产品协同 (550A 原创版 / 550B 标定版 / 550C 量产版)

能力集合是**包含关系** 550A ⊆ 550B ⊆ 550C (10 / 20 / 26 项, C = 元数据基元全量 18 + 阶段全量 8), 由此得到可测的协同不变量:

\[
\text{cap\_sig}(550A) \mid \text{cap\_sig}(550B) \mid \text{cap\_sig}(550C)
\]

实测三对整除全为 True。含义: 升级产品只是"乘上新增能力对应的质数", 因此**低版本的能力一定能在高版本里被唯一还原**(整除 ⇒ 商恰为新增能力之积) —— 这就是产品间协同 + 数据一致性的代数表达。

## 六、L5 状态空间工程: 边工作边自主进化

每 tick (`ManifoldEngineLoop.step` ⑥):

1. 取本 tick **真实出现**的结构: 位置恒有; 力/速度按实际载荷是否非零计入; 阶段按 8 阶段质数表计入 (不臆造)。
2. `PS.understand(...)`: 编码成质数签名, 与记忆库 `zmax_data/manifold/prime_memory.json` 比对。
3. **未见结构 ⇒ 记一条进化事件** (签名/组成/时间/产品), 即自主进化的输入; 已知结构只累加命中数。
4. 干跑 (`apply_updates=False`) 只读不落盘, 不污染唯一依据记忆库 (判据实测 mtime 不变)。

实测 3 tick: 签名 [134, 8030, 2134]; tick0 组成 `[m_pos, 接近]` vs tick1 `[m_pos, m_force, m_vel, 下降]` (结构随真实载荷变化); `product_id=550A` 随唯一依据。

## 七、与元数据根服务的一致性 (全系统数据一致性)

- 元数据 = 整个系统的数据库根服务 (18 项基础核心组成: 玻色子型 10 场/连续量 + 费米子型 8 离散实体); 数据空间每个 topic = 元数据组合成的"原子/分子/有机物"。
- 本设计的**能力域质数直接由这 18 项生成**, 判据断言"与 `META_PRIMITIVES` 逐项同名, 差集 0" ⇒ 质数结构不会与元数据层漂移; 元数据变了而质数表没跟上, 判据立刻报错。
- 产品能力集合只使用唯一依据 id (18 基元 ∪ 8 阶段), 判据逐项检查覆盖面。

## 八、接口 (唯一实现, 禁止在别处复制)

```
PS.signature(items, domain)        原子结构 → 质数签名
PS.decompose(n, domain)            签名 → 原子结构 (唯一分解, 不干净直接报错)
PS.fingerprint(product, iteration) 发布指纹 (唯一, 可反解)
PS.read_fingerprint(n)             指纹 → (产品, 迭代, 能力集)
PS.cap_signature_of(product)       产品能力签名 (整除关系用)
PS.spectral_symmetry(g)            只读谱偏离量 (绝不改写 g)
PS.anchor_ok(i) / anchor_sparsity(n)     质数锚点
PS.sample_rate(step) / curriculum(n)     质数计数课程
PS.understand(items, ...)          结构化理解 (已知/未见 + 进化事件)
PS.report(product, iteration)      汇总 (含协同关系)
```
