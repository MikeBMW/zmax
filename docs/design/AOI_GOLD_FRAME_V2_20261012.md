## 改法（一行命令回退：`ZMAX_AOI_GOLD_RECT=0`）
1. **新取景 `aoi_exposure_fix.gold_roi()`**（锚 + 扩，不切边、不取全宽背景）
   - 锚 = 竖直边缘密度最强带（与旧口径同源，历来稳）；
   - 扩 = 按**金色证据**向上下扩（容忍 3 行空洞，硬上限 2.5× 锚高）；
   - 列 = 齿排行内『金色列 ∪ 焊盘亮块列』1%/99% 分位 + 小余量（上下 max(6px, 高×0.4%)，左右 max(6px, 宽×1%)）；
   - 纯 blob 口径实测在产线帧上抖 **324 行**（不可用）⇒ 只当保障证据。
2. **帧间锁框 + 去抖** `_gold_roi_hold()`：差 ≤6 行/12px 沿用旧框；超差要**连续 3 帧**同向才切。
3. **几何锚在锁定条带上**（`_gold_rectify` v3）：只用左/中/右三段拟合出的上下沿斜率做透视，四角 = 条带自身边界 ⇒ 输出尺寸恒定；拟合不成**不丢帧**，退化成原样等比贴。
4. **严格等比**：`Ws = min(输出宽上限, 条带自身宽)`（绝不放大），`Hs = 条带高 × Ws/条带宽` ⇒ 不再纵向拉伸。
5. **输出尺寸锁** `_GOLD_OUT_LOCK`：首次算定后恒定，条带按等比塞进内框（差 <1% 肉眼无感）。
6. **绿框判定用施密特触发** `_gold_rect_vote()`：上线 0.46 / 下线 0.36（自检 r 在 0.43~0.52 抖时保持原状态，不再闪）；真摆正 r 0.7~0.9 立刻进，真拿走 r<0.2 立刻出。
