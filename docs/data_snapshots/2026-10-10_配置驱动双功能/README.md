## 5. 诚实项（口径，别当"已达标"）

1. **L5 = 配置驱动的目标/阶段链**（`ss_mode` → 链 + `targets`/`overrides`），本轮**不是**在线 LLM 每帧调用（LLM 端点未配）。要"L5 大模型下指令"须先配端点。
2. **插拔的 "插入深度 depth" 实为"到目标点残距"**（0.0004m），不是插入量/配合深度 —— 命名误导，建议改 `dist_to_goal` 并补真插入量判据。
3. **仿真单颗 CT 10.6~11.6s** > 目标 ≤3.15s（PVT 是产线节拍，仿真控制带宽更慢，非同口径，不宣称达标）。
4. **真空(进带→锁) 425~538ms** > 配方 200ms —— 仿真口径**含下降末段**（真机 200ms 指触碰后抽真空），已在日志标注，不作为仿真不合格项。
5. **Δz +1.78mm 系统偏置**：判据真源 `rest_z=0.0160` 与物理落座 `0.01778` 差 1.78mm（三槽一致、非随机）。建议按物理量测修 `rest_z`（或在落座判据里显式建模），否则每颗都吃 1.78mm 余量。
