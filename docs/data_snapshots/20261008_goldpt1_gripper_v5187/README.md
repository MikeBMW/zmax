## 二、夹爪「点了没反应」根因（不是安全闸、不是链路）
- Orin 上驱动实际暴露的服务名 = **`/gripper_srv`**；执行器三处（642/1314/1318）写 **`/gripper_driver`**（不存在的名字）
  ⇒ `ros2 service call` 永远 `waiting for service to become available` → 30s 后 `rcl node's context is invalid`
  ⇒ **夹爪指令全部石沉大海**（与 2026-09-21「松开夹爪不好使」同一病根）。
- 驱动**历来没有 systemd unit**（10-07 归并清单 `CONSOLIDATE_MANIFEST.jsonl` 里只有 arm bridge + uplink）
  ⇒ 掉了没人管。已拉起 `gripper_driver` 并加 `@reboot` 常驻（Orin 无免密 sudo，做不了 unit）。
- 实测: 直发 `/gripper_srv` → 回执 `curr_pos=977.0`；`/gripper_pos` 从 **1000（全开）→ 0.0（闭合到位）**。
- **未清**: `/gripper_pos` 类型冲突（驱动发 `Float32`，`ss_remote_tap` 订阅 `Float64`，三份工作空间新旧版本不一致）
