# 数据快照 · 2026-10-08 修 0.1mm 下压误判 (v5.18.6)

## 现场现象
点「去空间1」→ 页面显示已受理 → **臂一动不动**（"点了不动"）。

## 真因（三层，逐层排掉）
1. **手动模式**（为录 7 个点切的）：SDK 腿前置自检 `rc=3 ABORT 不是自动模式 (OperateMode.manual)`，
   0.01s 返回 ⇒ 臂不动。现场切回自动后解决。
2. **执行器被上一次失败粘住**：阶段2 失败后命令通道未释放，后续点击全部空响应（页面 lines=[]）。
   重启执行器解决（这是健壮性缺口，尚未修）。
3. **0.1mm 下压误判（本次修复）**：臂实际停 z=0.1726，参考点 z=0.1727，
   `keep_z` 横移取"当前高度"= 0.1726 ⇒ `z_floor`（容差仅 1e-6 m）判"低于参考点 0.0mm" ⇒ 整段拒发。

## 改了什么
- `tools/l2_daemon.py` `keep_z` 段：横移高度不得低于参考点；需往上贴时**最多微抬 5mm**
  （只补编码器/重力沉降的亚毫米噪声，不构成抬升）。
- `tools/l2_daemon.py` `z_floor`：容差 `1e-6` → `5e-4`（0.001mm → 0.5mm）。
  红线本意是"不许攻进夹具"（毫米级以上），0.5mm 不削弱它。
