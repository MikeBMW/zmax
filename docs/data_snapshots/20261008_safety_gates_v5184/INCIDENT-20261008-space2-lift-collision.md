## 根因（一句话）
**阶段1「就地抬升」的量是相对"当前位姿"的盲抬（cur+50mm），与目标点、与起点上方净空都无关**；
臂停在比目标点高 50mm 的位置时，这一抬必然比"该点自身需要的抬升"多抬 50mm ⇒ 越出该点净空。

## 落成的规则（要写进 L2）
1. **阶段1 只在需要时才抬**：目标 z = `max(点位z + 余量, 当前z + 极小余量(≤3mm))`；
   **当前 z 已在 `点位z + 余量` 之上 ⇒ 整段跳过（零抬升）**，不要"总是 +50mm"。
2. **每个空间点要有"上方净空上限"**：任何阶段目标 z > `该点记录z + 净空` ⇒ 拒发（可行域逐层收窄落到点上）。
3. **启动建图/转移前先判起点净空**：当前位姿若不在任一点位的净空域内，先归位再说（今天这一步是老倪手动做的）。
4. 听到"碰撞/急停"⇒ 立刻全局停（建图 + 采集 + `stop` + 执行器），以真值确认静止。
