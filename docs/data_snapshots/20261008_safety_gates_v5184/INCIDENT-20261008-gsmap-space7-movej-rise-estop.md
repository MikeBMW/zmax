## 根因（我的责任）
1. **MoveJ 自愈换了运动学却没换安全预期**：MoveL 走直线，操作者预期"就抬 86mm"；被拒后改 MoveJ 是**关节插值，末端路径可达空间内任意**，中途高度**不受目标 Δz 约束**。
2. 09:55 我加这条自愈时，只写了"会慢/会绕"，**没有加"升高不许超过目标 z + 余量"的闸**，也没有"升高类动作禁用自愈"的判据。
3. 让机器人**自动跑点（建图 7 轮）之前，没有先关掉自愈** —— 自动流程里出现关节乱摆，只能靠人按停。

## 处置与规则（即刻生效）
1. ✅ 听"急停/要碰撞" ⇒ 先停一切自主动作（建图 + 采集 + 执行器保留 + 以真值确认静止），再谈别的。
2. ✅ 急停后回安全区**只用纯 -Z 分步下降**（每步 ≤20mm、慢速、**关自愈**），每步核真值，报警变化即停。
3. ⛔ **MoveJ 自愈默认关闸**：仅当"目标 z ≤ 当前 z + 30mm 且姿态差 ≤5°"（下降/纯平移被拒）才允许，且必须带"关节插值中途 z 上限"闸；**任何升高类动作一律不许自愈**，被拒就停 + 问人。
4. ⛔ **建图/回点等自主跑点流程一律带"自愈关"**（宁可停住，不许关节乱摆）。
5. 待补：**space7 及其 XY 的实测净空**（同 10-01/10-08 space2 的待补项，等老倪口述或现场量）。
