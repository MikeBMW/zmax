## 三、两处必须说清的修正（不是照抄方案）

**1. 温度的语义（方案四「归一化前除以温度参数，控制分布集中程度」）**
数学上 `x/τ ∥ x` ⇒ **单纯投影的方向对 τ 是恒等操作**（判据 ④(a): 差 8.6e-17，纯浮点舍入）。所以 τ 落在"归一化前"**不产生集中/铺开效果**。它真正起作用的两处已实现：
- **输出量级目标**：归一化前除 τ ⇒ 要与 `unit_norm_regularizer` 一起用，"网络该输出多大"由 τ 定；
- **分布集中度**：`sphere_logits = ⟨p,q⟩/τ`（或 vMF `κ=1/τ²`）。判据 ④(b) 实测软分配熵随 τ 非降：
  `H(0.02)=0.000 → H(0.1)=0.236 → H(0.5)=3.976 → H(1.0)=4.120 → H(5.0)=4.158`（τ↓ 集中、τ↑ 铺开 ✔）

**2. 指数/对数的互逆域（方案六「对数映射: 用反旋转公式」）**
`log_p(exp_p(v)) = v` **只在 ‖v‖ ≤ π 成立**（球面单射半径）。越域不是 bug 而是球的固有几何：‖v‖∈(π,2π) 时 `exp` 折回并反向，`log∘exp(v) = −(2π−‖v‖)·û`；`exp` 对 2π 严格周期。判据 ⑧ 三条全核（0.7 互逆 2.1e-16 · ‖v‖=4 周期 精确 · 绕回式精确）。

## 四、与现场（在役 su2 档）的关系

- 在役流形**仍是 `su2`**（`config/calib` + 现场 `engine_latest.json::manifold=su2 · M=3.643 · inertia=False`），本次**未切换默认档**——按 09-12 定的门槛（*有提升非仅不回退，未证明提升不得进默认档*），切档需先出同口径 A/B 证据。
- su2 与 sphere 的几何关系：SU(2) ≅ S³（单位四元数球），故 `log_map/parallel_transport` 对 su2 同样成立，但须**双覆盖消歧**（±U 同一旋转）：引擎里已按"取同叶 (⟨p,q⟩≥0)"处理，对径输入满足 `log(−U,−V) = −log(U,V)`（判据 ⑱）。
- **零回归**：引擎 sphere 档补算子前后**逐位相同**（`sha256=606acb7edfaf44080af8c175b7e87ed69920035f5f7a5f62ecd658a173e4b375`，判据 ⑰）；`manifold_engine --selftest` 全部通过。

## 五、训练侧怎么用（方案七「代码框架」的口径映射）

现场的 `Encoder` 是 **PCA/SVD 闭式拟合**（不是 SGD 网络），所以"反向传播/优化器"部分落到**可选的球面投影层**上：

```python
from lerobot.manifold import sphere as S
proj = S.SphereProjection(temperature=1.0, learn_gain=False)   # 直接插在网络末端, 归一化可微
p = proj(z)                                                    # 推理: 单位向量
loss = S.sphere_distance_loss(p, p_target, mode="cos") \
     + 0.01 * S.unit_norm_regularizer(z_preproj-logits, form="sq")   # 长度正则
# 需要"集中/铺开": logits = S.sphere_logits(q, p, temperature=τ)
```

即：**编码器(任意网络) → 投影层归一化到球面 → 球面点入流形 → 用球面度量/梯度/测地线**，与方案五一致；L4 侧一行即可启用（`L4LatentSpace.project_sphere(z, τ)`）。
