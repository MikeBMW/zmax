# Roadmap Phase 卡: 与 L2/工程库对齐 + 点开可编辑 + 主指标整齐

老倪 2026-10-15 原话: 「Phase 0 这些黑灰字体的描述(原子技能…)与 L2 层要对应上, 再次检查, 更新;
鼠标点开的区域要可编辑、可保存更新; Phase 1/2/3/4 同理; 右下角主指标 速度反馈延迟≤10ms /
对位残差≤0.5mm / 成功率≥97% / 稳定恢复时间≤1s; 字体排列、位置要一致, UI 要优美整洁」

## 1. 卡上描述不许手写 —— 由单一工程库生成
- 真源 `data/database/zmax/zmax_engineering.db` 表 `sys0/sys1/sys2` 的功能行。
- `tools/gui/studio.py`: `PHASE_ROW_SHORT`(库行名 → 卡面短语) + `_db_sys_rows()` + `_phase_desc()`
  + `_phase_db_ref()`(弹窗里的「库真值全量」块, 可复制核对)。
- 判据 `tools/verify_roadmap_phase_texts.py` ① 断「对照表的键集合 == 库行集合」(逐条相等,
  多一条/少一条都红), ② 卡面「功能 N / MCD」必须等于库里算出来的值。
  ⇒ 库里加了/改了行而代码没跟, 判据直接红, 逼着同步; 不再靠印象写描述。
- 卡面要“字少不挤”: 卡上只留组名(去括号细节), 全量明细(含库行名)进弹窗只读块。
- 顺带教训: 侧栏/L2 文案也别凭印象 —— 曾写「安全层 · HAL · EtherCAT」, 库无此二行且
  `robot_io.py` 明标 EtherCAT「预留·未接入」⇒ 一律按库/代码真值改写。

## 2. 点开可编辑 (Phase 0/1/2/3/4 同款)
- 覆盖落盘 `config/roadmap_phase_texts.json`(原子: tmp + `os.replace` + 回读校验), 字段白名单
  title/desc/time/dims/kpi; 卡片当场 `_rebuild()` 刷新并打「✏️ 人工改写」标记(不冒充库真值);
  「↩ 恢复库真值」删掉该 Phase 的覆盖即回退。
- 判据必须自测整条环: 保存 → 回读一致 → 卡文本变 → 恢复 → 文本逐字回退, 且**判据不留痕**
  (现场快照 → 跑完原地还原, 再断与原字节一致)。

## 3. 主指标(KPI)整齐 = 同一字号 + 同一右/下边界 + 固定框
- 布局: KPI 之前 `addStretch()` ⇒ 贴卡底; 标签 `AlignRight|AlignBottom`; 标题固定 3 行高、
  KPI 固定 2 行高 ⇒ 五张卡「标题/维度/描述/指标」逐行对齐(不再因描述长短错位)。
- 字号不要拍脑袋: 用 `QFontMetrics` 在**实机卡内宽**里逐条量, 取「最长那条也放得下」的最大统一字号。
  实测卡内 176px: 13pt 两条需 226/242px(折行); 12pt 最长 174px ⇒ 单行。
- 折行的那一张 = 那一行比别的卡多一行 ⇒ 判据要断「每一条都单行放得下」(verify ⑧)。

## 4. 几何真源头量, 别拿截图猜
- 命令通道: `echo roadmap_geo > /tmp/zmax_nav_cmd` → `/tmp/zmax_roadmap_geo.json`
  (五张卡 + 各自 KPI 标签的**真窗坐标/宽高/字号** + 是否被挤出窗外 + kpi_ok 判定)。
- 截图/OCR 只能给「大概在哪」; 判「同一水平线 / 同一字号 / 有没有被挤出窗外」必须用控件几何(误差 0)。
- 像素复核作旁证: 按卡色统计 KPI 文字带的 y 范围与右边界, 右边界间距应等于卡距。

## 5. 陷阱(都实测踩过)
- **整页横向溢出会静默吃掉最右边的卡**: 页面最小宽由最宽的子件决定。实测 `HardwareCard` 的
  状态条(`StatBar` 4×300px)把首页最小宽撑到 1328px > 实机视口 1144px ⇒ Roadmap 第 5 张卡
  (x=1360..1600)连主指标一起看不见。修法: 改窄那个子件(300→245px) + 卡内长文本开 `wordWrap`,
  不要去缩字体硬塞。
- 卡的**最小宽常由头部那一行**(Phase 徽标 + 时间串)决定: 时间串不开 `wordWrap` 时
  「2026 Q4 - 2027 Q1」一条就把卡最小宽顶到 275px ⇒ 五卡最小宽合计 > 视口 ⇒ 第 5 张被挤出窗外。
- QLabel 的 `minimumSizeHint`: 只有开了 `wordWrap` 才降到「最长词」, 否则按整串宽度算。
- 启动/重启脚本判「实例在跑」必须**锚定整条 cmdline** (`^[^ ]*gui-venv311/bin/python studio\.py$`);
  子串 `pgrep -f` 会把自己终端里含该字串的诊断命令当成实例 ⇒ 服务 exit 0 报成功但**窗口 0 个**。
- 离屏脚本 `print` 后 `os._exit(0)` 会丢输出(管道缓冲) ⇒ 用 `python -u`。
