5. **安全边界**: 本流程零运动下发; 判据里加"安全门"(扫描 move_joint/move_pose/target_relative_joint/

## ⚡ 启动提速与"后台建页"铁律 (2026-10-19 实测)
控制台启动从 8.9s → 3.4s 的做法与**必须遵守的约束**:
1. **只先建首页 + 配置中心**; 其余页占位, 用 `_realize_page/_realize_pending` 按需/后台真建。
   索引不变: `insertWidget(idx, 真页)` 后 `removeWidget(占位)`; 画布插回原位后**必须**按 `stack.indexOf` 重算 `self.modules`。
2. **后台建页禁止用固定节拍**(120ms/500ms chain): 每页构建 0.1~2.5s 全是主线程阻塞, 连起来 = 窗口画出来了却
   点不动/滚轮没反应 (老倪原话:「无法用滚轮上下移动屏幕, 等很长时间能动了」)。
   正确做法 = `StudioMainWindow.start_idle_build()`: ① `QAbstractEventDispatcher.aboutToBlock` 判空闲
   ② **最近 2s 内有滚轮/鼠标/键盘输入 ⇒ 一个页都不建** ③ 每次至少隔 0.8s ④ 按实测耗时"轻的先生、重的最后"
   (`zmax_data/page_build_ms.json` 持久化), ⑤ YOLO 依赖链预热放最后。
3. 判据不能假设"窗口建完 = 所有页都在": 探针/判据里加 `win.materialize_all()` 一行;
   量布局前**显式切到目标页签**(配置中心会恢复上次页, 非当前页从未 layout, 量到的是 (0,0,640,480) 假绿)。
4. 装饰性横线别用 `QLabel("─"*96)`: 96 个字宽把整页最小宽度顶到 1632px, QTabWidget 取最大值 ⇒ 窄窗每页都被撑出可视区。
   用 1px `QFrame`。一排 12 个按钮最小 1472px ⇒ 改 6 个一行的 `QGridLayout`。

## 🔭 观察窗口 (太阳系/3D/信号) 的状态显示铁律 (2026-10-19 实测)
1. **视图不许只在 `__init__` 建一次数据**: `OrbitalArchView` 原来 `self.data.build()` 只在构造时跑一次,
   `_tick` 只推虚线相位 ⇒ 引擎 cycle 2.5s 内一动不动, 屏上是"打开那一刻"的死值。
   正确: `OrbitalArchData.reload()` 重读全部唯一依据 (canvas 138KB≈2ms, 8 份 JSON 合计≈4ms) + 500ms `refresh()`,

2. **状态必须分源, 不许一个灯代表全部**: 每体按**它自己唯一依据**的 mtime 上色 (●在跑≤2.5s · ◐陈旧≤60s · ○离线),

4. 判据 `tools/verify_orbital_state.py` 13 条 (帧龄独立复算/三个阈值边界/末行一致/改 ts 变状态/重读次数/悬停六项)。

## ▶ 观察窗口的"在跑"必须由控制台发布 (2026-10-19 老倪两次纠正)
老倪原话: 「太阳系不要来回跳，要连续，这些行星要连续旋转」「现在我还没有点击运行按钮，应该没有运行的力啊」
1. **别用文件新鲜度判在跑**: `tools/ss_engine_loop.py --hz 10` / `ss_fw_trace_pub.py` / `ss_skill_dispatch.py`
   是**常驻后台**进程, `engine_latest.json` / `torque_live.json` 永远 ≤1s ⇒ 按 mtime 判"实跑"会永远显示在跑。
   正解: 控制台在 `start_sim`→`_start_real_sim` / `_start_state_space_sim` 里发
   `zmax_data/ss_live/ui_run.json {running, ts, pid, task}`; `stop_sim` 发 false。
   观察窗口 (`orbital_arch._ui_run` / `gravity_table.run_state`) 只认它 **且 pid 还活着**
   (`os.kill(pid,0)`; 崩溃/被杀 ⇒ 自动判没跑, 不留假在跑)。没有该文件 ⇒ 未运行。
2. **没在跑就不许有力/不许动**: 不画力线(含透描)、不画自转弧、相位冻结、每体状态"未运行"、
   太阳标签只写 `M=… · 未运行 (无实时力)` 不写 T (否则等于把上次推理当实时)、表格头 ⏸。
3. **公转必须积分, 不能每帧按数据重算**: 旧实现 `相位 = f(实测量)` ⇒ 数据一跳相位跳 (来回抖)。
   现在 `_ph[k] += ω·dt`, `ω` 向目标平滑 (`+= (tgt-ω)·min(1,dt·1.8)`), 在跑时 ω 恒 >0 (0.25~1.25 rad/s);
   没在跑 ω=0 且相位不动。实测 12s: 每步增量恒正且 <0.09rad, 无一次倒退。
4. `_geom()` 的 pad 依赖图注行数 ⇒ 数据一变行数变, 半径 S 跟着变, 整张图"呼吸";
   加滞回 (行数差 ≥2 才重算) 后, 两次采样标签块位移 0px。

## 🚫 太阳系「禁止任何跳跃」(2026-10-19 老倪: 「必须改, 不能有任何连线的跳跃的发生」)
五条硬规矩 (违反任何一条, 画面就会"跳", 他一眼看出来):
1. **位置只能积分**: 公转相位 = ∫ω dt (ω 由实测量定快慢, 运行态恒 >0)。
   禁止 phase = f(实测量) —— 数据一变相位就整体瞬移, 这是"来回跳"的根因。
2. **跟数据走的量一律低通**: 月球轨道半径(残差)、连线近共线偏移(0↔4px)、连线透明度
   (有/无信号)、文字块位置 —— 全部一阶低通; 阶跃输入也不许阶跃输出。
3. **文字块 key 用"去掉状态字形后的首行"**: 状态一变字形 ●→◐/○, 拿整行当 key 会被当新块
   ⇒ 直接落位 = 跳一下。位置低通还要加**单帧位移上限 14px**(纯指数逼近时, 布局从一侧换到另一侧
   一步能走 160px, 看着仍是跳)。
4. **尺度不许呼吸**: `_geom()` 的半径依赖图注行数, 行数浮动会让整张图缩放跳变 ⇒ 加滞回(差 ≥2 才重算)。
5. **连线端点必须取当前球心**: 每帧用 `positions()` 现算, 不许缓存上一帧坐标。
判据: `tools/verify_orbital_nojump.py` (N1 相位步长 ≤0.30rad/帧 · N2 块位移 ≤22px/帧 ·
     N3 透明度 ≤0.35/帧 · N4 残差阶跃下月球半径 ≤0.06/帧 · N5 连线端点可取到) —— 5/5。
