# PyQt 交互/布局陷阱 — 闪烁 · 拖不动 · 杀进程 · 离屏取证

适用: `studio.py` 及其页面(太阳系/主参数/画布)。这些症状用户会用“一直在闪”“横向不动了”“上来自动跑”描述,
根因都不在数据层, 先按下面四条对。

## 1. "某一行一直在闪" = 悬停提示条反复弹出压住读数

- 机制: `mouseMoveEvent` 每移一次就 `setToolTip(...)`。鼠标停在右栏(没击中任何图元)时也设了一句通用提示,
  Qt 就把提示条反复弹/收 —— 截图上表现为半透明条盖住一两行数字, 像那一行自己在跳。
- 取证: 连拍 15~20 帧(0.16s 间隔), 量那块区域的墨量序列。数字在变时墨量**平稳**;
  提示条压上/拿开时是 2~3 倍量级跳变, 且逐字比对能看到整行文字被替换或消失。
- 修法: ① 加 `_set_ttp(txt)` 去重(文本没变就不调 `setToolTip`); ② 没击中任何图元 ⇒ 置空, 不弹通用提示。
  自测: 连续 6 次 mouseMove 调 `_hover()` ⇒ `setToolTip` 只应被调 1 次且为空。
- 数字本身每拍刷新(四元数/力)不是闪; 区分方法就是上面的墨量平稳性。

## 2. "分隔条拖不动了" = 两端最小宽之和顶死 QSplitter

- `QSplitter` 手柄能不能动, 取决于 `总宽 − 左min − 右min`。任一侧 `setMinimumWidth` 预先固定大值(如右栏 1080),
  加上画布最小宽, 一旦超过可用宽, 手柄就只剩几十像素甚至完全不动 —— 看着像“卡死/失效”。
- 修法: 大值只作**首选宽**(由 `setSizes()`/落盘恢复给), 最小宽压到内容真正需要的最小值
  (表的最小内容宽 + 边距; 画布 320); 窄了就横向滚动, 不牺牲可拖性。
- 离屏验证(不用真拖鼠标): 找到 `QMdiArea`+面板那对 splitter, `setSizes([900,759])` 后**回读** `sizes()`,
  再看反方向 `setSizes([1300,359])` 是否也被接受。两次都被接受才算修好; 只有一边动 = min 还预先固定着。

## 3. 杀 GUI/常驻进程: 写进脚本, 别内联 pgrep

- 内联 `pgrep -f 'studio\.py'` 会**匹配到调用它的那条 shell 命令自己**(cmdline 里就含这个字符串) ⇒ 把自己杀掉,
  表现为命令 exit -15、后续什么都没执行。
- 做法: 把模式串与 kill 循环写进 `.sh`(脚本文本不在自己的 cmdline 里), 只对匹配到的 pid 发 TERM, 再回读剩余。
  同一思路用于“某进程是不是真在跑”的检查: 扫 `/proc/*/cmdline` 时要**按 argv 分词**
  (`argv[0]` basename 以 python 开头 + 某参数 `endswith(脚本名)`), 不能用子串 —— 子串会把 grep、heredoc、
  判据进程都算成目标(实测: 明明没进程也报 alive)。

## 4. 独立进程组的"自动运行"印象

- 子进程用 `start_new_session` 起的常驻闭环, 控制台退出/重启**不会**带走它 ⇒ 下次开界面时它还在跑,
  用户描述为“一上来自己就运行了, 点重启也自动运行”。
- 规矩: 这类进程只能由用户点按钮启动 ⇒ 控制台**启动时与退出时各清一次**(启动时只清“不是本次进程的子进程”的残留;
  退出时连自己的子进程一起收), 并把它的状态文件无条件归位成 `stopped`(杀不到进程时也要写)。

## 5. 离屏(offscreen)自检: 能验结构, 别信像素

- `QT_QPA_PLATFORM=offscreen` 下可以: 构造窗口 → `materialize_all()` → 读 `sizes()/minimumSizeHint()/currentIndex()`、
  调渲染方法看内部记账(`_last_arrows`/`_s3_lens`/`_s3_slots`) —— 这些是稳定判据。
- 像素级断言只作旁证: 虚线的“占空比可见性”这类阈值判据会随相位/遮挡偶发掉线(同一代码连跑有时 64/64、有时 63/64),
  别拿它当回归门; 要稳就“多相位取最好一帧”, 但那等于放宽, 需明说。
- 主窗口离屏建完要 `win.materialize_all()`, 否则懒建的页不存在, `findChildren` 拿不到目标控件。
