# 🌍 万有引力表 (主参数 M 页 · 太阳系下面那张表)

老倪 2026-10-16 口述规格 → 落地口径。**照抄这张表前先看「坑」一节**, 那里每条都是当场踩出来的。

## 规格 (逐字)

> 画布右侧栏, 主参数的太阳系, 下面的参数, 不要测量 标定 诊断 配置, 只要一个标签「万有引力」,
> 列一个表格, 第一列实际对应状态空间(当前配置的元任务), 依次的列为 L2 L3 L4 L5 合力;
> 每个格是一个四元数, 右下角是四元数的合力; 每一时刻有一个主力, 其它是赋能力, 主力高亮;
> 例: 插拔的时刻插拔技能的 L2 是主力, L3 规划的 action、L4 L5 都是赋能力。

实现: `tools/gui/gravity_table.py` (数据层 `GravityField` + 视图层 `GravityTableWidget`), 接入点
`tools/gui/model_tree.py::MasterParamMView` (页签只剩一个 `🌍 万有引力`)。判据 `tools/verify_gravity_table.py` (23 条)。

## 每一格的四元数怎么来 (只许从真源算, 缺就写「未算」+ 写清缺哪个文件)

| 列 | 力幅值真源 | 方向 |
|---|---|---|
| L2 执行收口 | `skill_latest.<项>_mps` (实际执行) | 该项真实运动轴 = `ss_traj_last.u_exec_vec` 分段均值 |
| L3 调度规划 | `skill_latest.<项>_请求_mps` (调度请求; 技能闸门就是拿它比 L2 实际) | 同上 |
| L4 认知策略 | `chunk_latest.ff[0]` (前馈; **单拍量 ⇒ 只有当前阶段有**) | 前馈自身方向 |
| L5 意图规划 | `u_norm0 × engine_latest.confidence` (意图只给条件) | 同上 |

四元数 = 指数映射 `q=(cosθ/2, sinθ/2·û)`, `θ=π·min(1,|F|/u_ref)`, `u_ref=chunk_latest.u_norm0` (本拍参考速度)。

### 合力 = 主力 + Σ赋能力 (矢量相加) —— 老倪 2026-10-16 口径, 别再改回四元数平均

- 每一层的力先当**矢量**: `F_i = |F_i|·û_i`; 行合力 `Σ_i F_i`; 列合力 = 该列各项矢量相加; 右下角 = 全表所有格子矢量相加。
- 四元数仍然由该层的**真实力矢量**经指数映射给出 ⇒ 合力有四元数也有真实幅值。
- 等式核对 (每行独立重算: `|合力 − Σ各层力|`) 实测 0.0e+00; 主力↔合力夹角 max 32.5° (插入拍, 前馈补偿推开), 同轴行 0.0°;
  一致度 `|ΣF|/Σ|F|` 0.49~1.00。
- ❌ **别再**用「四层四元数等权平均 (Markley)」当合力: 那时 |F合| 恒等于 0、夹角 37~83°, 与老倪「主力和合力相差不大」直接矛盾。
- 表上要能让老倪一眼看到这个关系: 合力格第二行写 `Δ主 xx°`; 页脚一行写 `✅ 等式: 合力 = 主力 + Σ赋能力 (矢量相加) · 残差 max · 夹角 max · 一致度`。
- 主力**上色**: 每行主力格 = 实心琥珀底 (alpha 165) + 加粗 + 亮黄字; 首列该行带 ★ (★ 不许进数值格, 见坑 1)。右下角总合力格同色。

## 主力口径 (老倪给的判据, 别用纯 argmax)

- **正在跑的项 ⇒ L2 执行收口是主力**, 其余格子是赋能力。
- 纯按幅值 argmax 会出错: 插入时刻 `_请求_mps`(0.1417) > `_mps`(0.085) ⇒ argmax 会把主力判给 L5, 与老倪口径相反。
- 没在跑的项 ⇒ 该行里影响力最大的层。

## 坑

1. **窄栏省略号**: Qt 的省略阈值 = 列宽 - padding。实测侧栏 682px ⇒ 6 列各 ~98px (可用 90px)。
   `+0.24 +0.42` (11 字符) = 91px **会被打省略号** ⇒ 小数省前导 0 写成 `+.24 +.42` (84px)。
   同理 `一致度=0.64`(94px) 放不下 ⇒ 缩写 `致 0.64`; `主力 插入·L2`(90px) ⇒ `★插入·L2`(62px)。
2. **判据要按字宽机械核**: 单元测/视觉都会被省略号骗。用 `QFontMetrics(max(item.font(), table.font()))` 逐格逐行核, 因为
   表格字体来自 stylesheet, `item.font()` 拿到的可能是默认字体 (低估 → 假绿)。视觉子代理两轮都报「有省略号」, 机械核验 0 溢出
   (首列内容只有 28px) ⇒ **以机械核验为准**, 但要在报告里如实写清两边不一致。
3. **上下要能用鼠标调**: `addWidget(w, stretch)` 是死的, 鼠标拖不动 ⇒ 必须 `QSplitter(Qt.Vertical)`, 且
   `setChildrenCollapsible(False)` (否则一拖就拖没)、抓手 ≥ 10px + 描边 (深色底 7px 纯色看不到, 老倪会说「没有」)、
   `handle(i).setToolTip(...)`。拖过的比例落盘 (`splitterMoved` → QSettings), 但**只有人拖才写**。
4. **字号**: 老倪在 3068×1862 上, 10px 看不到 ⇒ 表体 14px / 表头 13px / 页脚 12px 是当下合适的档。字号一改就要重跑宽度核验 (见坑 1)。
5. **页脚放一份保底总合力**: 表可能被窗口裁掉 ⇒ 页脚第一行固定写 `★★ 全表总合力 … · 一致度 … · 本刻主力 … ★★`,
   并把逐真源帧龄列出来, 过期项标 `⚠️ 非本刻` (引擎没在跑时 L3/L4 是上一拍的力, 不能装作实时)。
6. **打包**: `gravity_table.py` 是 M 页的静态 import, 但仍显式加进 pyinstaller `--add-data` (win `;.` / mac `:.`) ——
   与 `proj_state.py` 同一类坑, 别赌 PyInstaller 自己能分析到。
7. **改格式串必数参数**: 去掉一个 `%.2f` 却少删一个实参 ⇒ `TypeError: not all arguments converted`,
   而 refresh 里那层 try 只捕获读真源的异常 ⇒ 活控制台只显示「万有引力: 表建不起来」, 判据还可能全绿。
   ⇒ 判据第一条必须是 **⓪ 控件能建起来 (行数>0)**, 再加一条 ⑬ 主力格上色/首列 ★, 否则「画得对不对」全是空谈。
8. **宽度自适应不要用「表给大最小宽」**: M 页套在 QScrollArea 里, 表的 minWidth 只会把表撑出视口
   (右边被裁, 看着像省略号)。要么直接给右栏 `ModelTreeDock.setMinimumWidth(1080)`, 要么按宽度降小数位:
   `_pick_fmt()` 逐档量字宽选 (3/2/1 位小数) 并 `resizeEvent/showEvent` 后 `QTimer.singleShot(0, ...)` 重定
   (resize 当时表格 viewport 还是旧宽度, 不延后一拍会永久选错档)。
