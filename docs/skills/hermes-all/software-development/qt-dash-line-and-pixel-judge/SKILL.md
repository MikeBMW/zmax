# Qt 自绘虚线 + 像素级判据的口径 (踩过的坑)

## 1. 虚线: 要用像素单位, 且要 FlatCap
- Qt 的 `QPen.setDashPattern([a,b])` 单位是**笔宽倍数**, `setDashOffset` 也是 ⇒ 同一几何在不同笔宽上不一致。
- 默认帽是 **SquareCap**: 每段划两端各外扩半个笔宽 ⇒ 6px 的间隔被吃掉, 看着像实线(实测 duty 0.90)。
- 正解: 两支笔(发光+芯)用同一像素几何 + FlatCap:
  `_d, _g = 7.0, 6.0`; `p.setDashPattern([_d/w, _g/w])`; `p.setDashOffset(phase_px/w)`; `p.setCapStyle(Qt.FlatCap)`
- 相位要用**像素**推进，再除以笔宽 —— 否则两支笔的虚线相位不同步。
- 量“是不是虚线”: 沿线取样, 按**线自身颜色**掩码统计“划/隔”段数 (要求 ≥2 段空档); “只要不是背景色”会被底下的其它图形(轨道环/引力井)骗到。

## 2. 像素级判据自己也会错
- **采样圆半径**: 球半径 = `S·RAD` (S=形状尺度), 不是 `R·RAD` (R=轨道尺度) —— 差一倍 ⇒ 采样点落在球体里, 结论全错。
- **同向共线**: 两条线角度相同时(如水星/木星角度都为 0) 后画的会盖住先画的 ⇒ 量前者的颜色得到后者。正解: 先造一个**隔离视图** (只留一条边) 再量几何。
- **布局函数与判据读同一段数据**: 若收尾还会改块位置, `label_rects()` 必须返回**最终**矩形(不是中间的 placed), 否则判据量的是改前的位置。
- 虚线判据的阈值按占空定 (≈55% ⇒ 逐线阈值 45%, 不要写成 80%)。

## 3. 自绘图的标签避让(多层)
- 锚定块(如每个卫星的编号): 用**确定性布局**(径向 + 奇偶错开 + 撞障就绕角度 ±22.5°/±45°), 不要用“找最优候选”, 否则拥挤区会堆在一起。
- 偏移量下限 = 块半宽 + 障碍半径: 32×14 的块挂 4px 球上至少要 ~26px 才不压到自己那颗球。
- 收尾再加一道“两两相交 ⇒ 后一块改放页边栏空槽”; 空槽也要对球/已放块做 keep-out。
- **块宽要随文字自适应**(按 QFontMetrics 量最长行 + 14px, 上下限 90/228): 统一固定宽会在短文本侧留大片空白、长文本侧贴边。
- 块被挤得离自己的球太远(>~90px)就拉一根 1px 淡色**引线**, 否则读图的人认不出归属。

## 4. 发光/透描遍的 z 序
- “外发光/透描”遍为了压在文字下面, 往往排在球体之后画 ⇒ 线会穿过球面(看起来 z 序错)。
- 正解: 这一遍包在 `QPainter.save()` + `setClipRegion(全画布区域.subtracted(每颗球的椭圆 QRegion))` + `restore()` 里。

## 5. 判据自身的两个隐形错
- **球本色≈线色**: 用“球心区里有多少线色像素”验证“线不穿球”时, 若该球颜色与线色接近(金球 vs 金线) ⇒ 假阳性。选与该球颜色距离**最大**的线色, 容差收紧到 ≤45。
- **只读静态检查被 `p.save()` 误伤**: 检查“源码里没有写文件口”的 grep 含 `.save(` 时, 先把 `p.save()`/`_p.save()`(QPainter)剔掉。
- **图例要按本帧实画生成**: 写死“紫=反馈”但本帧无紫线 ⇒ 图例与图不符。改成从实画边集收集信号种类, 再补一句“本帧无: 紫=反馈/回灌”。
