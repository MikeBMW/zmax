# AOI 成像选型：分辨率、视野、快门、镜头光源

老倪/客户常提“上 4K/6K 高分辨率就行”。接受其中对的，拒绝错的。

## 采纳：高分辨率 + 窄视野 + 多区域裁切，放弃“一镜全图”

- 一镜全图的死穴是物理的：**边缘畸变、景深不足、照度衰减**，算法改不了光学。
- FOV 定在“刚好覆盖物料偏移余量”，让坏区不进检测区。
- 算法端切 **2~4 个 ROI** 分别送模型；带宽/算力按 ROI 付，不按整幅付。
- 每块 ROI 的分辨率按“**最小待检缺陷尺寸**”反算像元，不按整幅定相机。
- **多相机是兜底**：整幅 4K/6K 多路并发撑不住时，才改分区拍特写。

反例（本项目实测）：10083 表面 2448×2048 里工件只占 9.2%，10082 金手指判据条带 2131×75 ——
整幅付分辨率、付带宽，有效信息密度极低。

## 拒绝：运动中用 Rolling Shutter

果冻效应是**几何形变**（逐行曝光时间差 × 相对速度），属信息丢失，不是噪声；
去噪/超分/后处理都补不回。0.1mm 划痕在飞拍里直接糊成一片。

Rolling 可用的四种条件（其余一律 Global 大靶面）：

| 条件 | 可否 | 说明 |
|---|---|---|
| 运动中飞拍（几十 µs） | ✗ | 果冻+拖影，不可逆 |
| 停拍（相对静止） | △ | 需 de-warp + 亚像素边缘拟合兜底，仅局部试点 |
| 极短频闪冻结 | △ | 毫秒级脉冲频闪，代价：光源成本 + 同步精度 |
| 静态拍摄+多帧合成 | ✓ | 这是消费级用 Rolling 的前提，产线没有 |

## 成本：省下的相机钱砸光学，不砸数量

- 小像素 ⇒ 衍射极限低。**镜头 MTF 不够时，4K 拍出来和 1080P 一样糊**。
- 必须配 **大光圈(F1.8 或更大)工业定焦 + 高亮频闪光源**。
- 几十 µs 的短曝光下，决定画质的不是底噪，是**绝对进光量（光子数）**。

## 对外表述（客户版，不激化）

1. 先肯定：高分辨率拓宽视野 + 算法裁切局部，确实是解决光学边缘限制的最优解。
2. 再坚持：工业飞拍（几十 µs 曝光）下，Rolling 的果冻效应和进光量不足算法救不回来；
   **只要在运动中拍，必须 Global 大靶面**，把钱花在大光圈镜头与频闪光源。
3. 给台阶：真要推 Rolling 降本，只能在停拍/频闪的固定工位局部试点，不作全线方案。

> 口径纪律：MTF/果冻效应属行业共识，不是本项目实测。对外引用时要标“需按所选机型复核”，
> 并附具体相机像元尺寸 + 镜头 MTF 曲线，别让共识数字被当成实测数据。
