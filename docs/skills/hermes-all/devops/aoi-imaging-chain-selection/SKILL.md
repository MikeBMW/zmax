# AOI 成像链路选型（分辨率 / 视野 / ROI / 快门）

## When to Use
- 给检测工位选相机、定视野、定曝光链路，或用户提出「上高分辨率 / 用卷帘降本 / 多装几台相机」。
- 写选型方案、技术协议、评估报告里的成像章节（要与实测数字分得开）。
- 现场出现「边缘看不清 / 量不准厚度 / 飞拍有拖影 / 划痕糊了」这类硬件层问题。

## 铁律一：决策顺序不可颠倒

```
最小待检缺陷 → 每缺陷几个像素(pixel coverage) → 像元/放大倍率
  → FOV 只覆盖「工件 + 物料偏移余量」 → 按工位/朝向切 2~4 个 ROI → 算带宽与算力
  → 仍不够，才拆多相机
```

从「要多高分辨率」倒推，只会买到一台拍得清整条产线、却量不准单条划痕的相机。

## 铁律二：高分辨率 + 窄视野 + ROI 裁切，放弃「一镜全图」

- 一镜全图的三个物理死穴：**边缘畸变**（越靠画幅边缘，畸变与真实尺寸误差混在一起）、
  **景深不足**（工件有高低差时边缘先虚）、**照度衰减**（边缘比中心暗一档，阈值判据直接漂）。
- 做法：4K~6K 分辨率，FOV 只定在「刚好覆盖物料偏移余量」，算法端切 2~4 个 ROI 分别送检测模型；
  带宽与算力按 ROI 付，不按整幅付。
- 🔴 **多相机是兜底，不是首选**。把「必须多相机」写成结论会被熟悉现场的负责人直接纠正：
  顺序是先缩视野、再切 ROI，只有整幅 4K/6K 多路并发把算力/带宽撑爆时才拆多机。
  落笔时三层按顺序写出来，别把兜底手段写成第一选择。

## 铁律三：运动中拍摄只有 Global 一条路

| 拍摄条件 | Rolling 可否 | 说明 |
|---|---|---|
| 运动中飞拍（几十 µs 曝光） | ✗ 不可用 | 果冻效应 + 拖影；**几何形变属信息丢失，不是噪声，去噪/超分补不回** |
| 停拍（工件与相机相对静止） | △ 可局部试点 | 需 de-warp + 亚像素边缘拟合兜底，不能当全线方案 |
| 极短频闪补光冻结画面 | △ 有条件 | 毫秒级脉冲频闪强行冻结，代价是光源成本与同步精度 |
| 静态拍摄 + 多帧合成（消费级做法） | ✓ 成立 | 这是 Rolling 能用的**前提**；产线是动态节拍，没有这个前提 |

- 消费级上小像素 Rolling 靠的是「静态 + 多帧合成 + 算法」，工业侧没有这个自由度，别照抄。
- 选 Global 时连**大靶面**一起选：像素做小了单像素进光量下降，几十 µs 曝光下信噪比不够，
  过曝亮条与工件面的边界反而更糊。

## 铁律四：省下的相机钱花在光学上

- 大光圈（F1.8 或更大）工业定焦 + 高亮度频闪光源。小像素衍射极限低，**镜头 MTF 不够时 4K 拍出来
  和 1080P 一样糊** —— 这笔钱省不掉，也补不回来。
- 算法兜底只用于「相对静止的局部工位」：前后帧畸变仿射 de-warping + 亚像素边缘拟合，
  用灰度梯度补偿像素变小带来的信噪比损失。不要写成通用方案。

## 铁律五：实测与行业共识分开写

| 链路 | 实测 | 含义 |
|---|---|---|
| 表面工位原图 | 2448×2048（5 MP） | 工件只占画面 9.2% ⇒ 整幅付分辨率、信息密度极低 |
| 金手指判据条带 | 2131×75（长宽比 28.4） | 判据只吃这一条，整幅其余区域全是浪费 |
| 判据边缘残差要求 | < 3 px | 实测 57 px 不达标 ⇒ 分辨率/边缘锐度是硬约束 |

- 上表是实测；「果冻效应不可逆」「MTF 不足时 4K≈1080P」是**行业共识**，页脚必须标
  「行业共识，非本项目实测；需按所选机型复核」。混写会被人拿去对供应商，一对就穿。
- 不替供应商定型号：只写约束（全局快门、靶面、FOV、像元、频闪频率、MTF 下限），
  具体机型留待用 MTF 曲线 + 像元尺寸复核；拿不到曲线就写「待供应商提供」。

## 坑

| 坑 | 症状 | 修法 |
|---|---|---|
| 先定相机再看缺陷 | 买了 5MP 全图，2px 划痕仍量不准 | 从最小缺陷反算 pixel coverage，再定像元与 FOV |
| 把「多相机」写成结论 | 被现场负责人纠正「先算裁切，算力不够才拆机」 | 写成三层阶梯：缩视野 → 切 ROI → 多机兜底 |
| 飞拍用 Rolling | 停不住的瞬间拍，直线拍弯、划痕糊成一片 | 运动中一律 Global 大靶面；降本只在停拍/频闪工位试点 |
| 降本只降相机 | 便宜相机配平庸镜头，4K 出图比 1080P 还糊 | 预算从相机挪到镜头(MTF)与频闪光源 |
| 把行业共识当实测写进报告 | 用户拿去和供应商对数，口径对不上 | 页脚标注来源等级，实测单列 |
