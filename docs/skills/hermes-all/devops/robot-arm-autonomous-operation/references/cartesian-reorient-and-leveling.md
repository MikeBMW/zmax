# 笛卡尔换姿 / 「把末端摆正」落地配方 (已真机验证通过的部分 + 硬限位在哪)

适用: 用户说「把末端/模块摆正」「把轴放平/立直」「换个朝向」, 而当前位姿离目标差 10°~90°。

## 1. 先把「歪多少」量成数字, 再谈怎么转

两套姿态口径, 用途不同, 不要混比:

| 口径 | 取法 | 用途 |
|---|---|---|
| 控制器 TCP `abc` | `/pose` 的 `abc`/quat(`x,y,z,w`) | 下发目标用; `R=Rx(a)Ry(b)Rz(c)` 外旋 XYZ |
| URDF tool1 真姿态 | `/api/urdf` 关节链 + `/api/tcp.joints` 做 FK | **用户看到的画面**以它为准(拿它判「歪不歪」) |

两者差**一个常量旋转**(实测同一时刻 tool1 轴 44° 上翘, 而由 abc 算出的轴水平) ⇒
「歪多少」用 FK 算, 「往哪下发」用 abc 算, 世界系的**增量旋转**两边通用。

倾斜量的定义(只关心某一根轴时):

```
z_c = R_tool1[:,2]                     # 关心的那根轴(单位向量, 基座系)
 tilt_deg = degrees(asin(clip(z_c[2], -1, 1)))     # 相对水平面的仰角
axis = normalize(cross(z_c, z_target))            # 转动轴
```

## 2. 目标姿态 = 世界系增量 左乘 当前姿态

```
Rd   = Rodrigues(axis, angle)          # 世界系
R_tcp_target = Rd @ rot(abc_now)
abc_target   = rpy_of(R_tcp_target)    # 反解外旋 XYZ
```

不要把「URDF 里 tool1 的轴」直接塞进 abc 的槽位 —— 中间差了那个常量旋转, 算出来的目标永远对不上画面。

## 3. 下发: 必须是「小步 + 掺位移」

- **位移=0 的姿态指令会被静默忽略**(回 rc=0、Δ=0、姿态不动), 所以每步带 **2~5mm** 位移。
- **步长 ≤10~11°**。一次 40°+ 会报 `50120/50102 奇异规避` 或「越界保护」而只走几毫米。
- 换姿前 **抬到 z≥450mm**(台面上方留扫掠空间), `guard_box` 放到 ±300mm; 窄 guard 会把换姿判成越界。
- 每步后**读真值**再算下一步的剩余角度(别用累加计划值, 实际会差几度)。

模板(每轮重算剩余角):

```
while tilt > 2°:
    step = min(10.0, tilt)
    abc_t = rpy_of(Rodrigues(axis, radians(step)) @ rot(abc_now))
    move_abs(xy 不变, z += 0.003, r=abc_t, speed=8, motion='L', guard_box=宽)
    abc_now, tilt, axis = 重新量()
```

## 4. 何时停手(这是硬边界, 不是再试一次)

- 同一片姿态区域**反复被拒**(换起始方位、换 dz、缩步长到 5° 都不行) ⇒ 腕部**关节限位**, 停。
  实测: 43° 里走到了 30°, 剩 13° 怎么都过不去; 换方位再来一次仍被拒。
- 处置: 把已到达的姿态、剩余角度、被拒的控制器原文一起报给现场, 请在**示教器上手动掰**到目标姿态,
  掰好后读一次 `abc` 存进任务/元素(`rpy_deg`), 下次直接用这组, 不再现场试。

## 5. 取证口径(汇报要给这几项)

1. 起始倾斜角 → 当前倾斜角(逐轴分量), 走了几步、每步实测变化;
2. 每步的回执 rc 与控制器原文(拒的时候尤其要给原文);
3. 结束后连续 3~4 次采样位姿**逐位相同**才说停稳;
4. 当前 op/mode/急停/报警四项原值。

工具: 仓库 `tools/level_tool.py`(量 tool1 轴 → 算目标 abc → 分步下发 → 每步回读, `--step`/`--dz`/`--max-steps`)。
