# 画布「配置 / 标定 / 诊断」接口节点的设计约定 (ASAM-MCD 类比)

何时用: 用户要把某个节点做成"整车配置"式的**统一入口**——一套接口里既能**配置**(选功能组合→派生参数)、
能**标定**(扫描/寻优/写参数)、又能**诊断**(断言跑分/参数健康/报告); 或者要新增一个"标定层向引擎暴露主参数"的节点。
典型代表: `n_calib_mani`(🧮 流形引擎标定 · 主参数 M)。

## 1. ASAM-MCD 三件套 ↔ 画布/工程 对应

| MCD 部分 | 原义 | 本项目对应物 (别再另造) |
|---|---|---|
| **MCD-1 MC**(XCP/CCP) | 工具↔ECU 的链路与协议 | 只读遥测(旁路帧源) + 在役位姿真值 `zmax_data/rokae_sdk/tcp_out/latest.json`(50Hz) + DDS 遥测; **写**永远走 8793 `/ctl/*` 收口链(白名单→授权→限流→FIFO→执行器→安全闸) |
| **MCD-2 MC**(A2L) | 描述 ECU 里可测/可标/可诊的量 | **描述文件**(如 `config/mcd/zmax_mcd.json`): MEASUREMENT / CHARACTERISTIC / COMPU_METHOD / GROUPS 四段; 由 `feature.dbc` + `config/calib/*` 生成 |
| **MCD-3 MC** | 远程读/写/启停 | `tools/hil_local_api.py`(8795) 的 `/hil/term/<域>` 路由(全带 token, 无 token 403); 上游是画布 `n_hil` 节点 |
| **MCD-1 POD** | 可插拔设备即插即用 | `feature.dbc` 的 `BU_`(模型节点) + `CM_`(能力组合); 第三方按声明接入, 不改平台代码 |
| **MCD-2 D / ODX** | 诊断数据库 | `verification_layer.FEATURES`(断言=诊断项) + 稳定故障码 ID |
| **MDF** | 采集数据存储 | 扫描记录 `reports/<域>/scan_*.jsonl`(每点一行: 参数值/指标/时间戳) |

核心不是协议, 而是"**量先被描述, 别的工具(旁路窗口/远程页/诊断脚本)才读得到同一个值**"。
现状的病根通常是: 参数的意义散在 `*_spec()` 函数、画布节点 `params`、`config/calib/*.json`、画布说明四处, 没有一份机器可读的描述。**先补描述文件**。

## 2. 参数五级分类 (强制; 这是"标定≠改红线"的唯一手段)

| 级 | 含义 | 写权限 | 例 | 允许的标定方式 |
|---|---|---|---|---|
| **G0 结构参数** | 由结构导出, **非自由拟合** | 只读 + 授权写 | M(等效惯量尺度)、latent_dim、manifold_type | 单标量现场标定; 禁止当自由参数调 |
| **G1 安全参数** | 硬红线, 有守卫兜底 | 只读; 写需**现场一次性授权** | saturate、veto_th、max_step、力上限、限位、`collision_detection` | 只能证明不违反后收紧, **不允许放宽** |
| **G2 性能参数** | 有目标函数, 可扫 | 授权写(走 mcd 通道) | 速度系数、前馈增益、夹爪时序、τ | 扫描 + 目标函数寻优 |
| **G3 场景参数** | 现场示教/几何 | 现场写(零运动录点) | 示教点/安全点、plane_z、z7、TCP offset | 只能"读当前真值落盘" |
| **G4 模型权重** | 不可标, 只版本 | 只读 | safetensors / LoRA / ckpt | 版本比对 |

每条参数强制元数据(缺一不可): `{级, 单位+换算, 范围+夹取策略, 默认值, 真源(文件+键), 影响面(哪些节点/层读它), 判据(好/坏阈值), 写权限, 关联 feature}`。
**G1 永远不挂在这条链的写口上** —— 标定节点只**读** G1 当约束。

COMPU_METHOD 一律要实测依据, 别现编: 腿速(名义 `0.0935×speed`, **实际≈÷10**)、D405 深度(0.1mm)、
容器内 `t` 比宿主早 8h(NTP 回拨, **只看文件龄不看 t**)、录点帧龄 >2s 拒用。

## 3. feature 组合 → 参数集 (派生 + 冲突检测)

`feature.dbc` 的 `BO_` 只声明能力与 SG_ 信号, 不说"这条能力暴露哪些可配置参数" ⇒ 补 `PA_` 绑定:
```
BO_ C2 精细对位: CFG/OUT C
 PA_ P_FINE_TOL  G2 [0.02,2.0] 0.10 auth  mm "允许偏差"
 PA_ P_FORCE_MAX G1 [0,2.0]    2.00 field N  "插拔力上限(红线, 只许收紧)"
```
派生算法(配置 = 一次纯函数调用): `CM_` 能力集 → 并集 `PA_` ⇒ 候选参数集 → 按级过滤权限
→ **冲突检测**(同一参数被两条能力要求不同范围 ⇒ 取交集, 交集空则**拒配**, 不许静默取一个)
→ 缺 G0/G1 则拒配 ⇒ 产出 `run_cfg` + `param_ready`。
按能力档位收敛: L2 只需 G1+G3 · L3 +G2 · L4 +G0 · L5 只读 ⇒ **换档 = 换参数子集**。

## 4. 节点 I/O 与"与可视化节点的交互" (最易踩的一条)

- **不动的部分**: 已有接线一条不改(加节点/加口都不能碰既有线)。
- **新增口只前向**: `f.x + f.w <= t.x`。
- 🔴 **与旁路实时可视化(`ssbypv`)的交互不要走画布线**: 可视化行在整图**最左端**(x≈700), 业务行节点在 x=1500~19000
  ⇒ "业务节点 → 旁路可视化"必是反向线, 被断言拦下。用**两条真通道**:
  ① **数据面(主)**: 节点写 `_SS_STATE[<域>]` + `reports/<域>/scan_*.jsonl`; `SSBypassView` 加一个**区块**读它
     (照既有「🛰 上网通道」区块: 同款 `CurveWidget` + 一个 `*_status_line()` 汇报函数), 区块里放触发按钮 POST 8795 ⇒ **双向**;
  ② **画布(可选)**: 要"看得见"就在可视化行**右端**另开轻节点接住(前向成立)。**绝不挪 ssbypv 或任何既有节点**。
- **要分清状态线/控制线**: 加完线要说清它是"只回显"还是"真驱动下游"(见 SKILL.md「接线 ≠ 被消费」)。

## 5. 写参数的纪律 (三段式 + 零回归)

1. 备份 `prev`(`<真源>.bak_<ts>`); 2. **只改自己那一节**(读-改-写单键; **禁** `sync_calib(write=True)` 整表重合并,
会把内参/几何/TCP 一起刷成"当前源"而改在役读值); 3. **回读核验**逐位一致 + 跑一次"零回归"断言分支。
- **零回归是默认态**: 关掉新机制(inertia=false / 参数回默认) ⇒ 行为与旧实现**逐位相同**; 面板/日志要常显"零回归 ✅/❌", 改完立即重算。
- 写口要能"先演练"(`{dry:true}` 不动盘), G1 参数在写口**直接拒**。

## 6. 与状态空间工程的科学整合 (四条硬约束)

1. **稳定性先于性能**: 参数可行域不是滑杆给的, 是**算出来的** —— Lyapunov 单调(`ΔV<0`) + 步长上界 + 谱半径<1,
   与滑杆范围求交; 超出报"**不可标定**"而不是"标定失败"。
2. **指标同源, 零新造**: 终到误差/η/节拍/力峰/否决率全部取自 `io_trace`、`energy_manifold`、`manifold_layer`;
   面板里**不另算一套**(第二份真相 = 下一轮被戳穿的地方)。
3. **可辨识性先验**: 先算有限差分敏感性 `S=∂J/∂参数`; `|S|` 落在噪声带内 ⇒ 报"**本场不可辨识**, 换数据段/换指标再试",
   **不报一个假的最优值**。扫描要**随机化顺序 + 每点多采**防顺序效应。
4. **可回溯**: 每条参数带 `关联 feature` + `归属层`, 改一个参数要能答"动了哪些能力/哪一层/影响哪些断言"。

## 7. 落点与分批 (每批独立验收)

| 批 | 内容 | 判据 | 碰 GUI/画布? |
|---|---|---|---|
