客户给的是章节目录（执行摘要 / 市场格局 / 能力矩阵 / 重点公司 / 定位与策略 / 动态指标）时，
按这张表落地。**先定两张核心决策图（竞合格局矩阵、差异化定位图），骨架就定了**，
其余图往里填，最后才写字 —— 先写文字再找图配，必然图文脱节。

## 全册三条版面约束

- **每图一句结论**：页底固定位置一根色条 + 一行字（y ≈ 6.4–6.5），不写大段。
- **配色一套定死**：国内 / 国外 / 直接竞品 / 合作伙伴 / 我方，五色，不随页换。
- **未实测项不许画成实测**：柱高是设计预算就在图上标红字「设计预算，未测」；
  某项指标从没测过时，副轴只放目标线、不放推演曲线 —— 画了曲线就等于宣称测过。

## 交付链

`data_*.py`（唯一数据源，出 JSON）→ `figs_*.py`（只从 JSON 读，图上不手抄数字）
→ `make_pptx_*.py`（页码自增）→ `soffice --headless --convert-to pdf` + `pdftoppm -r 110 -png`
→ 逐页 PNG 交视觉复检。

口径页（倒数第二页）必写：三条数据红线（估值标性质与截止日 / 出货标统计周期 / 未披露 ≠ 0）、
未披露名单、来源分级（官方 > 第三方 > 估计，标「估计」的不进商业材料）。
