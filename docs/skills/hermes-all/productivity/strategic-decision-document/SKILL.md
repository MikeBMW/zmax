# 量化决策文档：从分析到「先投什么」

分析层的活是「说清格局」，决策层的活是「给出顺序和判据」。用户要一次能拍板的文档时，
走这套：可复核的打分 → 可考核的 KPI → 决定资源顺序的敏感性 → 每家/每条动作都带触发条件。

## When to Use

- 「破局点在哪 / 要不要做这件事 / 资源先投哪一件 / 12 个月怎么算过」。
- 老板要一份能上会拍板的简报，而不是一份长报告。
- 竞品/ROI/路线图/性能分析已经做完，需要收口成决策。
- 需要一个以后每季度能重算、不是一次性结论的东西。

工具 API 层面（python-pptx 的读写编辑、模板、图表）看 `powerpoint`；
竞品格局的方法论（7 维 SRI、谁在绕过集成商）看 `competitor-positioning-sri`。
本技能只管「怎么把它变成决策」。

## 铁律

1. **分层诚实：事实 / 判断 / 推演，三层分开写，最后一页必带免责。**
   混淆三层的文档一被追问就废；分层之后反而更敢下结论。
2. **从未执行过的能力记「未测」，绝不估数。** 只有一个本体时，跨本体换型时间就是未测。
   编一个数会让整份文档作废；而「未测」常常就是最有价值的结论——它指出战略支点还空着。
3. **数字只有一个唯一依据。** 分数与派生指标写进 JSON，正文/表格图里的数字全部从 JSON 读。
   手抄必然漂移（图上 8.5、表里 8.4），且改分后无法一键重算。
   **计数同理，而且更容易漂**：标题里的「N 家」必须写 `len([r for r in rows if cond])`，
   不能手打 —— 同一句里「8 家」配 11 个名字、图例 3 个红格配文案「7 家未披露」，
   这类矛盾在评审现场等于自毁。交付闸要扫全文的「N 家 / N 条」并与 JSON 对数，不一致即失败。
   改数据脚本后必须重跑 数据 → 图 → 文档 → 闸 四步：只重建文档会印发旧 JSON 里的旧文案，
   成品看起来是新的、内容却是旧的。
4. **不要为了让结论好看去调权重。** 排名只动一位是正常结果；论据在**分布**，不在名次。
5. **每个动作必须带触发条件。** 只有动作没有「什么时候执行」的决策表，在评审会上等于没写。
6. **同一件事查到两个不同数字：两个都写，并标「合作前必须核实」。** 不许静默二选一 —— 选一个等于替用户做了
   他没授权的判断。外币口径（美股市值等）单独列，**不进人民币合计**，并写明「与一级市场估值不可比」。
7. **别人给的量级目标：先三口径对账，再照办或改写。** 老板/客户抛一个自上而下的数
   （「N 万人可替代 × 转化率 = X 台」），直接采信是附和，直接否掉是抬杠 —— 两者都会让整份文档失去分量。
   四步：复述算式 → 用实测换算因子修正一次（1 台顶几人，把「替代人数」与「台数」分开）→
   拿单品物理容量砸一次（装不下就要拆成「场景数 × 每场景台数」）→ 用行业份额校验上界（<1~2% 即不激进）。
   这一页紧跟执行摘要，标题就叫「口径对齐」；结论句必须落在真瓶颈上（通常是工艺包/交付速度，不是市场）。

## Procedure

### 1. 定标尺：先写维度定义表，再打分
每维一行：维度 / 量化指标（怎么算这个分）/ 数据来源 / 权重。
表里不出现形容词，只出现「可查的数」或「一次可复现的部署」。

### 2. 加一维：把「我方唯一领先的能力」单独立维
对手通吃的维度是**他们的尺子**，照它打分我方必然垫底。补上自己那一维并给最高单项权重。
平台型/集成型公司的这一维通常是「接口与封装」：跨本体标准化程度、换型工时、工艺包与判据资产、是否被第三方复用。

### 3. 两套权重并行，用 slope 图讲「换尺子」
一套是对手/行业现行口径，一套是含新维度的口径。两列排名连线，一眼看出换尺子的后果。
若某维第一名领先第二名数倍，那不是能力，是位置——这句话比名次有用。

### 4. 每维一张证据表
每格一行证据（出货台数、成功率、参数规模、开源仓库、客户数、BOM）。
我方那一行用系统唯一依据取证（配置文件、任务库、技能模板），不手抄印象。

### 5. KPI：定义 + 基线 + 目标 + 失败线 + 考核方式
- 定义必须能算（分子/分母都写出来）。
- 分母里的估算项单独标注「需现场核对」，不能当既定。
- 设**失败线**而不只设目标：没有失败线的指标不会有人负责。
- 考核方式写实物：视频、日志、验收记录、现场复现。

### 6. 敏感性分析定资源顺序（这一步决定文档有没有用）
把可控变量当旋钮，一次只动一个（其余固定），画单变量曲线看斜率。
结论常与直觉相反：**先投看起来最不性感的那件**。敢这么写，文档才叫决策而不是汇报。

### 7. 护城河用「复制成本不对称」论证，不用「我更强」
双组比较：我方补齐对手要多久（采购/接入/积累，月级）vs 对手补齐我方要多久
（与自身商业模式冲突，年级 + 自伤）。倍数差就是存在理由。标明是量级估计，不是承诺。

### 8. 决策矩阵 + 风险排序收口
- 每家/每条一行：定性 / 动作 / 触发条件 / 时间窗。动作必须是动词
  （采购、非独家接入、不合作、对标、观察），不能写「加强合作」。
- 策略每条后面跟一句可执行判据（覆盖率、条款覆盖率、成交结构占比），否则是口号。
- 风险按「会不会让战略失效」排序，第一条永远是「自己的差异化能力测不出来」。

## 从竞品分析到自主进化（feature 表桥）

竞品的模型名（VLA / 世界模型 / diffusion）**不是能力**，直接抄进 roadmap 毫无用处。
要让分析层真的驱动执行层（无论是 roadmap 验收还是自主进化器的 fitness），必须过一道翻译：

```
feature_id | 能力名称（禁算法词）| 完整定义（在 X 条件下做到 Y）| 可测指标+单位+阈值 | 证据强度
F-PREC-01  | 亚毫米盲插对位    | 工件被遮挡时凭力/位移反馈对位| 对位误差 ≤0.2mm   | 论文实测/官方演示/媒体报道
```

三条硬约束：
- 能力名称**不得出现算法词**（VLA、Diffusion、Transformer、世界模型）—— 只写「在什么条件下做到什么」。
  写算法的会退化成模型比大小，而模型比大小是本技能第一步就要避开的陷阱。
- 每条带**可测指标+单位+阈值**，否则无法进 fitness，也无法当验收项。
- 标**证据强度**（论文实测 > 官方演示 > 媒体报道），强度决定它能不能进「对手有我没有」的结论层。

这张表同时是三样东西：竞品差距清单 / roadmap 验收项 / 自主进化的基因与判据来源。
做平台型产品时，它比打分表更重要：打分表说「谁强」，feature 表说「下一步改什么」。

自主进化器要吃的不是公司名，而是这份 feature 表 + 本方可测基线。把进化对象从「超参/阈值」
扩到「能力组合」之前，先确认每一条 feature 都真有一个能算的分子/分母 —— 算不出来的不许进基因。

## 技术路线选型页：从「参数高低」改写成「构型与分工」

客户/评审最常追问的两页：「你们选六轴还是七轴」「你们是一个端到端大模型还是一堆小模型」。
这两问都**不能按参数高低答**，要按构型与职责分工答 —— 否则会被现场数据直接推翻。

### 本体：轴数不是精度
判据用公开标称重复定位精度，不用轴数：

| 形态 | 轴数 | 公开重复定位精度 | 代表 |
|---|---|---|---|
| 工业协作臂 | 6 | ±0.02mm | 遨博 i 系列、节卡 Zu 系列 |
| 仿人臂（轮式双臂） | 7 | ±0.05mm | 睿尔曼 RM75 |
| 仿人臂（轮式双臂） | 7 | ±0.1mm | 傅利叶 GRW |
| 人形 | 单臂 7 / 全身 22–29 | — | 智元 A2-W、银河 Galbot G1（双臂 7DOF×2）、星海图 R1（双七轴，全身 26 自由度） |

- 普通操作（上下料/搬运/分拣/锁付）⇒ **六轴协作优先**：精度够、成本约 1/3、集成商熟、备件通。
- 精密操作（插拔/装配/亚毫米对位）⇒ 要的不是第七根轴，是**构型刚度 + 力控 + 视觉闭环 + 标定一致性**；
  仿人臂为臂展与轻量化牺牲刚度，精度反而低一个量级（上表即证）。
- 七轴只在两种情形划算：工装把可达性卡死（只能从特定姿态切入），或力控需要姿态解耦。
- 口径句：**精度靠闭环，可达性靠自由度。**

### 模型：不是二选一，是分层

| 维度 | 端到端单个 VLA（含 VTLA） | 小模型组合（含仅感知/多模型编排） |
|---|---|---|
| 负责什么 | 听懂任务、语言→动作序列 | 把每个动作做到位、可被判据确认 |
| 精度上限 | 毫米级对位做不到（无可校验中间量） | 可控，每步可设判据/标定/留证 |
| 实时性 | 100ms～2s | 5～30ms，可跑工控机 |
| 可调试 | 黑箱 | 逐段可查、可单步、可回放 |
| 失效表现 | 整体失效，无降级路径 | 单步失败可拦停、可回退 |

- 判据句：**「毫米级对位 + 力控 + 可追溯」三者同时成立 ⇒ 执行环节必须是小模型**，
  大模型只能待在它上面的规划层（决定「做什么」），执行层决定「做到没做到」。
- 把大模型直接放进执行环节的方案，公开材料普遍拿不出毫米级装配的量化证据；「未给架构证据」照实标，不折算。

### 两条写作纪律
- **形态分段不能漏**：对比表要覆盖名单里每个形态分段（复合 AMR+协作臂 / 轮式双臂 / 双足人形）。
  只写两段就交付，用户第一句就是「轮式双臂呢」—— 而它往往是最贴近产线、数量最多的一段。
- **对外页不出现内部编号**：分层编号（L2/L3/L4/L5）与机型代号不进客户页，换成职能语言
  （见 `deliverable-doc-authoring` 铁律二）。这两页的素材通常直接来自内部讨论稿，最容易被污染。

## 矩阵图：先验算落点，再画

- **轴定义先验算。** 定完横纵轴，把每家代进去算落点，逐家核对「落点象限的角色名 == 这家的实际角色」。
  有一家落进矛盾的格子，**改轴定义，不改分数**。典型：纵轴用「自研闭环程度」，自研本体的整机厂
  会落进「模型伙伴」；换成「自研本体程度」后四格各装一类角色，右下角空出来只放我方 —— 空格本身就是结论。
- **标签朝「远离本组」的方向展开。** 朝圆心/朝组内会让 B 组的名字压进 A 组色块，读者把 B 组成员
  当成 A 组成员。这是**读法错误**：几何检查零告警、字也完整，但结论被读反了。
  锚点半径要让「标签内端」仍在本组边界之外。
- **四格标题放「离数据点最远的那半格」**：同格的点全在顶部就写底部，全在底部就写顶部；
  硬编码在某个角必然被压。
- **同构图别画两张一样的。** 摘要的全景图与决策矩阵天然同构，分工成「一张带气泡看规模（不标动作）、
  一张带动作字（买/谈/打/守）看怎么对待」，否则读者以为重复了两页。

## 验收（几何 + 眼睛，两者抓的缺陷不重叠）

1. **几何自检**：读回文档，逐 shape 断言 `left>=0, top>=0, left+w<=W, top+h<=H`；
   表格底边距页脚留 ≥0.2 英寸。全幅装饰条会合法贴边，按名字白名单排除，不要放宽阈值。
2. **独立目检**：把渲染出的逐页 PNG 交给子代理/视觉检查，按页给设计契约（这页该有什么），
   只让它报客观缺陷。几何查不出「标签压在散点上」「图被表格盖住」「字被色块边界裁」。
   没有视觉模型时按 `references/deck-authoring-pitfalls.md` §12 用 OCR + ASCII 降采样保障：
   数字、几何、算数仍以程序闸为准，OCR 只用来证「字真的渲出来了」。
3. **改一处要全量复检**：布局修正会把碰撞从一格推到隔壁一格，只看改过的那页会漏掉新伤。
4. 交付前把「改了什么」和「口径提醒」一起报给用户，不要把过程复述一遍。
   用户说了会自己删简压缩时，另给一句「**先保哪几页**」：决策页（矩阵、口径陷阱、结论层、打法）
   优先留，数据全量表与型号卡是可删的弹药。页数宁多勿少 —— 但每页必须能单独拿掉而不破上下文，
   不要写「如上页所述」这种跨页依赖。
5. **用户给了模板就以模板为版式唯一依据。** 模板 → `soffice --headless --convert-to pdf` → `pdftoppm -r 110`，
   量出尺寸、两三个品牌色、标题字号与位置、页脚页码格式，预先固定成生成脚本的 token，之后每页复用（改色只改一处）。
   不要「照感觉」配色 —— 用户拿模板来就是要那个版式，偏一点都能看出来。
6. **出血白名单按抗锯齿留余量，不按设计值裁。** 顶部 0.075in 装饰条在 110dpi 渲染后实际吃到 ~0.16in，
   按 0.11in 裁仍判 R0/T0 出血。裁切量取设计厚度 +0.1in，或对全幅装饰条按形状名白名单排除；
   封面也照样过检，别把第 1 页整页跳过 —— 跳过的那页往往带全幅底色块，刚好是唯一有真出血的。
7. **价格/分成对比页必须过一道算数自检。** 一列一个价格包，逐行相减 == 毛列池，池值 ÷3 ==
   「三方各得」单元格。表里的数字是拼进 pptx 的字符串，几何检查和目检都看不出「A 取 50 台档、C 取 20 台档」
   这种跨量档错行，只有逐行相加能拓住。

## 坑

- **图源比例是版式输入。** `bbox_inches="tight"` 加上远处标注会把横图变成竖图；
  contain-fit 之后只剩一半宽，下面的表格直接盖住它。要给已知框的图，锁 `set_ylim` 且别用 tight bbox。
  **图高不要自己算**：按宽度乘比例推出高度，必然与插图函数实际落盘的高度不一致，
  正文再预先固定一个 y 就压到图上（实测算出 4.83/3.61 英寸，实际 4.08）。用 `pic()` **返回的 h** 定后续文本起点。
- **散点标签不要手调偏移。** 挪开一个就压到下一个。锁完坐标轴后遍历候选偏移，
  同时判「标签撞标签」和「标签压散点」（点到矩形距离 < 标记半径），取第一个零冲突位。
  纯文本-文本检查会漏掉被点压住的标签。
- **脚本拼中文文案时别用 `%` 格式化。** 文案里本来就带 `25%`、`92%（11/12）`，
  `"...%d..." % args` 会把它们当格式符，抛 `unsupported format character`，而且一次只崩一处。
  混了百分号的段落一律用 f-string，或把字面 `%` 写成 `%%`。
- **中文字体要单独设 east-asian 字面**，只设 `font.name` 只管西文，中文会回落到主题字体。
- **我方低分要照实画**，并在图注点明这是刻意选择（例如「本体 1.0 = 不造本体」）；
  否则读者当成弱点，反而看不出「不追」就是策略。
- **合成指标（被绕过概率一类）标「情景模型 + 系数为设定值」**，只用于比较各旋钮的相对敏感度，
  不预测真实概率。可信度靠分层，不靠数字看起来专业。
- 交付形态固定为「主文档 + 打分 JSON + 重算脚本 + 逐页预览」，让人能改分重算，而不是只能接受结论。
  **但生成脚本只能存在交付目录这一份。** 从 scratch / 备份 / `/tmp` 任何地方 `cp` 覆盖它，会把交付目录里
  改了几十处的排版修正静默回退 —— 产物是对的、脚本是旧的，下次重跑全部白改。
  任何批量 `cp` 之后必须过一道**签名闸**：重新生成到临时路径，逐页逐 shape 比对（名称/坐标/尺寸/文本/表格列宽），
  要求**差异 0** 才允许相信「脚本能重现产物」。改一处文案也要重跑这道闸。
- **跨口径的计数不许搬运。** 图上「缺几个」必须由该图自己的矩阵数出来。工位口径（12 工位 × 5 类 = 60 格）
  与能力口径（35 条 feature）分母不同，「4 个工位全缺」不能写成「5 条全缺」。同页出现两个分母时
  必须在副标题里写清映射，否则一定被追问，而且会被直接当成「图坏了」。
- **派生指标比原始量更有判断力，但要标口径差。** 估值排名只回答「谁大」；估值 ÷ 出货（每台估值）
  才回答「市场为什么付钱」，能把「出货多 ≠ 估值高」从感觉变成可核对的事实。比值一旦跨
  「一级估值 / 二级市值」两类口径，必须标「含流动性溢价、不可精确横比」。
- **交付目录要自带能重跑的骸架。** 主文档 + 逐页 PNG + data.json + 生成脚本 + 模型脚本副本 +
  `README.md`（结论 / 量与假设分层 / [估] 项清单 / 重跑命令）+ `MANIFEST.md`（逐页目录 + 结构计数）+
  `sha256sums.txt`。只给一个 pptx 等于交一份不能再生的结论；数字一旦被追问口径，没有脚本就答不了。
- **卡片、结论条、页脚三者按坐标算一遍**：`卡 y + n × 步进` vs `结论 y` vs 页脚位置。
  算错的两种典型是卡片挤到结论条上（像被划了删除线）和结论压页脚 —— 这两类在小图上都看不出来。
- **表格行高是下限，不是定值。** 长单元格会把行撑开，`表头 + n × 行高` 算出来的表底是**低估**：
  预算到 6.7 英寸的表实际能压到 6.9，写在下面的注脚就印在最后一行字上。表格靠近版面预算时，
  注脚放**表格上方**（做成副标题），或留 ≥0.35 英寸余量。往下挪注脚挪两次都没用 ——
  因为表格根本不在算式算出的位置。
- **每个页面构造函数必须自己开页。** 拿「当前 slide」当参数、内部忘了 `new()` 的 helper，
  会把整页画到上一页身上：四页静默消失、不报错、不截断，只有输出页数不对。用**一个**
  `TOTAL` 常量、页脚读它、构建时断言 `len(slides) == TOTAL`（页脚预先固定 `n/32` 而实际 33 页，
  连封面上的「32 页」也得跟着改）。
- **关键词分类：先判否定词，再判细节，最后判大类。** `"未开源"` 里含 `"开源"`，
  子串匹配会把闭源公司染成「可自证」；`"VLA + World"` 先中 `"World"` 会把 VLA 系从 4 家
  吞到 1 家。分完类还要拿分布对一遍标题 —— **标题和数据打架时，错的是分类，不是标题**。
- **同一张图只能有一个单位，换算在数据层做完。** 值算的是「亿元/台」、标签格式写「万/台」，
  两个小数就被 `%.0f` 抹成「0 万/台」；拿美元数除人民币数，41 倍的差距会写成「5.8 倍」；
  港元值直接画进标「亿元人民币」的轴，同图三行三种折算。做法：绘图前全部换成轴单位，
  标签由换过的值 + 自己的单位词拼（`18.6 亿元/台`），故意不折的行明确写「未折算」；
  跨度超过 ~20 倍用对数轴，不要为了「看起来均匀」去截断。
- **卡片网格除不尽就填空格。** 5 张卡放进 2×3 会空出四分之一页，读者以为没排完。
  空格放一张「这一页怎么读」的小结卡（同规格、浅色底），既补版又给结论 ——
  比缩小卡片或改成 4 列（字挤到 6pt）都好。
