# 对外材料里的数字口径（估值、份额、开源、"未披露"）

交付件里的数字被打回，八成不是结论错，是**同一张表里混了不同口径**。写成文档前先把这四类分清。

## 1. 估值四口径

| 口径 | 长什么样 | 能不能横比 | 文档里怎么写 |
|---|---|---|---|
| 一级投后 | 私募轮次后的公司估值 | 只在邻近轮次间可比 | 「某轮投后 X 亿」 |
| 二级收盘市值 | 科创板/港股当日收盘 | 可横比，受流动性利动 | 「某日收盘 X 亿」 |
| IPO 发行估值 | 招股书发行价 × 股本 | 与投后不同体 | 「IPO 发行估值 X 亿」 |
| IPO 理论测算值 | 按拟募资规模反推 | **不可当估值用** | 「IPO 理论测算 X 亿（非投后）」 |

- 把 IPO 理论测算值写进「估值」列是最常见的错：同一家公司两个数能差 2.4 倍，
  实际投后 43 亿被写成 104 亿，一句追问就穿。
- 母公司内部的业务线（无独立估值）写「无独立估值（母公司市值 X）」，**不要反推一个数字充估值**。
- 港股/上市公司必须带取价日期；不带日期，同一家能在两份材料里差 76%。
- 对外只用这三种表述：某日收盘市值 / 某轮投后估值 / 招股书披露。禁「约」「级」这类模糊量词——
  「约 500 亿」「百亿级」不算口径。

## 2. 未披露 ≠ 0

- 原样保留「未公开 / 未明确 / 未披露」，不折算、不估算、不用同行均值代填。
- 统计句里**显式计数**：「15 家里 10 家有数据或模型合作痕迹，5 家写未公开」。
  分母摆在明面上，比模糊地说"普遍弱"有说服力，也方便对方自己判断可信度。

## 3. 派生指标必须带派生口径

- 单台估值 = 估值 ÷ 同期出货；不同年份的分子分母不可横比，只用来说明**倍数**，并在图下标注这一点。
- 市占率、订单额、出货量：写清统计周期（全年 / 上半年）与是否含出口、是否含非人形。
- 区间值（如 300–530 亿）要么给出取价时点，要么拆成两个数；不要把一个区间当点值参与计算。

## 4. 技术叙事类标签（开源、架构）

- **开源三档**：权重+代码+License 可下载（可自证）/ 只开数据集或推理脚本（半可证）/ 未明确或不开源。
  只开数据集**不算**开源模型；合作前要三样：权重链接、License、验证通过的 benchmark，缺两样以上当闭源处理。
- **架构标签只认公开论文/仓库/官方技术博客**。一句式的「VLA 大模型」「类脑大模型」归为
  **未给架构证据**，不进架构统计。
- 相近概念不合并计数：如「世界模型 × 动作生成」不等于 JEPA；「外挂触觉传感器」不等于「预训练内建触觉」。
  合并了，一查权重就露。

## 5. 交付件里的写法

- 同一张表口径不一时：分色 + 图例标注性质（上市 / 一级 / Pre-IPO），不要靠读者自己猜。
- 必带一页「口径与来源，以及本报告不能证明的事」——这页本身就是可信度证明。
- 图与正文必须同源：图里算出 10 家、正文写 9 家，交付即被打回。生成前把计数从数据文件重算一遍。
