# 竞品/合作格局分析：7 维打分 + 替代威胁指数 SRI

## When to Use
- 老倪问「谁是竞品谁是伙伴 / 这几家公司怎么看 / 商业模型的外部环境 / 我们的护城河」。
- 要判断「某厂商会不会绕过集成商直供工厂」，或要给融资/投标材料做竞争格局页。
- 已有定性判断，需要变成**可复核的打分 + 图 + 可季度跟踪的 KPI**。

## 铁律

1. **先用公开数据立外部环境，再打分**。市场份额、出货、融资、产线实测数都要带来源与时间；
   没有来源的行业感觉不写进结论层。
2. **打分必须可复核**：每个维度给出「凭什么给这个分」的一句话证据；权重写进脚本，争议改分重算，不做口头辩护。
3. **推演曲线必须标注「情景推演，非预测」**。图 2（SRI 随时间）、图 5（边际成本）都不是公开预测。
4. **合成指标用乘法不用加法**：任一环节为零，威胁即为零 —— 这正是集成商的生存空间，加法会掩盖它。
5. **对方自评低分不是安慰**：自有度低 ⇒ SRI 低，但那是「没有被替代」而不是「不可被替代」。

## 7 维指标（0–10，越高越强）

| 代码 | 维度 | 判据 |
|---|---|---|
| D | 工厂场景工艺深度 | 是否已有真实产线 + 精度指标（力控/亚毫米/良率），工艺 know-how、来料容差、验收口径 |
| S | 模型自研 | 是否有自研基座/世界模型（不是接第三方 API） |
| H | 本体自有 | 是否自研本体 |
| F | 数据闭环 | 真实产线数据获取与回流能力（含是否自建数据平台） |
| R | 交付复制半径 | 同方案复制到 N 个厂的能力、行业跨度 |
| C | 客户/存量入口 | 是否握有工厂客户与存量装机 |
| P | 解耦/可插拔 | 跨本体、跨模型兼容度（**反向指标**：越高越倾向合作而非替代） |

合成：
```
一体化自有度 = 0.40*S + 0.30*H + 0.30*F
直供复制力   = 0.60*R + 0.40*C
场景深度系数 = 0.5 + 0.5*D/10
解耦折减     = 1 - 0.40*P/10
SRI = (自有度/10) * (直供力/10) * 场景深度系数 * 解耦折减
```
SRI > 0.55 视为「已能绕开集成商」，0.3–0.55 为窗口期，<0.3 为可合作区。

## 六张图（脚本 competitive_figs.py，matplotlib）
1. 战略定位矩阵：x=一体化自有度，y=场景深度，气泡=规模，四象限标注谁在往「直供」走。
2. SRI 时间推演：logistic 上升曲线 + 临界线 0.55，直接给出**窗口期月数**。
3. 价值链：毛利率柱 + 相对市场规模折线（集成≈本体×3 是关键论据）。
4. 雷达图：我方 vs 四家，**必须露出自家短板**（S/H 低分照实画）。
5. 护城河曲线：复用型成本∝n^-0.45 vs 项目型 n^-0.08 —— 平台化是否真在发生。
6. 价值链结构图：box+箭头，画出「去集成商化」的红色旁路。

## 结论层的 5 条规律（可迁移，换项目复用）

1. **价值从本体迁到工艺数据**：本体毛利 18–25%，集成市场≈本体×3 且轻资产，数据服务 60%+，真机数据已被标价 500–1000 元/小时。
   ⇒ 模型与本体会商品化，不商品化的是「只在这条线/这批来料上成立的过程数据与判据」。
2. **替代需要三件事同时成立：自有模型 × 自有本体 × 单场景复制力**。缺一就必须找集成商。
   ⇒ 战略不是「变更强」，是**持续推高它们的缺项成本**（多品种小批量、来料差异大、验收苛刻）。
3. **集成商的生死线是解耦度**：绑定单一本体/模型 ⇒ 退化为代理，毛利被压到 10% 以内。
   可测：支持本体数 ≥2、模型数 ≥3、切换工时 <2 天。
4. **工艺数据有半衰期**：通用模型每 12–18 个月升一档，数据只能卖一次，**规则与认证可以反复收税**。
   可测：工艺规则化率（已写成可执行规则/验收判据的占比）。
5. **工厂付溢价买的是「敢停线」不是「更聪明」**：对手用长时直播+成功率做信任营销，说明缺的是可信度。
   可测：首次验收通过率、停线事故数、MTTR。

## 交付形态
- 目录：`~/zmax_data/deliverables/competitive_<日期>/`：6 张 PNG + `REPORT.md` + `report.html` + `scores.json` + `competitive_figs.py`。
- HTML 用自写 `md2html.py`（零依赖），**白底极简、表格可复制、图内嵌相对路径**；老倪会在手机/浏览器直接看。
- 报告必带「口径与免责」节：哪些是公开事实、哪些是本框架打分、哪些是推演。

## 坑（都踩过）
- **md2html 表格被切碎**：判分隔行写成 `set(row) <= set(":-")` 时，空行（空集）也是任何集合的子集 ⇒ 每张表最后一行被当新表头。
  定式：`re.fullmatch(r"\|[\s:\-|]+\|?", next_line) and "-" in next_line`。
- **matplotlib 中文豆腐块**：本机用 `Noto Sans CJK SC`（`fc-list :lang=zh` 核对），并设 `axes.unicode_minus=False`。
- **标注重叠/越界靠眼睛不可靠**：savefig 前用 `t.get_window_extent(renderer)` 两两 `overlaps()` + `ax.get_window_extent().contains()`
  程序化自检，打印「⚠ 重叠/越界」，改到零告警再交付。
- **气泡大小**用 `sqrt(规模)`，否则头部厂商把别家压成点。
- **HTML 验收**别只看文件存在：用浏览器打开后 JS 统计 `figures/img.naturalWidth/tables/overflow`（图必须 naturalWidth>0），
  并核对 figure 落在「图」那一节里。
- 图 5 的 `n^-0.45` 与 `n^-0.08` 是指数假设，报数时要说明「示意模型」，别让用户当实测。
