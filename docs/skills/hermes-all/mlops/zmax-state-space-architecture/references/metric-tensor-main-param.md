# 流形引擎主参数 M = 度量张量 g_ij(x) — 设计口径 · 实现 · 数值坑

老倪定调: 「流形引擎的主参数是一个张量 —— 随状态变化的度量张量 g_ij(x); 大小 n×n, 独立分量 n(n+1)/2;
联络/曲率/梯度/测地线都是从它导出的。」

## 1. 分解: 尺度 × 形状 (现场能标定的前提)

    g_ij(x) = M · G_ij(x),   det G = 1

- **M** = 度量的整体尺度 = 原来那个标量 M (范围 [0,8], 物理=等效惯量尺度)。各向同性时 Γ=0 且 g⁻¹F = F/M
  ⇒ **a = F/M 与旧语义逐字一致** (零回归)。
- **G** = 形状 (各向异性 + 随状态变化), 单位行列式把尺度全部交给 M, 二者可分辨。
- 关键性质: **克里斯托费尔符号对度量的整体尺度不变** ⇒ 曲率只由形状决定。所以现场顺序是
  **先标 M (单标量, 现成接口) → 再标形状**; 不分离则标 M 会连带改变弯曲, 无法标定。

## 2. 三种形状参数化

| mode | G | 独立参数 |
|---|---|---|
| `isotropic` | I | 0 (旧行为, Γ≡0, 直线) |
| `diag` | diag(w)/det(w)^{1/n} | n (每轴刚度) |
| `full` | L Lᵀ/det(·)^{2/n}, L 下三角 | n(n+1)/2 |

独立分量数: 3→6 · 6→21 · 16→136 · 43→946 (判据逐个数出来, 不靠嘴说)。
状态相关 (可选): `G(x) = G₀ + Σ_k x_k G_k` (gain; 缺省 0 = 常度量)。

## 3. 实现要点 (`src/lerobot/manifold/metric_field.py`)

- 梯度 ∇Φ = g⁻¹∂Φ 用 **Cholesky 求解**, 不显式求逆; Γ^k_ij = ½g^{kl}(∂_i g_jl + ∂_j g_il − ∂_l g_ij) 中心差分;
  R^i_jkl = ∂_kΓ^i_jl − ∂_lΓ^i_jk + Γ^i_kmΓ^m_jl − Γ^i_lmΓ^m_jk; 测地线 ẍ^k = −Γ^k_ij ẋ^i ẋ^j (+ g^{kl}F_l), 半步辛积分。
- n>8 的曲率**如实降级**为 3 维子空间抽样 (O(n⁵) 差分不假装算全张量), 返回体注明 `full_tensor: False`。
- 🔴 **写盘闸门必须查「归一化前」的原始形状**: `_normalize_det` 会把奇异/半正定矩阵夹成正定 ⇒ 归一化后永远
  "正定", 闸门形同不存在。改成查原始参数后实测 `diag=[1,1,−2]` 与奇异独立分量组合都被拒写。
- 🔴 **Riemann 差分的缓存维度是 `[m,k,i,j]`** (= ∂_m Γ^k_ij); 若开成 5 维再按 `[i,j,k,l]` 取, 会静默广播成数组,
  报 `setting an array element with a sequence` (症状离根因很远)。

## 4. 解析对照 (判据用: 2D **单位行列式**度量 g̃ = diag(a, 1/a), a = h^{-1/2})

    Γ¹₁₁ = −h'/(4h) · Γ²₁₂ = +h'/(4h) · Γ¹₂₂ = −h'/4 · 其余 = 0
    无迹关系: Γ¹₁₁ + Γ²₁₂ = 0

⚠️ 别拿**未归一化**度量 g=diag(1,h) 的解析式 (`Γ²₁₂ = h'/(2h)`) 去比归一化实现 —— 差正好 **2 倍**,
会误判成实现错。实测数值对上解析 1.8e-11。

## 5. 实测数值 (可复述)

| 情形 | 结果 |
|---|---|
| 各向同性 (G=I) | ‖Γ‖=0 · 测地线 vs 欧氏直线偏离 5.6e-17 · a=F/M 逐字一致 |
| 弯曲度量 (h=1+x², x¹=0.5, v=(0.7,0.7)) | 测地线 [2.5671,0.9545] vs 直线 [1.9,1.4] ⇒ 偏离 **0.80**, ‖Γ‖=0.427, ‖R‖=0.724 |
| 节点随状态度量 (gain[2][2][0]=0.6) | ‖Γ‖=0.52 · ‖R‖=0.18; 去掉 gain ⇒ 0 / 0 |

🔴 **各向异性但「常」的度量仍然走直线** (Γ=0, 数学上正确): 各向异性改的是**距离与梯度**, 不改测地线的直。
要看到测地线弯, 度量必须**随状态变** (gain ≠ 0)。别把「常各向异性下测地线不弯」当实现 bug 去改代码。

## 6. 判据结构 (`tools/verify_metric_main_param.py`, 可重跑)

①独立分量数 ②对称正定 + det G=1 ③**零回归**(Γ≡0 / 直线 / a=F/M) ④解析 Γ 张量逐分量对照
⑤常度量 ‖R‖=0 / 弯曲 ‖R‖>0 ⑥配置真源可读可写 + 非正定**拒写** ⑦真跑节点报出度量三行(dim/mode/独立分量 ·
正定/曲率 · 测地线 vs 直线)。实测 23/23 PASS。
