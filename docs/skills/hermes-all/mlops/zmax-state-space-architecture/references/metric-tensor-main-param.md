# 流形引擎主参数 M = 度量张量 g_ij(x) — 设计口径 · 实现 · 数值坑

老倪定调: 「流形引擎的主参数是一个张量 —— 随状态变化的度量张量 g_ij(x); 大小 n×n, 独立分量 n(n+1)/2;
联络/曲率/梯度/测地线都是从它导出的。」

## 1. 分解: 尺度 × 形状 (现场能标定的前提)

    g_ij(x) = M · G_ij(x),   det G = 1

- **M** = 度量的整体尺度 = 原来那个标量 M (范围 [0,8], 物理=等效惯量尺度)。各向同性时 Γ=0 且 g⁻¹F = F/M
  ⇒ **a = F/M 与旧语义逐字一致** (零回归)。
- **G** = 形状 (各向异性 + 随状态变化), 单位行列式把尺度全部交给 M, 二者可分辨。
- 关键性质: **克里斯托费尔符号对度量的整体尺度不变** ⇒ 曲率只由形状决定。所以现场顺序是
  **先标 M (单标量, 现成接口) → 再标形状**; 不分离则标 M 会连带改变弯曲, 无法标定。

## 2. 三种形状参数化

| mode | G | 独立参数 |
|---|---|---|
| `isotropic` | I | 0 (旧行为, Γ≡0, 直线) |
| `diag` | diag(w)/det(w)^{1/n} | n (每轴刚度) |
| `full` | L Lᵀ/det(·)^{2/n}, L 下三角 | n(n+1)/2 |

独立分量数: 3→6 · 6→21 · 16→136 · 43→946 (判据逐个数出来, 不靠嘴说)。
状态相关 (可选): `G(x) = G₀ + Σ_k x_k G_k` (gain; 缺省 0 = 常度量)。

## 3. 实现要点 (`src/lerobot/manifold/metric_field.py`)

- 梯度 ∇Φ = g⁻¹∂Φ 用 **Cholesky 求解**, 不显式求逆; Γ^k_ij = ½g^{kl}(∂_i g_jl + ∂_j g_il − ∂_l g_ij) 中心差分;
  R^i_jkl = ∂_kΓ^i_jl − ∂_lΓ^i_jk + Γ^i_kmΓ^m_jl − Γ^i_lmΓ^m_jk; 测地线 ẍ^k = −Γ^k_ij ẋ^i ẋ^j (+ g^{kl}F_l), 半步辛积分。
- n>8 的曲率**如实降级**为 3 维子空间抽样 (O(n⁵) 差分不假装算全张量), 返回体注明 `full_tensor: False`。
- 🔴 **写盘闸门必须查「归一化前」的原始形状**: `_normalize_det` 会把奇异/半正定矩阵夹成正定 ⇒ 归一化后永远
  "正定", 闸门形同不存在。改成查原始参数后实测 `diag=[1,1,−2]` 与奇异独立分量组合都被拒写。
- 🔴 **Riemann 差分的缓存维度是 `[m,k,i,j]`** (= ∂_m Γ^k_ij); 若开成 5 维再按 `[i,j,k,l]` 取, 会静默广播成数组,
  报 `setting an array element with a sequence` (症状离根因很远)。

## 4. 解析对照 (判据用: 2D **单位行列式**度量 g̃ = diag(a, 1/a), a = h^{-1/2})

    Γ¹₁₁ = −h'/(4h) · Γ²₁₂ = +h'/(4h) · Γ¹₂₂ = −h'/4 · 其余 = 0
    无迹关系: Γ¹₁₁ + Γ²₁₂ = 0

⚠️ 别拿**未归一化**度量 g=diag(1,h) 的解析式 (`Γ²₁₂ = h'/(2h)`) 去比归一化实现 —— 差正好 **2 倍**,
会误判成实现错。实测数值对上解析 1.8e-11。

## 5. 实测数值 (可复述)

| 情形 | 结果 |
|---|---|
| 各向同性 (G=I) | ‖Γ‖=0 · 测地线 vs 欧氏直线偏离 5.6e-17 · a=F/M 逐字一致 |
| 弯曲度量 (h=1+x², x¹=0.5, v=(0.7,0.7)) | 测地线 [2.5671,0.9545] vs 直线 [1.9,1.4] ⇒ 偏离 **0.80**, ‖Γ‖=0.427, ‖R‖=0.724 |
| 节点随状态度量 (gain[2][2][0]=0.6) | ‖Γ‖=0.52 · ‖R‖=0.18; 去掉 gain ⇒ 0 / 0 |

🔴 **各向异性但「常」的度量仍然走直线** (Γ=0, 数学上正确): 各向异性改的是**距离与梯度**, 不改测地线的直。
要看到测地线弯, 度量必须**随状态变** (gain ≠ 0)。别把「常各向异性下测地线不弯」当实现 bug 去改代码。

## 8. 健康度 H 与尺度分离 (分级口径)

    H = (1/κ)·λ_min = M · H̃,    H̃ = (1/κ)·λ̃_min      (λ̃ = 形状 G 的特征值, det G = 1)

| 配置 | M | κ | λ_min | H | **H̃** | 分级(按 H̃) |
|---|---|---|---|---|---|---|
| TASK-01-FW 插拔 (diag [10,10,50,10,10,10]) | 3.643 | 5.00 | 2.786 | 0.557 | **0.153** | 良好 |
| TASK-06-TRAY 摆盘 (isotropic) | 4.423 | 1.00 | 4.423 | 4.423 | **1.000** | 优秀 |

- 为什么: κ 与 anisotropy 对 `g → M·g` 不变, 只有 λ_min ∝ M ⇒ H 里混着"物理尺度"。
- 实现: `health.py::health_from_metric(g)` → HealthReport(H/κ/λmin/λmax/anisotropy/status/trend);
  阈值真源 `config/calib/zmax_health.json`(grades/trend_eps/kappa_warn); 分级 ≤0.01 危险 / ≤0.1 警告 / 0.5 良好 / >0.5 优秀。
- 对外: **H 与 H̃ 两个都给** —— H 反映工作量(带尺度), H̃ 无量纲、用于分级与阈值标定。

## 9. 闭环引擎 (`engine_loop.py`) + SIL 实测数字

## 10. 配置单 → M 映射 (`tools/config_to_M.py`)

| 规则 | 目标 | 依据 |
|---|---|---|
| R1 | dim | 工序含腕部姿态控制(旋转/翻转/定向/朝向) ⇒ 6; 否则 3 |
| R2 | mode | 平移↔姿态 / 图面↔深度耦合 ⇒ full; 同类轴公差比 ≥1.25 ⇒ diag; 否则 isotropic |
| R3 | diag/components | 各轴刚度 ∝ 1/公差(公差越小越"贵"), 归一 det G=1 |
| R4 | gain | 动态交互需现场辨识 ⇒ 系数**待标定**(缺省 0=常度量), 留有限差分实测入口 |
| R5 | scale M | M = 1 + (½m_eff v² + m_eff g h)/E_ref, clamp[0,8] (复用 `tools/master_param_m.py`, 别 fork) |

- 幂等以 **`m_audit_sha`** 为准; 文件 sha 每次都变(`_updated_at`)。
- 落地分工: 「主参数M节点」= 映射(写 `m_*` 参数 + 逐条打依据 + 写回回读) · 「流形引擎节点」= 用 M 算几何/健康/扭矩。
- 节点右键源码: 映射函数用节点新字段 `m_source/m_source_symbol` 声明; 若要让右键默认直达它, 需同步改原判据的期望值(不要静默改判据)。
- 回退: 真源被映射改写后, `git checkout`(若在库内) 或从画布 `_archive/` 备份恢复。

## 12. 写盘与判据的两个通用坑

- 🔴 **原子写(临时文件 + `os.replace`)会把软链顶成普通文件**: 画布真源是 `src/lerobot/engineering/flows/x.json`
  →(软链)→ `data/database/zmax/sources/canvas/x.json`; 对软链路径 rename 之后**软链消失、两份从此分叉**
  (实测 `git status` 报 typechange)。写前先 `os.path.realpath(p)`, 或直接写真实路径。
- 🔴 **判据别拿"前后时间戳不同"当"本次真跑过"**: 秒级时间戳在同一秒内的两次写会相等 ⇒ 假 FAIL。
  改成"时间戳落在最近 N 分钟内"或比较内容/计数。
