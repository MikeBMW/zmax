# 流形球面几何算子落地 (S^n · SU(2))

## 何时用
- 老倪给出一份几何/流形方案文档, 要落成真代码与判据。
- 要给 `manifold_engine` 的球面/sphere/su2 档加算子 (投影·度量·exp/log·测地线·平行移动·损失·正则)。
- 要验证“归一化球面/单位向量约束”在引擎里是否真成立。

## 1. 单真源, 引擎只复用不重写
公式全部写进 `src/lerobot/manifold/sphere.py` (numpy + 惰性 torch)。`manifold_engine.py` 只 import 复用 (顶部 `try: from lerobot.manifold import sphere as sphere_mod`), 引擎里**不再写第二份公式** —— 两处实现必然漂移。
未实现的档位必须 `raise ValueError` 明确报错, 不许静默返回假值 (仓库铁律)。

## 2. 改活代码前先冻结行为指纹 (零回归证据)
固定种子跑一遍「投影 / 距离 / 步进 / 测地线」→ `json.dumps(..., sort_keys=True)` → sha256 存成常量。
改完重跑对指纹: 相等 = 逐位零回归。把该 sha256 常量写进判据脚本, 成为可重复的门。
在役档位 (su2) 不要顺手改默认值; 切档要按门槛「有提升非仅不回退」先出同口径 A/B。

## 3. 判据按**真数学**写, 别照抄方案文字
方案文档里的几何描述常有想当然处, 判据要实测把它们挑出来:

- **温度参数**: `normalize(x/τ) ∥ normalize(x)` ⇒ 单向量投影方向对 τ **恒等** (差仅浮点舍入)。
  τ 的真效果在 `⟨p,q⟩/τ` 的 softmax 集中度 (或 vMF κ=1/τ²) 与「输出量级目标」上。判据用软分配熵随 τ 非降来核。
- **单射半径 π**: `log_p(exp_p(v)) = v` 只在 `‖v‖ ≤ π` 成立。越域 exp 折回并反向: `log∘exp(v) = −(2π−‖v‖)·û`, 且 exp 对 2π 严格周期。这是球的固有几何, 不是 bug。
- **双覆盖 (SU(2))**: ±U 是同一旋转。取 log 前先取同叶 (`⟨p,q⟩<0 ⇒ q=−q`); 对径输入满足 `log(−U,−V) = −log(U,V)` (模长相同), **不是**相等。
- **退化点别用 arccos+clamp**: `arccos(c.clamp(1e-6, 1-1e-6))` 在 c=1 给出 ~1.4e-3 的**假距离**。用稳定式 `θ = 2·arcsin(√((1−c)/2))`, c=1 ⇒ 逐位 0; vMF/FS 口径用 `arccos|c|` 的同一稳定式。
- **零向量 / 极小向量**: `eps` + `clamp_min`, 零向量给固定基向量并回 `zero=True` 标记, 不产 NaN; torch 侧反传也要核梯度有限。
- **平行移动真公式**: `v' = v + ⟨v,e⟩((c−1)e − s·p0)`, `c=⟨p0,p1⟩`, `s=√(1−c²)`, `e=(p1−c·p0)/s`。判据: 保长度 / 保内积 / `⟨v',p1⟩=0`。
- **切片/维度坑**: 造候选集时 `rng.normal(size=(k,dim))` 不是 `size=k` —— 后者在错误维度上做点积, 熵等统计看着合理但几何不对。
- **夹紧方向别搞反**: τ↑ ⇒ 集中度↓ ⇒ 熵↑ (非降), 单调性断言要写对。

## 4. 判据脚本形态
`tools/verify_*.py`: 每条约 `chk(id, claim, got, ok, expect, note)` → 落 `zmax_data/eval/*.json` (判据/实测/阈值/结论) → 非全 PASS 时 `exit 1`。
必带: ① 与引擎单真源一致 (逐项数值等价, 容差 1e-12, 说明浮点表达式顺序不同) ② 零回归指纹 ③ 非实现档报错 ④ **真数据段** (现场真源, 如 `zmax_data/ss_live/engine_latest*.json::z_latent`)。
最后跑一遍 `manifold_engine.py --selftest`, 确认所有 ready 档仍全通过。

## 6. 可视化 (S³ 立体投影球 · 侧栏面板)

老倪 (2026-10-16) 给了完整可视化方案 (状态点/切空间/测地线/度量场/轨迹/四面板共享时间轴),
要求「做到画布右侧的主参数 M 的侧面栏窗口」。落地要点 (踩过的坑):

1. **立体投影进 sphere.py, 不进 GUI** (单真源铁律): `stereographic_project(p, pole)` / `stereographic_inverse(x)`。
   北极→无穷远、南极→原点 ⇒ `x = p[:n]/(1−p[n])`; 极点必须 **clip 并标 `clipped=True`**, 返回 inf 会让
   GUI 画出垃圾、判据 NaN。**批量路径** (`p.ndim==2`) 必须有 —— 整条轨迹逐点调用会慢 100 倍, 而且
   两套实现必然漂移 (判据 A4 核「批量==逐点, 逐位相等」)。
2. **S³ 上画什么**: 单位球面 = 赤道 {p₄=0} 的像 (数学上精确, 不是装饰); 点在球内 ⇔ p₄>0, 球外 ⇔ p₄<0;
   大圆仍映为圆/直线 ✓; 状态点用**真源四元数**, 轨迹用**引擎同源映射**。
3. **状态序列从哪来**: `ss_traj_last.json` 的 `obs[i]` 是 43 维原始观察, 位姿四元数只是其中 `obs[3:7]`
   (任务里几乎不动 ⇒ 球上只有一个点)。**正解 = 引擎同源映射** `left_right/state_space/su2.py::encode_obs43(obs)`
   (ω = π·tanh(gain·‖e‖)·ê, e = 模块头−孔位 ⇒ e→0 ⇒ U→I)。实测 357 帧弧长 1.62 rad、首帧 φ=0.248→末帧 0,
   球上就是一条收敛曲线。**映射来源要写在页面上** (别让人以为是引擎缓存)。
4. **渲染走 QPainter 2.5D, 不开第二个 GL 控件** (画布主窗口已有 GL 上下文, 见 `qt-gl-rendering-pitfalls`):
   球面经纬线预渲染 QPixmap (一次) + 每帧只投影动态元素 (轨迹/测地线/状态点)。Qt API 尺寸参数一律 `int()`。
5. **切空间向量必须是真切向量**: 速度用 `log_map` 相邻帧差分 (传 `tangent_project` 收口, 判据核 ⟨v,p⟩=0);
   力 = M·a (M 取**标定真源**, 不是画布节点快照的默认值); 梯度 = `log_p(目标)` 方向。
   在切标架坐标里画 (先 `coeff = ⟨v, e_i⟩`, 再 3 维投影) —— 直接拿 R⁴ 向量去投影会 matmul 维度崩。
6. **度量椭球要分清作用空间**: 球面固有度规 (测地线=slerp ⇒ 圆度规) 是**各向同性** ⇒ 采样椭球全等 =
   「度量均匀」; 标定真源的 diag 度规 (dim=6 · 第 3 轴 50 vs 其余 10) 作用在**任务空间 (xyz+rpy)**,
   与 S³ 切空间不是同一空间 ⇒ 如实分开画 + 文字标清, 别拿 6 维度量去画球上的椭球。
7. **面板要自适应**: 侧栏窄了 2×2 自动转单列 (`resizeEvent` 里切 grid), 否则 4 个 min-size 面板挤成一团
   (老倪: 不许挤/不许截断)。底栏可见文字要短、完整路径挂 tooltip (界面字数有判据预算 400 字)。
8. 判据形态 `tools/verify_manifold_viz.py` (29 条): 几何 A (极点/往返/批量) · 真源 B (单位范数/同源映射/
   M 取标定真源/只读) · 几何量 C (distance 交叉核对/大圆弧长=θ/切空间性) · 控件 D (四面板/共享时间轴/
   空态诚实/窄栏转单列/帧龄标注) · 接线取证 E (M 页真接线/四面板像素证据/无重复公式)。
9. **取证坑 (真踩过)**: 用 X11 全屏抓图 (`grabWindow(0)`) 时, 只要控制台被终端/浏览器压住, 抓到的**就是压在上面那个窗口** ——
   会误判成"可视化没显示"。两条正确做法: ① 从控制台进程内 `QWidget.grab()` (与遮挡无关);
   ② 控制台自带命令通道 `echo mparam > /tmp/zmax_nav_cmd` (跳画布页 + 侧栏切主参数 M),
   `echo mparam_shot > /tmp/zmax_nav_cmd` (进程内抓 M 页 → `reports/ui_shots/live_mparam_sidebar.png`)。
   另: 控制台默认停在**配置中心页**, 画布页+右侧栏不在屏幕上 —— 没切页就说"看不到"是错的。
   还有 `lerobot` 被 fork 包遮蔽也会让面板退化成橙字空态 (见 `_load_by_path`)。
10. **文字不许越框** (老倪红线「不许挤/不许截断」, 2026-10-16 看截图抓到真缺陷): 面板里所有长串一律走
   `_fit(p, text, width)` = `QFontMetrics.elidedText(...)` —— **width 必须 `int()`**, 传 float 会抛异常被吞掉
   ⇒ 静默退回「不截断」, 文字就越框压到隔壁面板 (本文件踩过两次); 面板标题精简到 ≤16 字、完整说明挂 tooltip;
   页面无节点时四个表留一行「(无条目)+为什么」的**诚实占位**, 不留全空黑表; 控制台懒建画布时**别立刻断言
   「没有这个节点」** (1.2s×6 自动重试, 耗尽才报警)。判据 G1 (面板里 ≥28 字的串必须走 `_fit`)/
   G2 (把四面板各缩到 300×380 真渲染, 记录每次省略, 断言无一超宽)/G3 (不许全空表) 核这三件事。

11. **判据要能"量每一次绘制", 但不能给 C++ 类方法赋值**: 给 `QPainter.drawText` 直接赋值会让 PyQt
   **SIGABRT** (exit 134, 还会先报 `first argument of unbound method must have type 'QPainter'`)。
   正解: `class _Spy(QPainter): def drawText(self,*a,**kw): 记录; return QPainter.drawText(self,*a,**kw)`,
   然后临时把**模块全局** `manifold_viz.QPainter = _Spy` (面板里 `p = QPainter(self)` 用的是模块全局),
   finally 恢复。两个硬判据: ① 每次绘制的右边界 ≤ 面板宽 ② 同一面板里任意两次绘制的文字矩形不重叠
   (能抓出"两串字叠在同一行"——这种肉眼看得到、别的方式量不出来)。
12. **面板中部不要放浮标数值**: 切空间面板把 `v/F/∇d` 三个数值原本画在画面中部 (无宽度夹紧) ⇒ 窄侧栏下
   直接撞右边界被硬切。一律改成**底部固定行** (统一 13px 行距, 每行 `_fit`), 否则必然出现
   "两行同 y 叠死"(真踩过: 作用空间行与值行都在 h-12) 和"右侧半个字被切"。
13. **现场真源被别的进程每帧改写 ⇒ 像素类判据必须先冻源**: 控制台/引擎每帧写 `zmax_data/ss_live/*.json`,
   判据读的几何/角度一直在变 ⇒ 同一份代码时红时绿。做法: 把关键真源拷到 `tempfile.mkdtemp()`,
   视图支持 `root=` 参数指向冻结副本 (在役行为不变); 另外量像素前 **停掉 QTimer + phase 归零**。
   颜色掩码容区别卡太紧 (~320): 线压在金色引力井环上/浅角度抗锯齿会混色, 太紧会误判"线没了"。
   判定用"每条线 ≥3 个可用采样点 · 至少 1 处命中 · 单线 ≥50% · 全线平均 ≥85%"。

## 7. 球心引力架构视图 (天体 ↔ 画布真节点, 老倪 2026-10-16)

老倪口径: 「流形引擎是太阳, 前馈加速器是地球, DiT是火星, 接触流形是水星, 性能流形是木星,
原子技能是卫星, 用球体映射主要的节点。状态校正节点是月球。前馈加速器和状态校正器协同行进」
落在画布右侧「主参数 M」页 (`tools/gui/orbital_arch.py`, 与四面板同页用下拉切换)。

   里是: 太阳 `ss_mani_eng` · 水星 `ssmani_c` · 地球 `ssff` · 火星 `ssdec` · 木星 `ssmani_p` ·

   `skill_latest.json`/`skill_error.json`。**位置也是实测的映射** (水星←进度 · 地球←请求/v_cap · 火星←块步 λ ·

**老倪追加四条硬要求 (2026-10-16, 全部已落实并量化判据):**
1. **原子技能 = 绕地球的卫星群** —— 不能散落在太阳系外圈。做法: 卫星在**轨道平面内**绕地球
   (半径 `SAT_R=0.055R` 恒定, 相位 = 地球相位 + `2πi/N` ⇒ 与地球同向公转); 月球(状态校正器) 在**外一圈**
   (`MOON_R=0.085R`) 也绕地球 ⇒ 两者不重叠。判据在**平面坐标**里核 (`view.local_offsets()` 给卫星相对地球
   的 (dx,dy): 逐位 == SAT_R + 均布相位), 再用 `positions()` 核屏幕距离贴着地球 (与视角无关)。
2. **鼠标可操作**: 左键拖动 = 旋转 (偏航 + 俯仰, 限幅 ±1.15), 滚轮 = 缩放 (0.55~2.4), 双击 = 复位。
   必须是**真三维变换**: 轨道面倾角 → 绕 Z 偏航 → 绕 X 俯仰 → 正交投影 + 近大远小 (`1+0.10*z`),
   不是手画椭圆凑。判据派假 `QMouseEvent`/`wheelEvent` 断言状态变化 + `grab()` 图真变了 (像素差 >5000) + 限幅。
3. **连线 = 力的相互作用, 有作用才画**: 线集全部来自画布 `links` 真源 —— 所有「至少一端是主体」的真连线
   都画 (主体↔主体 + 主体↔体系外直接邻居画到外圈灰星点), 反向核 `want == got` (一条不漏一条不造);
   同一对节点的**重边去重** (画布里常有不同 label 的重边, 叠线会发灰发亮); 线义按**真源 label** 归类 (不猜)。
4. **连线人眼友好**: 每条线**两遍画** (外发光 `pen_w+3.6` alpha 22~46 + 实芯 2.2px alpha 210; 主体↔外部降到
   1.4px); 反馈类虚线用 `setDashOffset(phase)` **慢速流动** (每 tick +0.06), **禁止任何透明度脉冲/闪烁动画**。
   量化判据: ① 沿线 **7 处法向剖面取中位数** ≥2px (**别只量中点**: 单点会被“线恰压轨道虚线/光晕”
   打偏 ⇒ 同一份代码时红时绿, 判据不稳等于没判据; 色距阈值取 150~200) ② 连拍 3 帧线像素极差 <12% 且帧间
   变化占比 <0.35 且每帧 >300 px (不闪/不整条消失) ③ 生成帧条图给人眼复核。

**看图抓到的真缺陷 (2026-10-16 第二轮, 已修 + 已入判据)**:
- **标签必须「先避让再画」**: 每块用**带底圆角框**(深底 alpha≈205 + 细框) 才好读。坑: 块宽 228px 而径向
  偏移只有 ~47px ⇒ 块**反过来盖住自己的球**, 每个候选位置都被自身球的 keep-out 判"冲突", 退化成
  "重叠最小者"(跑到画布另一头/两块叠死)。铁律: 径向偏移 ≥ 块在该方向上的半宽 + 球半径 + 12;
  候选方向顺序 = 径向 → ±45° → ±90° → ±135° → 反向, 每方向 6px 步扫, 每个候选**先 clamp 进画布再判冲突**
  (先判后 clamp 会把"不冲突"的坐标变成冲突)。判据: `view.label_rects()` 两两不 `intersects()` +
  每块都在画布内 + 每块内亮像素 ≥30 (真的有字, 不是空框/被盖成背景色)。
- **漏键 ⇒ 线被静默跳过**: `positions()` 里少了 `"sun"` 键 ⇒ `_draw_forces` 取不到端点直接 `continue`
  ⇒ **太阳的连线一条都没画**, 而"线集清单相等"的判据还全绿。教训: 这类 bug 只能**像素级**抓 ——
  判据要对每条主体↔主体线沿线段取 21 个采样点(跳过落在文字块/球体里的点), 要求 ≥80% 在法向 ±3px 内
  命中该线色 (实测 9/9 · 10/10 · 7/7 · 8/8 · 6/6)。
- **不透明文字块会挡线**: 画完文字块后, 对主体↔主体线再以极低透明度 (α≈70) 透描一遍 ——
  被文字块压住的那段也不断线 (老倪: 连线不要很快消失/平顺柔和)。

**取证坑 (真踩过)**: 量线宽/帧差前**必须 `reset_view()`** —— 前一段判据把视角拖到极端 (pitch=-1.15,
zoom=0.55) 会把线中点挪出画布, 量出 0 像素会误判「线太细」。**性能坑**: QImage 取像素别用 `img.pixel(x,y)`
双层循环 (68 万像素 ≈ 秒级), 用 `constBits()+np.frombuffer().reshape(h,w,4)[:,:,2::-1]` (快两个数量级)。

**43D obs 通道划分** (重建手/光模块头/孔位必需, 见 `su2.obs43_geometry`):
`[0:3]手位置 [3]夹爪 [4:7]光模块位置 [7:11]光模块四元数 [11:18]pad×7 [18:36]上一帧 [36:39]孔位 [39:43]触觉`;
光模块头 = `obs[4:7] + (0,0,0.030)`。判据 C5 就是核这个重建与真函数逐位相等。

**画球体** (QPainter, 不用 GL): `QRadialGradient(光从左上)` + 高光点 + 描边 = 真球感;
判据从像素里量 (球色像素数 · 球内亮度落差 · 轨道像素跨行跨列 · **月球相位从像素质心反解**),
不靠「公式反推公式」自证。孤立的球心用不上——月球的相位锁定是**用椭圆轨道基反解 (角, 半径)** 验证的。

## 5. 训练侧与现场口径要对齐
