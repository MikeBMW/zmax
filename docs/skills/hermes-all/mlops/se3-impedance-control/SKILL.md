# SE(3) 几何阻抗控制 (被动 · 体坐标 · 精细装配)

把位姿误差变成力矩/速度指令, 且**接触时不震**。核心是把误差、刚度、阻尼全部定义在
体坐标系的切空间: 势能就是黎曼测地线代价, 刚体主轴固定在工具本体 ⇒ 插销时"侧向软、轴向硬",
末端怎么转主轴都跟着工具走 (欧氏阻抗做不到: 一转就跟着世界系错位)。

```
V(g) = ½·ξ_eᵀ·K·ξ_e ,  ξ_e = log(g⁻¹·g_d)
u    = +K·ξ_e − B·ξ + F_d          # 体坐标力扭, 6 维 [力; 力矩]
τ    = J_bᵀ·u                     # 体雅可比, 不是空间雅可比
被动性: V̇ = −ξ_eᵀ·B·ξ_e ≤ 0   (K,B 正定 ⇒ LaSalle ⇒ g→g_d)
```

## When to Use
- 要把相对位姿误差转成关节力矩/体 twist, 且要求与环境接触时**不注能量**。
- 精细装配插入 (销钉 / 连接器 / 光模块): 轴向硬维持插入压力, 侧向软顺应间隙。
- 用户给一份 SE(3) 阻抗 / IDA-PBC / 几何控制方案文档, 要落成可跑代码 + 判据。
- 要给状态空间/世界模型的"引力"换后端 —— 旧势只有方向、没有轴向/侧向区分。
- 现象侧信号: 插销时侧向顶死; 一改末端姿态刚度主轴就错位; 硬接触抖动。

前置: SE(3) exp/log 算子归 `lie_intent`; 球面算子归 `manifold-sphere-geometry`;
潜空间上的球面势归 `manifold-potential-field-design`; **本技能只管物理控制后端**。

## 🔴 1. 先对齐分量顺序 —— 这是最贵的坑

`lie_intent.se3_log` 返回 **`[ω; v]` (旋转在前)**, 而控制方案几乎都写 **`[ρ; ω]` (平移在前)**。

```python
def _xi_lie_to_std(x):        # [ω;v] → [ρ;ω]
    x = np.asarray(x, float).ravel()
    return np.concatenate([x[3:6], x[0:3]])
```

顺序搞反的后果不是报错, 是 `K = diag[k_lat,k_lat,k_ax, k_rot_lat,k_rot_lat,k_rot_ax]` 作用到**错的轴**上
⇒ "侧向柔顺、轴向硬" 静默变成 "侧向硬、轴向软", 插销直接顶死, 而代码一行没错。

**落笔前先量一次**: 纯平移 `x=0.5` 过 `se3_log` 应该给 `[0,0,0, 0.5,0,0]`; 纯绕 z 转 30° 应该给
`[0,0,0.5236, 0,0,0]`。数字对上了再写控制器。写完自检要有"往返转换一致"一条。

## 🔴 2. Adjoint 分块方向: Pinocchio 与 `[ρ;ω]` 相反

```python
# 按 [ρ;ω] 分块 (本仓约定)
Ad[0:3,0:3] = R ;  Ad[0:3,3:6] = skew(p) @ R ;  Ad[3:6,3:6] = R
```

Pinocchio 的 `pin.SE3.adjoint` 是 `[ω;v]` 分块 (两个角块位置相反)。按错的分块手写, 伴随校正整体错位。
自检两条就够: ①`Ad_g·Ad_{g⁻¹} = I` (1e-12 级) ②纯平移时 `Ad = [[I, skew(p)],[0, I]]`。

## 🔴 3. 误差 twist 的符号 —— 方案文档常常写反

`ξ_e = log(g⁻¹·g_d)` 是 **「从当前指向目标」** 的体位移: 目标在 +z 时 `ξ_e.ρ_z = +0.02`。
要让 g 追上 g_d, 体速度必须沿 **`+ξ_e`**。

```python
u_imp = +K @ xi_e − B @ (xi − xi_d_body)     # ✅ 弹簧拉向目标
u_imp = −K @ xi_e − B @ (xi − xi_d_body)     # ❌ 稳定地把点推离目标
```

文档里 `u = −K·ξ_e − B·ξ` 是**最常见的一处笔误** (作者心里把 `g̃` 当成了 `g_d⁻¹g`)。
实证: 按文档符号闭环, `V` 从 0.08 炸到 **1.8e7**, 残余 **299 米**; 改 `+K·ξ_e` 后
`V` 单调降到 **2.4e-28**, 残余 **0.000000 m**。被动性照样成立 —— 闭环稳态 `ξ → K⁻¹Bξ_e`,
代入 `V̇ = ξ_eᵀK(−ξ) = −ξ_eᵀBξ_e ≤ 0`。

**一步符号验收(比跑全程快得多)**: 目标在 +z ⇒ `u_z` 必须 `> 0`; 目标在 +x ⇒ `u_x > 0`。
先把这一条测通, 再搭闭环。反了以后看 V 曲线只会以为是增益调坏了。

## 🔴 4. `u` 的量纲是**力**, 不是速度

```python
a = u / m;  v = v + a*dt;  g_cur = g_cur @ se3_exp(_xi_std_to_lie(v*dt))    # ✅
g_cur = g_cur @ se3_exp(_xi_std_to_lie(u*dt))                              # ❌ 把 N 当 m/s
```

直接拿 `u` 当速度积分: `K=400 N/m × 0.02 m = 8 N` 被当成 8 m/s ⇒ 一步就飞出去
(实测 V → 1.8e7, 残余 299 m)。闭环自检必须带质量 `m=1kg` 走 `m·v̇ = u`。

## 🔴 5. SE(3) 势的梯度流不能用球面度规

`ManifoldEngine(manifold_type="sphere")` 的 `tangent_gradient` 做**切球投影**, 会去掉径向分量;
而**纯平移在球面上正是径向** ⇒ 梯度流推不动平移, 实测卡在 **1.96 mm** 一动不动。
SE(3) 势的梯度本来就活在 R⁶ 切空间, 换 `manifold_type="euclidean"` 后同一套判据降到 **0.1 mm**。

配套的第二个坑: **`engine.step()` 内部调 `gradient_flow()` 时并不带 `potential_fn`**,
它用的是引擎自带的 `½‖p−goal‖²`。要验自己的势, 必须显式
`engine.gradient_flow(potential_fn=prov.phi_fn(), p=cur)`。
不显式传会发现"梯度恒 0、只跑 1 步就收敛", 误判成势写得不对。

## 6. 刚度 / 阻尼设计

```
K = diag[k_lat, k_lat, k_ax,  k_rot_lat, k_rot_lat, k_rot_ax]   # 顺序 [ρ;ω], z = 插入轴
k_lat=80  k_ax=400  k_rot_lat=2  k_rot_ax=10   [N/m, Nm/rad]
B = α·K        α≈0.15 (比例阻尼)
u_max = [20,20,50, 5,5,3]     # 逐轴限幅 = 硬件保护
```

**整定顺序固定, 不许跳**: ① `K=B=0` 只发 `F_d` 前馈, 看力读数稳不稳 ② 只调 `α` 到不震
③ 从小到大抬 `k_ax`, `k_lat` 全程保持小 ④ 最后才开 `Kf`。
**绝不把 K 和 B 同时放大** —— 极易激发机械共振。
`u_max` 是硬件保护参数, 不参与在线调整也不许进进化搜索空间。

## 7. 力项语义 (判据要按 Kf 是否为零分开写)

```
F_err   = F_m − F_d
 u_force = F_d − Kf·F_err
```

`Kf = 0` 时 `u_force ≡ F_d`, **不随测量力变化**。所以"力不足就该补力"这条判据在 `Kf=0` 时
**必然失败** —— 那是判据口径错, 不是实现错。两种口径分开断言:
`Kf=0` ⇒ 输出恒等于 `F_d`; `kf_z=0.5` 且力差 6N ⇒ 输出 = `F_d − 3N`。

## 8. 判据 (全过才算实现正确)

| # | 判据 | 通过条件 |
|---|---|---|
| ① | 分量转换 | `[ω;v]→[ρ;ω]` 值正确且往返一致 |
| ② | 伴随 | `Ad_g·Ad_{g⁻¹}=I` ≤1e-12; 纯平移分块正确 |
| ③ | 误差/势 | `g=g_d`⇒`ξ_e=0,V=0`; 纯 z 偏 1cm⇒`ρ_z=0.01,ω=0`; `V=½k_ax·1e-4` |
| ④ | **被动性** | 500 个随机 `ξ_e` 全部 `V̇≤0`; **且负刚度必须能测出 `V̇>0`** |
| ⑤ | 闭环收敛 | `V` 单调不增→~1e-28; 残余 →0; `V̇` 全程 ≤0 |
| ⑥ | 各向异性 | 同 2cm 误差 轴向力 > 侧向×2; **且方向朝目标** |
| ⑦ | 饱和 | 超限被标记 `saturated`, 输出在限幅内 |
| ⑧ | 力反馈 | 按 `Kf=0` / `Kf≠0` 两种口径分别断言 |
| ⑨ | 关节映射 | `τ` 维数=关节数, `τ=Jᵀu` 逐位 |

判据 ④ 里那条**反向验证**(构造负刚度让 `V̇>0`) 不能省: 只测"随机采样全 ≤0"是恒真断言式自证,
加上反向例子才能证明这个检查真的在检查东西。

## 9. 体雅可比, 不是空间雅可比

控制律所有量都在体坐标 ⇒ 必须 `J_b` (`getJacobianBody`)。用空间雅可比 `J_s` 直接映射,
公式全部失效、稳定性论证不成立。这条写进 docstring, 因为它不报错, 只是"抖"/"不收敛"。

## 10. log 映射的奇异

`g̃` 旋转接近 180° 时 `log6` 不唯一。精细装配全是微小相对姿态, 天然避开;
做大角度跟踪必须加角度分支切换, 否则过 180° 会跳。

## 11. 参数自主进化: 被动性是**硬闸**, 不是加权项

- 进化对象: `k_lat / k_ax / k_rot_* / α / kf_z`。`u_max` **不进化** (硬件保护)。
- **`V̇ > 0` 出现一次 ⇒ 整代判废**。安全判据做成加权项会被收敛高分掩盖 —— 
  加权是性能判据的形状, 被动性是安全性判据的形状, 两者不能混。
- 适应度分量**先归一化再加固定权重**: `ρ_end/1e-3`、`超调/5e-4`、`|u|峰/u_max`。
- **权重绝不许参与变异** —— 让权重一起变异时分数会靠调权重虚涨, 模型本身没变好。
- 台账同时记原始分量 (ρ_end mm / 超调 mm / |u| 峰 N) 和归一化分量, 便于归因。

端侧部署: Intel 上**系统 `python3` 没有 torch**, 有 XPU torch 的是 `~/train_venv/bin/python`,
service 的 `ExecStart` 与 ad-hoc ssh 命令都要指它。纯 numpy 的闭环仿真不需要 GPU,
冷却时间给足 (600s) 别和训练抢资源。

## 12. 交付口径 (诚实边界)

- **仿真闭环 ≠ 装配精度**。"ρ_end=0.43mm" 是 m=1kg 质量-弹簧-阻尼仿真值, 不是真机重复定位精度。
- 没有真机 `J_b` 就是**没跑过真机**; `τ=J_bᵀu` 只有单测 ⇒ 执行层未接通, 要接臂 SDK 桥才算。
- 汇报分三层, 缺哪层说缺哪层: ①几何/被动性可证 ②是否接进下发链 ③任务级精度/成功率。
- 用户方案文档里的公式**不是免检的** —— 符号、分量顺序、量纲三处都要自己验一遍再实现,
  并且把发现的偏差写进代码注释 (为什么与原文不同), 否则下一个人会"修回去"。
