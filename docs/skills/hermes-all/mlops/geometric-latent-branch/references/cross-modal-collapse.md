# 跨模态嵌入塌缩: 判据、阈值与"稳态 vs 训练不足"的区分

适用于"两个模态各自编码后要在联合空间对齐"的场合 (双向跨模态 JEPA、对比式几何分支、
图像-位姿联合嵌入)。塌缩的定义: **编码器还能正常跑、loss 还在降, 但嵌入已经不带信息**
(所有样本映射到近似同一点或同一个低维子空间)。

## 1. 为什么 `(1−cos).mean()` 必然塌缩

设两侧都已 L2 归一化, 对齐损失 `L = mean(1 − e_v·e_g)`。当所有样本被映射到球面同一点时
e_v·e_g ≡ 1 ⇒ `L = 0`, 这是**全局最优**且极易到达。梯度上它只要求"样本之间不要有差异",
于是编码器的最省力解就是把方差全扔掉。

换成 InfoNCE(batch 内其他样本做负样本):

```python
S      = e_vis @ e_geo.T / tau            # (B,B)
labels = torch.arange(B)
L_align = 0.5 * (CE(S, labels) + CE(S.T, labels))
```

塌缩时 `S` 全 1 ⇒ `CE = log B`(**最大**, 不是最小) ⇒ 梯度把样本推开。这是 CLIP 的结构,
也是唯一能自然免疫塌缩的写法。别用 `1−cos` 图省事。

## 2. 防塌缩正则的权重必须和 CE 同量级

CE 的量级是 `log B`(B=64 ⇒ 4.16; B=32 ⇒ 3.47)。方差/协方差正则写成权重 1.0 时会被完全压过,
实测照样塌缩。给 **3.0**。

```python
l_var = relu(gamma - std(e, dim=0)).mean()          # 每维 std 不低于 gamma
l_cov = offdiag(cov(e)).pow(2).sum() / d            # 维度之间不许冗余
loss  = lam_i2g*l_i2g + lam_g2i*l_g2i + lam_align*l_align + 3.0*(l_var + l_cov)
```

## 3. 判据: 有效秩, 不是每维 std

**VICReg 的 `γ=1.0` 不可移植。** 它是对 2096 维嵌入调出来的; 维度越少, 信息越集中在少数维度,
每维 std 天然越小。实测 16 维嵌入训练后 `std_min = 0.22~0.23`, 而 120 步与 350 步几乎没有差别
(0.2166 → 0.2263) —— 说明 0.22 就是这套正则下的**稳态**, 不是"还没训够"。
拿 `γ*0.5 = 0.25` 去卡它, 每代都会误判成塌缩。

有效秩对维度数不敏感: `exp(归一化奇异值的熵)`, 塌缩 ⇒ 1, 满秩 ⇒ d。

```python
def effective_rank(e):
    a = np.asarray(e, float)
    a = a - a.mean(axis=0, keepdims=True)
    s = np.linalg.svd(a, compute_uv=False)
    s = s[s > 1e-12]
    if s.size == 0:
        return 0.0
    p = s / s.sum()
    return float(np.exp(-(p * np.log(p)).sum()))
```

三重判据(任何一条命中即判塌):

| # | 判据 | 阈值 | 防的是 |
|---|---|---|---|
| ① | `std_min` | < 0.10 | 常数输出(绝对底线, 不随维度缩放) |
| ② | `effective_rank` | < `max(2, 0.15·d)` | 信息退化成 1~2 维复读 |
| ③ | 协方差非对角均值 | > 0.6 | 维度之间互相复制(秩可能看着不低) |

② 才是主判据, ① 只是兜底 —— ① 单用会把"高维但低方差"和"真塌缩"混为一谈。

## 4. 三条判据的自检: 必须能判"假嵌入"

只用真实训练后的嵌入测是自证。要造三种合成输入确认检查本身有效:

| 造法 | 期望 | 实测 |
|---|---|---|
| 常数嵌入 (全是同一个向量) | 判塌 | `std_min = 0.0000`, 命中 ① |
| 冗余嵌入 (同一向量复制到所有维) | 判塌 | `eff_rank = 1.00`, 命中 ② |
| 独立高斯随机 | 放过 | `rank 14.9 / 15.0`, 放过 |

"常数"和"冗余"两条都要有: 前者测 ①, 后者测 ② 且 `std` 可能并不小(复制后每维方差照样大)。
只写常数一条, ② 就算写错了也测不出来。

## 5. 对齐质量的判据: 对角优势, 不是 cos 均值

InfoNCE 下 `cos` 均值不再有意义(塌缩时它也能到 1)。要看**正样本对相似度比负样本高多少**:

```python
pos = S.diagonal().mean()
neg = S[~torch.eye(B, dtype=torch.bool)].mean()
adv = pos - neg        # 健康值 > 0.2, 实测好模型 0.91 (pos 0.906 / neg −0.006)
```

`adv` 高而 `eff_rank` 也高 ⇒ 真的学到了跨模态对应, 不是塌缩。两个数必须一起报。

## 6. 进化里的落法

- 塌缩 **⇒ 整代作废**, 不计分不扣分(与被动性硬闸同形状, 理由不同: 这条是统计退化)。
- 三个性能分量各自除参考尺度再乘**固定**权重: `−img2geo/1e-3`、`adv/0.5`、`−0.3·geo2img/1e-2`。
- 搜索空间只放结构/训练超参 (`d_e` / `tau` / `lam_align` / `lr` / `steps` / `batch`), 权重不动。
- 台账同时记原始分量和归一化分量, 以及 `eff_rank` / `std_min` / `pos` / `neg`, 便于归因。

## 7. 数据侧: 两个模态之间必须有可学结构

评估用的合成数据必须是"A 真能决定 B 的一部分"(如 `ξ = z·W + 噪声`)。两侧完全独立时
任何模型都学不到东西, 进化出来的只是"哪个超参更会拟合噪声", 分数没有意义。
这一步要在造数据时就定死, 不能等到看分数才怀疑。
