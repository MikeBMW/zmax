# 度规势梯度流: 实测数据与失败记录

背景: 球面状态空间上, `goal_point` 固定的梯度流。基线用欧氏势 `½‖p−goal‖²` + 切空间投影;
要加"度规约束"(Fubini–Study 距离当势)。最初一次实测是**度规把方向弄坏了**(cos 0.8010→0.3692),
所以"度规无效"的结论被写进了报告 —— 实际上是**势函数选错**, 不是度规错。

---

## 1. c 的分布: 为什么必须同时避开两端

`c = ⟨p̂, ĝ⟩` 在真实轨迹(`optical_insert_v6_disturb`, 87,150 帧)上的分布:

| c 区间 | 占比 | 危险 |
|---|---|---|
| `[0.95, 1.00]` | **11.3%** | arccos 导数 `−1/√(1−c²)` 发散 |
| `[0.70, 0.95)` | 24.0% | 安全 |
| `[0.35, 0.70)` | 26.7% | 安全 |
| `[0.10, 0.35)` | 32.7% | 绝对值尖点附近 |
| `[0.00, 0.10)` | **5.3%** | `|·|` 在 c=0 不可导 |

- **62%** 的样本完全走度规势、**81.3%** 实际走度规路径 —— 不是"偶尔碰到"的边界情况。
- `‖∇Φ‖` 实测能塌到 **5.9e-05**, 此时方向完全由浮点噪声决定。

## 2. 两次错误的"半球翻转"——记下来防止再试

两者动机都是"`_dot<0` 时梯度整体反向", 现象是真的(实测 k=30 约 9%、k=150 约 **34%** 的样本
`g_eu` 与 `g_met` 夹角 180°), 但修法都是错的:

### 错法 A: 两路梯度都翻 goal
```python
if np.dot(p, goal) < 0: goal = -goal      # 然后 g_eu / g_met 都用这个 goal
g_eu  = tangent_gradient(euclid_phi_using_flipped, p)
```
结果 cos **0.4564 → 0.3238**(更差)。因为欧氏分量也被翻到 `−goal` 去了, 而基线臂 A
用的是原 goal ⇒ 两臂比较的已经不是同一个方向。

### 错法 B: 只翻度规那一路
```python
goal_met = -goal0 if np.dot(p, goal0) < 0 else goal0
g_eu  = tangent_gradient(..., goal0)        # 不翻
g_met = tangent_gradient(..., goal_met)     # 翻
```
结果 cos **0.4564** —— 与"完全不翻"**精确相同**。原因: `½(1−c²)` 里 `c` 取了绝对值,
`c²` 把符号平方掉了 ⇒ **势函数对 `±goal` 逐位相同**, 翻转是空操作。

### 分桶诊断才看得见真相
按 `⟨p,goal⟩` 符号分两组量 D 臂的 cos:

| 分组 | n | B(度规) | D(两者) |
|---|---|---|---|
| `⟨p,goal⟩ ≥ 0` | 99 | 0.9767 | **1.0000** |
| `⟨p,goal⟩ < 0` | 51 | **−0.9435** | **−1.0000** |

负号组是**完美反向**(−1.0000), 不是"随机变差"—— 这种"分组后干净反向"的形状才是
"方向整体翻转"的诊断指纹, 比总均值含糊的 0.45 有用得多。

### 正解
```python
def phi(q, goal):
    return 0.5 * (1.0 - float(np.dot(unit(q), unit(goal))))   # 带符号, 无绝对值
```
梯度 ∝ `−(ĝ − ⟨p̂,ĝ⟩ p̂)`, 无论 `⟨p,goal⟩` 正负都指向 goal。**不需要任何翻转代码**。

## 3. 最终 A/B 结果

k=150 / eps=150 / 89 帧真轨迹:

| 臂 | 原版 cos | 修后 cos | 法向泄漏 | 收敛拍 | 单调率 |
|---|---|---|---|---|---|
| A 基线 | 0.8010 | 0.8010 | 0.5161 | 38.08 | 1.000 |
| B +度规势 | 0.3692 | **0.9560** | 0.1804 | 38.08 | 1.000 |
| C +切投影 | 1.0000 | 1.0000 | 0.0000 | 38.09 | 1.000 |
| D 两者都开 | 0.4000 | **1.0000** | **0.0000** | 38.09 | 1.000 |

k=30 口径同样 6/6 (A 0.9651 → B 0.9815 → D 1.0000); 几何自检 11/11 全 PASS,
零回归项偏差 `0.00e+00`。

**关键证据: 在算法层从"证伪"变"成立", 而收敛拍数与单调率一点没让步** —— 这才是"改写没带来副作用"的正向证据。

## 4. 实现细节备忘

- 权重 `w` 用 smoothstep 从 `c∈[C_LO, C_HI]` 过渡, 常量 `C_LO=0.10 / C_HI=0.35 / W_MAX=0.85`
  全部可用环境变量覆盖(`ZMAX_PHI_W_MAX` 等), 便于不改代码做扫描。
- `gradient_flow` 的 `phi` 返回值与梯度必须来自**同一函数**; 旧的分支式 `phi` 定义要**删掉**,
  不要留着"以后可能用" —— 留着就会有人接错。
- 删掉旧分支后, 原先针对旧 `phi` 写的那批判据会集体变红; 不是功能回退, 是判据口径过时。
  改判据时把它改成验**执行量**。

---

## 5. 这类改动的止损点

同一份代码改了三轮才中(空操作翻转 → 反向翻转 → 带符号势), 每轮都跑一次完整 A/B。
教训: **当两次"补救"给出完全相同或更差的数值时, 停下来做分桶诊断, 别再试第三个翻转。**
分桶(按夹角/符号/距离区间分组看指标)几乎总能在一个回合内把"方向反了"和"幅度不够"分开。
