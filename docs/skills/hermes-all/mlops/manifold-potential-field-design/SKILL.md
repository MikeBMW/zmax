# 势函数与梯度流设计 (测地线流 · 度规约束)

## When to Use
- 要给流形/球面加一个**势场** Φ, 用 `−∇Φ` 驱动点到目标点 (`gradient_flow` 之类)。
- 要"把度规(黎曼/Fubini–Study/chordal)真正用进"梯度, 而不只是算距离。
- 要在切空间投影、度规势、能量项之间做**混合**。
- 别人问"这个约束有效么? 有数据证明么?" —— 需要 A/B 臂与判据。

前置: 球面上的距离/投影/exp·log 算子归 `manifold-sphere-geometry`; 能量/功率记账归
`manifold-engine-energy`; 本技能只管**势函数怎么选、梯度怎么混、怎么证**。

## 🔴 律 1: 势必须光滑 **且带符号**

球面上"朝目标收敛"的势, 只有一种写法同时满足光滑无奇点、方向唯一:

```python
# ✅ 带符号内积 (chordal / Fubini–Study 同族: c 的单调变换, 测地线相同)
def phi(q, goal):
    return 0.5 * (1.0 - float(np.dot(unit(q), unit(goal))))     # ∈[0,1], ᵠ无奇点

# ❌ arccos + 绝对值: 两个奇点
#   arccos 在 c→1 导数 −1/√(1−c²) 发散; |·| 在 c=0 有尖点
#   ‖∇Φ‖ 能塌到 5.9e-05 ⇒ 方向完全由浮点噪声决定
def bad_phi(q, goal):
    return 0.5 * np.arccos(abs(np.dot(unit(q), unit(goal)))) ** 2
```

**为什么不能事后补救**: 真实轨迹上 c 的分布是**双侧**的 —— 实测 k=150 中 `c>0.95` 占 **11.3%**
(正好在 arccos 发散区)、`c<0.10` 占 **5.3%**(绝对值尖点)。两者都不能靠调参避开。

🔴 **`½(1−c²)` 配 `c=|⟨p,g⟩|` 是陷阱**: 它让 `goal` 和 `−goal` 给出**逐位相同**的势
⇒ 想用"把 goal 翻到同半球"来消歧是**空操作**(两版实测结果精确同为 `0.4564`)。
取绝对值那一刻符号信息就丢了, 后面怎么补救都是无效动作。
**换势之前先问: 这个势在 `±goal` 上值一样吗? 一样就丢了一半信息。**

### SU(2) 双覆盖: 语义上 ±p 同一姿态, 但**梯度**要知道朝哪个
`p` 与 `−p` 是同一旋转, 但 `⟨p,goal⟩` 的符号决定切向梯度指向。带符号的 `½(1−⟨p̂,ĝ⟩)` 已经
自己处理了这一点, **不需要额外的半球翻转代码**; 加了反而会翻错方向 ——
实测"两路都翻"使 cos 从 0.4564 掉到 **0.3238**(欧氏分量被一起翻了)。

#### 🔴 符号口径: `∇Φ` 与 `−∇Φ` 差一个负号, 写反就是稳定地往反方向走

`Φ=½(1−c)`, `c=⟨p̂,ĝ⟩` ⇒ `∂c/∂p=(ĝ−c·p̂)/‖p‖` ⇒

| 量 | 表达式 | 用途 |
|---|---|---|
| `∇Φ` (Φ 的**上升**方向) | `−½(ĝ−c·p̂)/‖p‖` | 只是数学量, 别拿去驱动点 |
| `−∇Φ` (**下降**方向 = 朝 goal 移动) | **`+½(ĝ−c·p̂)/‖p‖`** | 步进向量必须用这个 |

任何名为 `metric_gradient` / `descent_direction` 的**步进函数必须返回 `+(ĝ−c·p̂)`**。
返回 `−(ĝ−c·p̂)` 会稳定把点推向**反 goal**, 而且因为 `½(1−c)` 在 `±goal` 上形状对称,
总指标只会"一致变差"、永不报异常 —— 实测 cos 从 `0.0321` 掉到 **`−0.5120`**(精确反号),
去掉负号后 `0.0321 → 0.5983`。

**验收这一行代码的办法**(比跑完整套判据快得多): 取已知 `p`、`goal`, 手算 `cos(p+ε·g, goal)`,
它必须 **大于** `cos(p, goal)`。跳过这一步就等着整批判据集体假红。
**docstring 里必须写明这个函数返回的是 `∇Φ` 还是 `−∇Φ`** —— 这是唯一能防住这类错误的东西。

## 🔴 律 2: 混合要在**方向级**, 不在标量级

```python
# ✅ 两势分别求导 → 只在单位方向插值 → 幅值统一取欧氏
g_eu  = tangent_gradient(euclid_phi, p)
g_met = tangent_gradient(metric_phi, p)
u = (1 - w) * unit(g_eu) + w * unit(g_met)
g = u * norm(g_eu)

# ❌ 先混标量 phi 再整体数值求导 ⇒ arccos 奇点 + 量纲差一起进梯度
phi_mixed = lambda q: (1-w)*eu(q) + w*met(q)
g = tangent_gradient(phi_mixed, p)
```

原因: `Φ_eu` 可以任意大而 `Φ_met∈[0,1]`, 线性相加后梯度幅值跳变; 而且标量级混合会把
被混进去那个势的**数值奇点**原样放大到执行量上。

**权重分段**(smoothstep, 不是硬切换): `c≤0.10` ⇒ w=0 (正交/对跖附近方向本性不定, 退纯欧氏);
`c≥0.35` ⇒ w=W_MAX; 之间平滑过渡。

## 🔴 律 3: 监视势必须与执行梯度**同源**

任何"收敛/单调"判据读的那个标量势, 必须是**你正在下降的那个势**。
实测: 梯度已换新势, 而 `phi` 返回值还停在旧的 `½arccos²` ⇒ 沿新方向走旧势不单调,
单调率从 1.000 掉到 **0.976**。两处统一成同一欧氏尺度势后回到 **1.000**。

**同一个函数服务两个口径(执行 + 监视)时, 一次只改一半是常见疏忽 —— 改完全局搜一遍谁还在算旧势。**

---

## 🔴 律 4: 留一条欧氏腿才能保单调

纯度规方向**不是**严格梯度下降方向(它是方向级混合的产物) ⇒ 实测仍有 **2.4%** 的步会让 Φ 微增。
上限 `W_MAX=0.85`(留 15% 欧氏)是实测可用的折中: 单调率 1.000, 而纯度规时 0.976。

## 🔴 律 4·补: 步长按**到目标的距离**给, 不能按状态本身的模长

```python
# ✅ 步长 = 到 goal 的距离 × 0.5 (最多走一半, 不会跨过头)
step  = 0.5 * np.linalg.norm(unit(p) - unit(goal)) * np.linalg.norm(p)
p_new = p + descent_direction(p, goal) * step

# ❌ 拿 ‖p‖ 当尺度去归一化梯度幅值 ⇒ p 离原点远时一步跨过 goal
step = np.linalg.norm(p)          # 与"还差多远"无关
```

用 `‖p‖` 当尺度时, 模长大的一步就跨过 goal ⇒ `Φ` 反而**上升** ⇒ 若外层还有"Φ 不得增"的
单调闸, 该帧判坏退回原值 ⇒ **净效果为零**, 但块内平滑器仍按"已修正"去改轨迹 ⇒
指标表面正常、实际什么都没做(实测单调率反而从 0.7372 掉到 0.7286)。
**自检**: 统计"被单调闸退回的帧数"; 它接近总帧数就说明**步长选错**, 不是势选错。

## 🔴 律 5: 这套方法有维度上限, d ≥ 64 就别用

球面上的方向判据全靠 cos 区分, 而随机单位向量的 cos 标准差 ≈ `1/√d`, 信号随维度雪崩:

| d | cos 标准差 | \|cos\| 中位 | 可分辨率 (\|cos\|>0.5) |
|---|---|---|---|
| 3 | 0.575 | 0.49 | 49% |
| 4 | 0.501 | 0.41 | 40% |
| 8 | 0.353 | 0.26 | 17% |
| 16 | 0.247 | 0.17 | 3.9% |
| 64 | 0.124 | 0.085 | **0%** |
| 256 | 0.064 | 0.043 | **0%** |

`Φ = ½(1−cos)` 在 d=256 的信号量级只有 **0.03**, 与数值微分噪声同阶 ⇒ 梯度方向由噪声决定,
与律 1 里「`‖∇Φ‖` 塌到 5.9e-05 后 arccos 奇点主导」是**同一类失效**, 只是成因从奇点换成了集中现象。

🔴 **给任意维度 latent (典型: JEPA 三层各 256 维) 直接套球面约束, 等价于没加约束且更糟 —— 引入伪引导。**
"引擎支持任意维度"(它会报 `need`/`got` 并零补齐) 不等于"那个维度上几何有效"; 能跑、不报错、不 NaN 全部不构成证据。

被问到"能不能叠到 XX 架构"时的定式回答:
1. 先量目标 latent 维度 → 对照上表给可分辨率; d ≥ 64 直接判定"不能直接套"。
2. 降维后约束: 只把与任务几何同构的 3~8 维子空间投到球面, 其余维度走 `latent_flat` 直通。
3. 不改表示、只加引导: 在融合层输出上叠 `Φ` 梯度 (classifier-guidance 式), 不动任何权重, 风险最低。
4. `latent_flat` 在 `project()` 里是**原样直通** (`return z.copy(), drift=0.0`), 不是"低维投影" ——
   选了它等于没约束, 别当成已加约束上报。
5. 多层异构 latent (语义/物体/空间) 的坐标系互不相通, 每层要独立定势的目标点与 radius;
   别默认"层间可以直接算 cos"。

## 5. A/B 四臂 + 六判据 (证明"这个约束有用"的标准形状)

四臂**只改一个开关**, 这样每条判据都能归因到单个机制:

| 臂 | 配置 | 作用 |
|---|---|---|
| A | 基线(纯欧氏势) | 参照 |
| B | +度规势 | 证明度规**单独**有效 |
| C | +切投影 | 证明投影**单独**有效 |
| D | 两者都开 | 组合 |

| # | 判据 | 通过条件 |
|---|---|---|
| ① | 方向一致性提升 | `cos(D) > cos(A)` |
| ② | 法向泄漏下降 | `leak(D) < leak(A)/2` |
| ③ | 收敛更快或持平 | `conv(D) ≤ conv(A) + 0.5 拍` |
| ④ | 单调率不劣化 | `mono(D) ≥ mono(A)` —— ⚠️ **仅适用于追踪类任务**; 插入/装配类轨迹天生不单调, 用它会把对的引导判错(见 §6.4, 改用 §5·补 的扰动恢复) |
| ⑤ | 度规单独有效 | `cos(B) > cos(A)` |
| ⑥ | 切投影单独有效 | `leak(C) < leak(A)` |

**参照系必须说清**: 球面上的正确参照是**切空间测地线方向**, 不是欧氏割线。
用未投影的 p→goal 当参照得到的 cos 只能用来量化"投影掉了多少切向分量"(实测 ~20%),
**不能**拿它推翻结论 —— 一度把割线当真值, 导致 A/C 两臂的排名直接互换。

两个口径都跑(k=30 / k=150), 都全绿才算稳; 只有大 k 通过或只有小 k 通过都要如实说。

### 5·补: 轨迹跟随时 goal 就是轨迹终点 ⇒ 收敛类判据**没有区分度**, 改用扰动恢复扫描

当 `goal` 取自轨迹本身的终点时, 原轨迹与引导后轨迹**都在终点收敛到 Φ≈0**
⇒ "收敛拍"与"终点 Φ"天然打平(实测 29.13 vs 29.17 拍, 差 0.04 在噪声内), 证不了任何事。
在这种数据上跑收敛类判据, 得到的是"看起来做了 A/B、实际两臂等价"。

正确的问法是**执行有偏差时能不能拉回来**:

```python
for sigma in (0.0, 0.05, 0.10, 0.20, 0.40):            # 相对平均步长的偏差幅度
    pert = seg + rng.normal(size=seg.shape) * sigma * mean_step_norm
    out  = guide(pert)
    err_raw = ‖unit(pert[-1]) − goal‖                  # 扰动后末端偏差
    err_fix = ‖unit(out[-1])  − goal‖                  # 引导后末端偏差
```

| # | 判据 | 通过条件 |
|---|---|---|
| ① | 抗扰动 | `sigma>0` 时 `err_fix ≤ err_raw` 全部成立 |
| ② | 不办坏 | `sigma=0` 时 `err_fix ≤ err_raw + 1e-6` |
| ③ | **增益随扰动单调增** | `gain(sigma)` 递增 ⇒ 证明是**真纠偏**而非随机扰动带来的假收益 |
| ④ | 实时性 | 一个 H 拍块 ≪ 控制周期 |

实测在 4 维 chunk 上: `sigma` 0.05/0.10/0.20/0.40 → 末端误差改善 **17.0% / 17.0% / 19.7% / 28.1%**,
`sigma=0` 时 `Δ=7.7e-08`(数值噪声级), 16 拍块 0.71 ms(≈0.04 ms/拍)。
**判据 ③ 是这组的核心** —— 只有它能把"真在纠偏"与"注完噪声后随便动一动也能小幅改善"分开。

## 6. 判据自身的错 (比算法错更常见)

几何/数值类判据很容易**自己写错**, 于是"算法不行"和"判据太严"分不清。四条实测:

1. **容差不能拍 1e-9**: `conv` 是"步数均值", 150 样本里 1 个样本差 1 步 = **0.0067 拍**。
   用 1e-9 会把"持平"判成 FAIL。量出"一个样本单位"有多大, 容差按它给(0.5 拍)。
2. **连续性必须沿连续路径测**: 拿一批**互相独立**的随机点逐对比较方向, 跳变 1.87(≈完全反向)
   是**必然**的 —— 这不是"硬切换"的证据, 是判据设计错误。固定 goal、让 p 沿同一方向
   连续靠近再量, 实测 0.000。
3. **分段判据要验执行量(权重 w / 梯度方向), 不要验 Φ 的数值**: 势的口径一改,
   验 Φ 数值的判据会**集体假红**, 看起来像"改动把功能弄坏了"。
4. 🔴 **不要拿"沿轨迹单调率"评价插入/装配类轨迹**: 真机插入轨迹天生不单调 ——
   实测 120 段真轨迹(4 维 action, 中位 50 帧)的相邻帧 Φ 不增比例只有 **0.7372**,
   因为"对位 → 下压 → 回退 → 再压"是任务物理必需的振荡。任何"让 Φ 逐帧不增"的引导都会
   抹掉这段必要振荡 ⇒ 单调率判据必然下降(实测 0.7372 → 0.7286), 而被测的引导其实是对的。
   **这类任务的主判据换成扰动恢复**(§5·补), 单调率最多留作辅助读数。

拿不准时先问: 这条判据在**修改前**能通过吗? 修改前就过不了/修改后必然变红的, 先怀疑判据。

## 7. 交付口径 (诚实边界)

- 报结果**分三层**: ①算法层可证(cos/泄漏/单调) ②执行层是否真接进下发链 ③任务级指标(成功率/跟踪误差)。
  **缺哪层就说缺哪层**。
- 🔴 **引擎没驱动真机时不许说"动作变好了"**: 若下发链 `tdrive_bus` 用的是欧氏 `grad_raw`、
  全文没有 tangent/投影, 那么本次只是**算法层有效性**。球面输出到欧氏扭矩空间的映射是架构级改动,
  在它之前不要暗示任务级收益。
- 自检脚本形状: 逐条 `chk(id, claim, got, ok, expect, note)` → 落 JSON → 非全 PASS 时 `exit 1`。
  必带零回归项(关掉新开关时与原实现**逐位相同**, `1e-12`)。
