# 球心引力架构视图 (`tools/gui/orbital_arch.py`) — 口径 · 改法 · 判据

控制台右侧「主参数 M」页里的「🪐 球心引力架构·太阳系」视图（纯 QPainter 自绘，无 GL）。
改这个视图前先逐条核下面的口径，改完走「四步」。

## 老倪口径 (每次都适用)
- **天体映射**(判据过): 太阳=流形引擎 `ss_mani_eng` · 水星=接触流形 `ssmani_c` · 地球=前馈加速器 `ssff` ·
  火星=Action Head `ssdec` · 木星=性能流形 `ssmani_p` · 月球=状态校正器 `ssinnov`；
  卫星=原子技能 **SK01~SK08**(只 8 颗, 绕地球)。其它球体与体系外灰点一律不画。
- **连线少而准**: 只画主体↔主体真边(画布 `links`), 颜色=信号种类(青=几何条件 / 金=性能集合条件 /
  绿=动作前馈 / 紫=反馈回灌)。
- **全部虚线**, 不留实线；而且**一条都不许装饰性地存在**: 画之前过信号门控, 依赖的真源信号没值就不画
  —— “每次显示都要由真源代码逻辑触发”。
- **柔顺**: 全图一个相位慢速流动(≈1.2px/帧, 60ms tick), 不脉冲、不整帧消失、不秒消失。
- **背景圆环**要画出来(行星公转轨道 + 地球卫星环), 与太阳引力井**色距拉开**(≥60), 否则 1× 下数不出圈数。
- **文字**: 不许压球/互叠/被边界切/硬截断(禁 `str(x)[:10]` 这类可执行截断); 标题写
  「**天体名 · 结点名**」(只写结点名用户认不出是哪颗天体); 块宽随文字自适应;
  挤不开时退到页边栏空槽并对球/已放块 keep-out; 离自己的球太远(块矩形到球面 >45px)拉 1px 引线说明归属。
- **底部图注按本帧实画生成**, 标真源与帧龄；没画的信号要明写「本帧无: X」。

## 骨架 (改哪一块)
| 位置 | 作用 |
|---|---|
| `_edges` / `_signal_ok` | 真源边集 + **信号门控**(有值才画) |
| `_force_segments` / `drawn_segments` | “要画什么”的唯一出处（含共线法向错开）—— 渲染与判据**共用** |
| `label_texts` / `label_rects` | 布局后的**最终**块矩形/文本（渲染与判据共用） |
| `_label_blocks` / `place_near` / `_gutter_slot` | 避让(径向+角度候选 → 页边栏空槽), 引线记账 |
| `_ball_clip` | 透描遍用 `QRegion` 挖掉球体(线不穿球面) |
| `_gravity_well` / 轨道环 / `_draw_forces` | 背景几何 → 力线(全虚线) → 球 → 透描 → 文字 |

配套: `tools/verify_orbital_arch.py`(只读判据, 冻源 `root=` 保确定) · `tools/orbital_shots.py`(离屏取证出图)。

## 改完必做四步
1. `./gui-venv311/bin/python tools/verify_orbital_arch.py` **连跑两次** —— 像素类判据要稳才认。
2. `./tools/gui/restart_studio.sh` 后 `echo orbital > /tmp/zmax_nav_cmd`，再 `echo mparam_shot > /tmp/zmax_nav_cmd` 抓在役实拍。
3. `./gui-venv311/bin/python tools/orbital_shots.py` 出 4 帧连拍 + 斜视角图。
4. 派看图子代理逐项复核这三张图 —— 判据量不到的视觉缺陷(归属认不出 / 两线糊成一条 / 辅助几何与线同色 /
   太淡看不见 / 标签贴边)基本靠它抓；它报的每条都要回落到一条可测判据。

## 坑
- **判据必须与渲染同源**: 渲染里有共线错开/避让挪位/边界夹紧 ⇒ 判据要调 `drawn_segments()` / `label_texts()`,
  拿 `positions()` 自己重算会量到**改前**的几何(假红)。
- 视图源码里的 `p.save()` 会被“只读”静态检查的 `.save(` grep 当成写文件口 ⇒ 检查前先剔除。
- 采样球半径 = `S * RAD[key]`，不是 `R * RAD[key]`（差一倍 ⇒ 采样点落进球体）。
- 发光/透描遍为了压在文字下面而排在球体之后 ⇒ 线会穿过球面；用球体裁剪把它挖掉。
- 球本色≈线色时, 用“球心区里有多少线色像素”验“线不穿球”会假阳性(金球 vs 金线) ⇒ 换与该球色距最大的线色。
