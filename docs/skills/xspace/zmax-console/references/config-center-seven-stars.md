## 3i. 底部信息窗 (可拖/可藏/随面) + 每页可滚动 (2026-10-15 老倪)

老倪: 「产品配置的右侧下半部分的显示区太小, 且不能用鼠标滚动调整, 看不到显示内容; 下面的信息窗口当选择相应的配置面时,
信息没有对应上, 且显示区无法用鼠标拖动调整大小, 要可以隐藏」。

· **真根因**: 页里的表按「不许挤」给了最小高度 (工程配置那张 AR 点表 = 510px) ⇒ QTabWidget 最小高 1265px,
  把竖直空间吃光 ⇒ 信息窗被压到 98px **且没有余量可分** (拖也拖不大)。所以“太小”与“拖不动”同源。
  → 每个页签包一层 `QScrollArea(setWidgetResizable)` (否则页面压不小、看不到的内容也滚不到);
  → 表的最小高度要封顶 (AR 表 300px), 不要按全表行数给。
· **信息窗**: 竖直 `QSplitter(工作区/信息窗)` + `setHandleWidth(9)`; 初值按内容给 **220~460px**;
  拖过之后记 `_out_user_sized=True` **不再自动覆盖** («↕ 自适应高度» 可重算); 头一行按钮 = 自适应/复制/收起-展开。
· **可隐藏**: 用自己记的 flag (`_out_on`) + `out_box.setVisible()`, **不能**用 `isVisible()` 当判据 (离屏恒 False)。
· **内容随面**: 换页签/点左树先落一版 `_page_out_text()` (第一行「📍 当前配置面: <页名>」+ 哪颗星 + 本面真源摘要),
  页面内动作 (导出/复制/定位到行) 之后再覆盖。判据: 8 个面逐一选 — 第一行 = 该面、含本面关键字、**不串味**。
· 判据 `tools/verify_config_center_info_panel.py` **27/27** (布局/可藏/拖动优先/8面内容/可滚/8页 QScrollArea/
  ⑦⑦b 表给足高度 · ⑧ 窗口压矮后表不被压没 · ⑨ 功能↔层模型映射与主控制台矩阵同源)。

### 3i-2. 表格必须给“最小高度”否则看不见 (老倪: 「窗口太小了, 根本看不到」)

页签包了 QScrollArea(widgetResizable) 后, 页面**会被压到视口高度** ⇒ 没有最小高度的表就被布局挤成两三行
(连表头都看不全)。规则:
· 每一张要看的表都 `setMinimumHeight(min(上限, 行高*(行数+2)+8))` (上限定 200~460, 看不够用表内滚动);
· **禁止**用 `setMaximumHeight` 去压一张要看的表 (旧代码的 `setMaximumHeight(96)` 就是”根本看不到“的元凶);
· 页面放不下时交给外层 QScrollArea 滚, 不靠压表; 表给「📋 复制…(TSV)」按钮让内容能拿走。
· 判据写法: 切到该页后量 `table.height()` (不是靠行数) —— 行数对高不对就不算过。

  别处改成 550B 后, 左树仍写「当前 550A」。修法 = mtime 监看 (每 2s 一次 stat) + 打开页面强制重读;
