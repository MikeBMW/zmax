## 版本口径（读之前先分清）

- **5.50.A / 5.50.B / 5.50.C 是产品档位**，不是先后版本：A = 4060 旁路测试机，B = VSCode 单线程调试，C = Intel 端侧主节点（在役主力）。同一文档出现三档是**故意的**，各档配置/功能确有差异。
- **5.50.5 / 5.50.758 是发布号**，按时间先后。发布号重复的文档只留最新一份。
- 同一文档的 `.md` 是正文真源，`.docx`/`.pdf` 是对外成稿，`.json` 是机器可读版；同族三格式并存是正常的。

## 规矩

1. 新版覆盖旧版时，旧版移到 `_cleanup_20261101/deliverables_tiers_20261101/`，本目录只放当前有效件。
2. 交付件一律由 `tools/` 下脚本生成（如 `machine_deck_build.py` 生成机器人整机方案），成品不手改。
3. 大文件（>50MB 的成片、模型、数据集）不放这里，放 `zmax_data/deliverables/`。
