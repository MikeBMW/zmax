## 一、这本手册的主线

世界模型不是其中一章，是全册的主语。四步论证：
1. **来路**（第 2 篇）：七十年，每一代世界模型解决上一代一个硬伤，也留下新的代价——1948 控制论 → 1960 Kalman → 1990 HMM/POMDP → 2018 World Models → 2022 JEPA/H-JEPA → 2025 V-JEPA 2。
2. **对标**（第 3 篇，核心）：NVIDIA Cosmos、Google Genie+Dreamer、OpenAI Sora、李飞飞 World Labs、Meta JEPA 五条路线同台，八维打分，用产线三条硬约束（延迟、精度、可判定）筛，落到 H-JEPA 分层。
3. **落地**（第 4 篇）：分层不是画在纸上，是五层状态空间 + 43 维观测 + SE(3) 阻抗 + 八阶段状态机 + L4 接管契约 + 记忆 + 安全闸，每一层都有代码位置与判据。
4. **兑现**（第 5-8 篇）：能力分级 C1-C5、型号 F1-F5、三张消融表、引擎 A/B、演练与自进化、成本与验收。

## 四、第 3 篇（核心篇，28 页）关键结论

- **产线要什么**：不是视频，是“我这拍下发后，下一拍会怎样 + 置信度 + 能不能判”（132）
- **四种技术基因**：生成像素 / 生成潜变量 / 生成可交互 3D / 生成轨迹分布；越往潜变量与轨迹走，越容易进控制环（133）
- **NVIDIA Cosmos**：2000 万小时视频、Predict/Transfer/Reason，定位“物理 AI 数据工厂”——我们用它造数据，不进控制环（135）
- **Google**：Genie（可交互，需动作条件）+ Dreamer（潜空间想象，L4 近亲）（136）
- **OpenAI Sora**：spacetime patches + DiT，证明视频有物理直觉；但没有动作条件、没有度量一致性、延迟秒到分钟（137-138）
- **李飞飞 World Labs**：空间智能与 3D 原生表征（RTFM/Marble），解决“世界长什么样”，不解决“动作后果”（139）
- **Meta JEPA**：表征预测 + 层级分工；V-JEPA 2（1.2B、62 小时机器人数据、零样本抓放）把世界模型与规划器分开（140-141）
- **自动驾驶**：三条可借（闭环仿真、动作条件生成、安全兜底分层）+ 两条不可照搬（米级容忍、开放长尾）（142-143）
- **八维对比**：预测对象/输入/输出/实时性/度量一致/力/数据需求/能否进控制环；只有最后一行“进控制环”分出胜负（144）
- **选 JEPA 四条硬理由**：4.4 ms 前向、可挂毫米判据、自监督省标注、天生可分层（145）
- **延迟账**：K=20 步 × 20 ms = 400 ms = 20 个控制拍；扩散单步 20–30 ms，20–50 步即 400 ms 起（148）
- **H-JEPA-MR**：四层时间尺度（分钟/秒/百毫秒/20 ms）+ 三条约束（层间只传 latent、每层自带判据、层可降级）+ 几何分支（149-151）
- **UPH>1000**：3.6 s/件、3.19 倍缺口、分项预算、并行/缓存/提前决策 ×2.4-3.1 倍、单一大模型为何到不了、分层三代价（153-156）

> 口径纪律：1000 UPH 与 3.6 s/件是**目标值（规划）**，在役仍是 314 件/h、11.468 s/件；外部工作只写公开发表的做法与作者自述目标，不替它们下性能结论。
