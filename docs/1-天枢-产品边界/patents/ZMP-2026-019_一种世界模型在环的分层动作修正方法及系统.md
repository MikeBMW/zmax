## 1. 技术领域

本发明属于具身智能与分层运动控制技术领域，具体涉及一种在分层架构中把**世界模型（动作条件潜空间预测器）**接入动作生成层的接口方法与系统，用于在不重新训练动作网络的前提下，对候选动作修正量做**前向预测验证**，并据此决定采纳、缩权或拒绝。

---

## 2. 背景技术

### 2.1 现有分层架构的三个断点

具身智能系统普遍采用分层架构：感知层（L2）负责从传感器得到几何/语义量，动作层（L3）负责生成动作，认知层（L4）负责预测与决策。但在工程实现中，层间连接往往存在三个断点：

1. **L4 有能力、无出口**：世界模型（如 JEPA 类动作条件潜空间预测器）具备"给定当前状态与动作，预测下一状态"的能力，但其输出通常只用于离线评估或旁路对照，**没有接进动作生成回路**。动作层实际执行时并不知道"这一步走出去之后会怎样"。
2. **动作层只有"当下梯度"，没有"前后比较"**：基于势场/梯度的修正方法（如极小化装配势能）给出的是**当前状态的最速下降方向**。这是一个开环判断——方向在当前点上是对的，但没有验证"沿这个方向走一步之后，代价是否真的下降"。
3. **L2 的健康度不参与动作决策**：感知层往往能给出"本帧观测是否可信"（如质量检测的通过/否决、帧龄、遮挡），但动作层通常无条件采信感知给出的几何量，导致**观测已经不可信时，修正量仍被全额执行**。

### 2.2 具体到精密插配场景

在光模块、连接器、销轴等亚毫米级插配作业中，上述断点会造成实际损害：

- 动作层依据当前梯度给出一个修正量，但该修正量在**临界干涉区**可能使工件进入更差的位置（梯度在非凸代价面上不保证全局有效）；
- 一旦执行了错误方向的动作，工件与孔壁发生刮擦，此时再靠后一拍的梯度纠回来，已经产生损伤；
- 若此时感知恰好不可信（反光、遮挡、帧过期），错误修正会被**加倍放大**。

现有技术中，若要解决"执行前先验证"，通常的做法是**重新训练动作网络**，把预测信息拼进网络输入端。但这引入新问题：拼接通道若未经充分训练，等同于向动作网络注入随机扰动（即"假注入"），实测效果可能比不注入更差。

## 3. 发明内容

### 3.1 核心思想

**不重新训练动作网络**，而是在动作层输出之后、执行之前，插入一个**世界模型前向验证环节**：

```
                    ┌──────────── L2 感知层 ────────────┐
                    │  几何偏差 δ_vis + 观测健康度 h     │
                    └──────────────┬────────────────────┘
                                   │ ① L2 → L3
                    ┌──────────────▼────────────────────┐
                    │  L3 动作层：名义动作 ξ_d            │
                    │  + 解析修正 Δξ（度规/势场方法）      │
                    │  → 候选动作 ξ_cand = ξ_d + Δξ      │
                    └──────────────┬────────────────────┘
                                   │ ② L3 → L4（把候选动作作为条件）
                    ┌──────────────▼────────────────────┐
                    │  L4 世界模型：                     │
                    │  z' = P(z_t, a_cand)              │
                    │  m' = R(z')  → 预测流形坐标        │
                    │  取 d_perp'（预测径向偏差）         │
                    └──────────────┬────────────────────┘
                                   │ ③ L4 → L3（预测结果回灌决策）
                    ┌──────────────▼────────────────────┐
                    │  增益判定：                        │
                    │  gain = (|d⊥| − |d⊥'|)/|d⊥|       │
                    │  gain ≥ g_hi → 全额采纳            │
                    │  g_lo ≤ gain < g_hi → 缩权         │
                    │  gain < g_lo → 拒绝（不执行）       │
                    └───────────────────────────────────┘
```

三层连接由此**显式闭环**：L2 提供"看得到什么、可不可信"，L3 提供"想怎么动"，L4 回答"这样动之后会怎样"，结果回灌 L3 决定"到底动多少"。

### 3.2 技术方案（步骤）

**步骤 1 · 构造几何潜空间状态**

将当前几何关系编码为固定维度的潜空间向量。在插配场景中取 7 维：

```
z7 = [ hx − target , hx − hole , grasped ]
```

- `hx`：工件末端（模块头）位姿，单位 m
- `target`：目标位姿
- `hole`：孔/销中心位姿
- `grasped`：夹持标志（1 维）
- 前三元组描述"距目标还差多少"，中三元组描述"距孔还差多少"，最后一维描述夹持状态

该构造的优点：**无需历史轨迹即可从当前状态直接算出**，不依赖时序缓存，避免"轨迹缓存缺失导致预测不可用"。

**步骤 2 · 生成候选动作**

动作层按既有方法（如 ZMP-2026-013 的各向异性度规解析注入）给出名义动作 ξ_d 与修正量 Δξ，构造候选：

```
ξ_cand = ξ_d + Δξ
```

**步骤 3 · 世界模型前向**

把候选动作作为条件送入世界模型，得到预测潜状态与预测流形坐标：

```
z' = P(z_t, ξ_cand)
m' = R(z')
```

从 m' 中取出**与任务成败直接相关的物理量**——在插配中取预测径向偏差 `d_perp'`（横向模场错位）。

**步骤 4 · 增益判定与三档处置**

以当前实测径向偏差 `d⊥` 为基准计算预测增益：

```
gain = (|d⊥| − |d_perp'|) / |d⊥|
```

按增益分三档：
- `gain ≥ g_hi`：预测明确改善，全额采纳 Δξ
- `g_lo ≤ gain < g_hi`：改善不足或存在不确定性，**按增益比例缩权**（保守执行）
- `gain < g_lo`：预测恶化，**拒绝该候选**，本拍不施加修正（退回名义动作）

**步骤 5 · 多档试算（过冲保护）**

对同一候选按多个缩放档（如 1.0 / 0.6 / 0.3）分别做前向预测，选择增益最高且不引发过冲的档位。仅当"全额档且改善显著"时才提前收敛，避免漏掉更优的保守档。

**步骤 6 · 尺度分工（关键）**

世界模型对动作的灵敏度随动作幅值变化。实测（见第 5 节）表明：亚毫米级微调时世界模型的响应增益仅约 1%，不足以分辨方向；而在数十毫米以上的大幅动作时增益可达 20%~70%，方向可分辨。

因此本方法**不把世界模型用于精调**，而是明确定位为**粗筛层**：

- **世界模型（L4）负责大方向否决**：若预测显示大幅动作方向错误（工件会更远离孔），直接拒绝；
- **解析度规/势场（L3）负责细节修正**：亚毫米级修正量仍由解析方法给出，不经世界模型验证。

这一分工避免了"用低灵敏度预测器去分辨微小差异"导致的随机判定。

**步骤 7 · 零回退（不造数）**

出现以下任一情况时，本方法**不做验证、也不做任何替代预测**，原样放行名义动作，并标注未验证原因：

- 世界模型权重不可用 / 未训练
- 几何潜空间状态缺失或非有限值
- 预测输出非有限值
- 推理异常

即"宁可不验证，也绝不返回一个编造的预测值"。

### 3.3 与现有技术的区别

| 维度 | 现有做法 | 本发明 |
|---|---|---|
| 预测结果的用途 | 离线评估 / 可视化对照 | **接进动作回路，决定动作是否执行** |
| 提升预测能力的方式 | 重新训练动作网络（存在假注入风险） | **不改网络权重**，在输出后加验证环节 |
| 候选动作处理 | 全量执行 | **前向验证后三档处置**（采纳/缩权/拒绝） |
| 世界模型的作用域 | 未加区分 | **明确限定为粗筛**，精调交给解析方法 |
| 预测不可用时 | 常见做法是填零或沿用上次值 | **零回退**，原样放行并标注原因 |
| 单位一致性 | 易混淆（潜空间 m / 动作 mm） | **契约化并在适配层强制换算** |

## 4. 权利要求书

1. 一种世界模型在环的分层动作修正方法，其特征在于，包括：
   由动作生成单元给出名义动作 ξ_d 与候选修正量 Δξ，构造候选动作 ξ_cand = ξ_d + Δξ；
   将 ξ_cand 作为动作条件送入世界模型，得到预测潜状态 z' 及其预测流形坐标 m'；
   从 m' 中取出与任务成败相关的物理量，计算预测增益；
   依据增益对候选修正量做**采纳、缩权或拒绝**的处置，**无需重新训练动作生成单元的权重**。

2. 根据权利要求 1 所述方法，其特征在于，所述几何潜空间状态由当前相对几何直接构造，包括"工件末端相对目标"的三元组、"工件末端相对孔/销"的三元组与夹持标志，**不依赖历史轨迹缓存**。

3. 根据权利要求 1 所述方法，其特征在于，所述增益为
   `gain = (|d⊥| − |d_perp'|)/|d⊥|`，
   其中 d⊥ 为当前实测横向偏差，d_perp' 为预测横向偏差；设定上阈值 g_hi 与下阈值 g_lo，按 gain 落入的区间分别执行全额、缩权、拒绝。

4. 根据权利要求 1 所述方法，其特征在于，对同一候选按**多个缩放档**分别做前向预测并择增益最高且不引发过冲者；仅在"全额档且增益超过显著阈值"时提前收敛，否则遍历全部档位。

5. 根据权利要求 1 所述方法，其特征在于，按**动作幅值划分作用域**：世界模型仅用于**大幅动作的方向否决**；亚毫米级修正仍由解析度规/势场方法给出，不经世界模型判定。

6. 根据权利要求 5 所述方法，其特征在于，所述作用域划分依据**实测灵敏度**确定——若某动作幅值下正向与反向候选的预测增益差小于分辨阈值，则该幅值档不启用世界模型判定。

7. 根据权利要求 1 所述方法，其特征在于，所述感知层向动作层提供**观测健康度**，当健康度低于阈值时不采信其几何量，此时世界模型验证亦不启用。

8. 根据权利要求 1 所述方法，其特征在于，当世界模型权重不可用、潜空间状态缺失、预测输出非有限或推理异常时，**不做验证、不生成替代预测值**，原样放行名义动作并标注未验证原因。

9. 根据权利要求 1 所述方法，其特征在于，所述世界模型的动作输入与潜空间状态分别采用不同单位（潜空间为米、动作修正量为毫米），在适配层**强制换算**后再拼接，避免量纲错位导致的静默错误。

10. 一种世界模型在环的分层动作修正系统，包括感知单元、动作生成单元、世界模型单元与存储介质，所述世界模型单元执行程序时实现权利要求 1–9 任一项所述的方法，且所述世界模型单元的输出**直接接入动作生成单元的执行判定**，而非仅用于离线评估。

## 5. 具体实施方式与实测

### 5.1 实施环境

- 世界模型：JEPA 类动作条件预测器，结构为 `predictor(MLP, 4 层, hidden=512)` 把 (z7, a4) 映射到 7 维潜状态，再由 `readout(MLP, 3 层, hidden=256)` 读出 6 维流形坐标 `[progress, risk, V, eta, rem, d_perp]`
- 权重规模：参数约 1.4 M，CPU 推理单次约 2 ms，可满足 10 Hz 控制周期
- 潜空间：`z_dim=7`，动作：`act_dim=4`，流形读出：`manifold_dim=6`

### 5.2 真权重加载与读出校验

以现场示教真值构造真 z7（单位 m）：

```
hx−goal = [−0.1496, 0.2704, −0.0797]
hx−hole = [−0.1087, 0.2704, −0.0797]
|hx−hole| = 0.3021 m (302.1 mm)
```

世界模型读出：

```
[0] progress = +1.475320
[1] risk     = −0.539607
[2] V        = +0.156965
[3] eta      = +2.449854
[4] rem      = −0.078214
[5] d_perp   = +0.944929
```

d_perp 与真实几何距离（302 mm）处于同一量级，说明读出具有物理意义，不是随机数。

### 5.3 动作方向敏感性（关键实测）

沿"朝孔心 / 背离孔心"两个相反方向分别施加不同幅值的修正，观察预测 d_perp 与增益：

| 步长 mm | 朝孔心 d_perp' | gain | 背离孔心 d_perp' | gain | 方向可分性 \|Δgain\| |
|---:|---:|---:|---:|---:|---:|
| 5 | +0.9353 | +0.0102 | +0.9550 | −0.0106 | 0.021 |
| 20 | +0.9093 | +0.0377 | +0.9873 | −0.0448 | 0.083 |
| 50 | +0.8700 | +0.0793 | +1.0586 | −0.1203 | 0.200 |
| 100 | +0.8271 | +0.1247 | +1.1822 | −0.2511 | 0.376 |
| 200 | +0.7498 | +0.2065 | +1.4249 | −0.5080 | 0.715 |

**结论**：该权重对 5 mm 级微调的响应仅 1%，无法可靠分辨方向；对 50 mm 以上动作响应 8%~51%，方向可明确分辨。**这正是权利要求 5、6 的实测依据**——世界模型限定用于粗筛，精调交给解析方法。

### 5.4 三档处置实测

对解析候选（径向 0.32 mm）与其反向候选分别验证：

```
原向：gain = +0.000439  → scale = 0.35（增益不足，缩权执行）
反向：gain = −0.000134  → scale = 0.35（缩权）
```

即：**增益不足时验证层不盲目全额采纳**，而是缩权。这与"原向优于反向"（+0.000439 > −0.000134）一致，说明验证方向正确，只是幅值不在该权重的灵敏区。

### 5.5 过冲保护实测

构造"过度修正会冲过零点"的世界模型，候选为 −0.60 mm（理想减速点 −0.40 mm）：

```
试算 1.0 档 → gain 0.500
试算 0.6 档 → gain 0.900  ← 选中
试算 0.3 档 → gain 0.450
```

若采用"达标即停"的简化实现，会停在 1.0 档（gain 0.500），实际执行过冲。因此必须**遍历档位择优**（权利要求 4）。

### 5.6 零回退实测

| 场景 | verified | 行为 |
|---|---|---|
| 权重可用 + z7 有效 | True | 正常验证 |
| 权重不可用 | **False** | 原样放行，不验证 |
| 预测输出非有限 | **False** | 原样放行 |
| 预测项缺失（λ=0） | — | 逐位等于纯几何结果（零回退） |

### 5.7 与 013 的协同

两件专利构成**两层防线**：

- **019（本件）**：粗筛层——大方向错了就否决，避免"走出去才发现走反"
- **013**：精调层——在小步长下用各向异性度规 + 视触觉融合做亚毫米修正

执行顺序为：先用 019 否决明显错误方向 → 若通过，则由 013 给出精细修正量 → 双重限幅后执行。两者在代码上分别是 `wm_verify.verify()` 与 `geodesic_inject.correct()`，互不侵入。

## 6. 技术效果

1. **不重训即可引入预测能力**：避免"特征拼接 = 随机扰动"的假注入问题，世界模型的增益直接体现为动作是否被执行。
2. **执行前拦截错误方向**：把"走出去再纠回来"变为"预测后不执行"，减少刮擦损伤。
3. **保守执行**：增益不足时自动缩权，而非非黑即白地全额执行或完全放弃。
4. **能力边界显式化**：通过灵敏度实测把世界模型限定在其真正可靠的作用域（粗筛），不用它做力所不及的精调。
5. **零回退不造数**：任何环节不可用时如实放行并标注，不产生"看起来在工作"的假预测。
