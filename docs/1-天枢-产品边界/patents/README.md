# 专利体系 · Z-MAX 状态空间工程

本目录是 Z-MAX 专利的**唯一归档处**。每件专利都不是孤立的法律文本，而是状态空间工程某一层技术核心的**可执行表达**：
专利里的每条主张，在代码里有对应实现，在验证脚本里有对应判据。

**判断一件专利是否"成立"的标准：把它的主张拿到代码里指得出来、跑得通、有数。**

### B 类新增：019 世界模型在环（回答"专利如何与世界模型结合"）

013 只写了 **L4 流形 → L3 动作头** 一段，**没有世界模型，也没有 L2**。019 补的就是这三层怎么连：

```
L2 感知 ──① 几何偏差 δ + 观测健康度 h──▶ L3 动作层
L3 动作 ──② 候选动作 ξ_cand 作动作条件──▶ L4 世界模型
L4 世界模型 ──③ 预测 d_perp' + 增益判定──▶ L3 决定"到底动多少"
```

| 专利 | 守住什么 | 代码落点 | 实测证据 |
|---|---|---|---|
| **019 世界模型在环** | 执行前验证"走完这一步会怎样"，而不是只看当前梯度 | `policies/manifold/wm_verify.py`（`verify`/`candidate_gain`/`couple_with_geometry`）+ `wm_adapter.py`（`predict_dperp`/`make_predictor`/`z7_from_state`）+ `engine/runtime.py` 写 `_SS_STATE["z7"]` | 真权重 `z_dim=7/act_dim=4/manifold=6` 加载无缺失；真 z7 → `d_perp=0.9449`（\|hx−hole\|=302.1mm 同量级）；灵敏度扫描 5→200mm 的 \|Δgain\| 0.021→0.715，**据此把世界模型限定为粗筛、精调交回 013** |

**关键实测结论（决定了架构分工）**：世界模型对 5mm 级微调只响应 1%，对 50mm 以上响应 8%~51%。所以它不是拿来做精调的——**粗筛（否决走反的大幅动作）归 019，精调（亚毫米修正）归 013**。这条写进了权利要求 5、6。

## 三、013 到底联动了没有（正面回答）

**联动了，链条是四段，每段都能指出代码、跑出数**：

```
① L4 流形算出几何量
   ssmani_c.py → _SS_STATE["perf_mani"] = {grad: ∇V_p, V_p, eta, stage}
                _SS_STATE["contact_mani"] = {axis, progress, risk}

② 进程内共享状态传递（同源真值，不复制不落盘）
   flow_matching_impl.py :: _l4_in_summary(ctx) 读取上述两项

③ L4→L3 解析注入（专利主体）
   读真源 zmax_manifold.json#inject（σt/σn/α0/V0/力阈值/接触刚度）
   → correct(nominal, ∇V, axis, eta, V_p, force, contact, dir_xy, residual)
   → Δξ = −α·M⁻¹∇V，双重限幅，力阈值保护
   → ξ* = ξ_d + Δξ 写回动作

④ 落地四处（缺一即"只停留在算法文件里"）
   主参数真源 / 画布 ssdec.params.l4_inject / 输出 ssdec.out1.l4_inject / 总线 L4注入.*
```

**每个环节的实证**：

| 环节 | 怎么证明它真的在跑 |
|---|---|
| ① 流形出数 | `probe_l4_inject` 打印 `∇V_p=[0.2635,-0.3319,-0.1309]`、`V_p=0.150484`、`eta=0.05` |
| ② 传递 | `_l4_in_summary` 的 `in5_sources` 含 `performance`/`contact` 两源 |
| ③ 注入 | 输出 `l4_cond_injected=true`；近孔 `δ⊥=0.495mm → Δξ径向 0.320mm` |
| ④ 落地 | 总线 live 实测 `L4注入.Δξ_径向_mm=0.001826`、`各向异性=400.0` |

**唯一未闭环的一环**：真六维力。当前 `tcp_out/latest.json` 只有位姿，`tactile4` 是从 peg−hole 距离合成的（本质是视觉几何的另一种表达）。
所以 013 的"触觉路径"目前跑在 `contact_proxy` 档，`force` 档的算法正确性已在受控输入下验证，等硬件到位即可切换，代码路径不变。
