# 1-天枢 · 产品边界

本层管**"卖什么、不卖什么"**。写进来的东西必须能回答商务和客户的问题，不写实现细节。

## 分区

| 子目录 / 文件 | 放什么 |
|---|---|
| `patents/` | 专利申请（ZMP-2026-001~014）+ `00_专利申请渠道清单.md` 总表 |
| `deliverables/` | 对外交付件，按**类型**分：产品方案 / 机器人方案 / SOR / 交付包-插拔 / 交付包-摆盘 / 立项与协议 / 配置与测试 / 工程手册 |
| `Z-MAX产品等级定义-L1-L5标准.md` | 产品等级怎么划（客户问"你能做到哪一级"） |
| `Z-MAX-硬件平台-L2-L3-L4方案.md` | 硬件选型与对应的能力上限 |

## 一句话判定

- 客户问「你能做什么、做不到什么」→ 放这里
- 问「凭什么这么说」→ 放 `5-玉衡-指标验收/`
- 问「怎么实现的」→ 放 `6-开阳-工程落地/`

## 交付件规矩

- 版本 token 有两类：**产品档位**（`5.50.A/B/C`，不同机型）各留一份；**发布号**（`5.50.7xx`）只留最新，旧件进 `deliverables/6-立项与协议/_历史版本/`
- 大文件（zip/pdf/pptx/权重）不进代码库，走网盘或数据服务器
- 交付件目录顶层 ≤9 个类型夹 + 1 个 `README_INDEX.md`

## 出口

- 作业怎么干 → `2-天璇-作业任务/`
- 能力清单 → `3-天玑-能力功能/`
