# 3-天玑 · 能力功能

本层管**"系统有哪些能力"**。两种东西，别混：

| 内容 | 位置 | 性质 |
|---|---|---|
| **能力定义**（功能清单、特征库、原子技能、能力栈） | 本层根目录 `*.md` | 手写，人读 |
| **技能库镜像** | `skills/` | ⚠️ 从 `~/.hermes/skills` 同步来的**镜像**，要改改源（`tools/sync_hermes_to_repo.sh`） |

## 根目录文档

| 文件 | 讲什么 |
|---|---|
| `state_space_feature_list.md` | 状态空间能力特征清单 |
| `zmax_l2_l3_l4_capability_stack.md` | L2/L3/L4 能力栈 |
| `model_capability_architecture.md` | 能力与模型的对应 |
| `atomic_skill_topics_20261015.md` | 原子技能话题定义 |
| `vision_grasp_skill.md` | 视觉抓取技能 |
| `空间质数结构化理解能力_设计_v1.md` | 结构化理解能力设计 |

## 能力定义的三条规矩

1. **feature 从能力角度定义，禁用算法词**（写"能识别微小间隙"，不写"用 SAM3 分割"）
2. **每条能力要有完整定义**：输入什么、输出什么、什么条件下失效
3. **模型 = 能力的组合**，不是能力本身

## 出口

- 能力怎么实现 → `4-天权-模型算法/`
- 能力达标没有 → `5-玉衡-指标验收/`
