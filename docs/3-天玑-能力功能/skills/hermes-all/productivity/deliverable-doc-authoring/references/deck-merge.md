# 多册合并成一册（总技术手册 / 合订本）

## 何时用

用户已有两本以上**各自能构建**的册子（技术白皮书、整机方案、能力分级产品册），要求「合成一个总的技术手册 / 合订本 / 一本」。

不要手工在编辑器里拼页，也不要新写一套内容 —— 用合并器从各册的**内容模块**重新构建。

🔴 输入必须是内容模块（`tools/deck_content*.py` 里带 `ch` 的 dict 列表），**不是成品 pptx**：成品里页已排版定死，
去重、重编号、插页都只能手工做，而且改一次内容要重做一次。

## 合并器结构（`tools/build_manual_deck.py`）

```
PART = {"deck_content1": 4, "deck_content2": 4, "deck_content3": 6, ...}   # 源模块 → 目标篇号

def collect():
    out = []
    for mod_idx, (mod, name) in enumerate(SOURCES):      # 源册序 = 排序第二键
        for e in mod.ENTRIES:
            kind = e.get("kind", "page")
            if kind in ("cover", "section", "quote"):   # 各册自己的封面/篇首页/结尾语录一律丢
                continue
            num = parse_ch(e.get("ch", ""))             # "3.2 L2 感知" → 3.2；附录 "A1｜术语表" → (0,"A1")
            part = PART[name]
            out.append((part, mod_idx, num, e))
    return out

# ① 归一化同名去重（去标点/空格/全半角）
# ② 显式 SKIP 表去掉「同主题不同标题」的重复
# ③ 排序 (part, mod_idx, num)，④ 重编号 f"{part}.{i:02d}"，⑤ 新建封面/导读/结语
```

导读页列**每篇页码范围**，页码由重编号后的位次算出，不要手填。

## 坑

1. 🔴 **只按原章号排序会让两本书的同号章节交错**。两册都有 6.1/6.2 时，按 `num` 排序得到
   `6.1(白皮书) 6.1(产品册) 6.2(白皮书) …` —— 读者看到「原型定义 → 单件成本 → 原型能力 → 交付包」这种来回跳。
   排序键必须是 **(篇, 源册序, 原章号)**。
2. 🔴 **标题归一化只抓「完全同名」；同主题不同标题必须靠显式 SKIP 表**。
   典型重复簇：五层引擎（85 个节点 / 五层分工）、五层记忆（什么该被记住 / 让练过的动作）、
   四道安全闸 vs 安全闸分层否决、力控压入 vs SE(3) 阻抗 + 三段压入、三机分工（技术底座篇 vs 原型篇）。
   做法：合并器里维护 `SKIP = {(源模块, 标题前 8 字)}`，逐条写明**保留哪一版、为什么保留在那篇**
   （技术名词解释留在技术底座篇，部署形态留在原型篇）。
   判据：合并后逐篇 dump 标题，按前 8 字做一次簇检测，人工过一遍。
3. 🔴 **两本书的附录都叫 A/B/C/D**，直接合并会出现两个「D1｜术语表」。
   给后并入那本的附录标题加来源前缀（`产品册｜A1｜…`），或整体改 `XX-A1`。
4. **`quote()` / `section()` 的签名各册不同**（有的要空 `chapter` 占位）。合并器重建这两类页时按目标册的函数签名显式传全参，
   否则 `TypeError` 只在构建到最后几页时才炸。
5. **页数写在三处**：导读里的篇章区间、交付说明的页纲表、各册正文里的「全册结构」句。合并后一起回读。
6. **合并不丢图**：成品册里的图片/方框图是构建时画的，合并必须仍然走各自的构建函数；
   合并后回读数一遍图片页数与方框图块数，应当等于源册清单之和（去重页的图除外）。

## 验收

```bash
soffice --headless --convert-to pdf <册>.pptx --outdir . && pdfinfo <册>.pdf | grep Pages
pdftotext -bbox <册>.pdf /tmp/mn.html     # 三段几何判据：出血 / 撞页脚 / 压字
```

- 页数 == 各册有效页 − 去重页 + 新封面/导读/结语（实测三册 209 + 72 + 82 → 260 页，去掉 6 页重复）。
- 逐篇抽首末页，正文首行**不得残留原章号**（正则 `^\d\.\d`）。
- 图片页数、方框图块数与预期一致。
- 数学符号重音框（`f_θ̄`、`γ̇`）在 bbox 判据里稳定假阳性，报出页码后对一眼即可，别为它改文案。
