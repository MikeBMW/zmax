# 算力分析章（立项/方案/交付文档里回答「算力够不够」的那一章）

用户说「把算力分析补进去」时，要的不是堆 TOPS 参数表，而是**一张时间尺度的账**：哪一层要 20 ms 出结果、哪一层的推理是秒级、
算力该放在哪台机器上、现在的瓶颈在哪。章序固定六节，每节一张表 + 一段结论句。

## 1 时间尺度与单次预算（表：环节 / 时间尺度 / 频率 / 单次实测）

| 环节 | 时间尺度 | 频率 | 单次预算/实测 |
|---|---|---|---|
| 控制拍（执行收口） | 20 ms | 50 Hz | 常驻回路单周期 0.99 ms（p95 1.46 ms） |
| 视觉定位（检测+反投影） | 20 ms | 50 Hz | 单层 20.09 ms |
| 潜空间/动作前向 | 4.4 ms | 可每拍 | 单次前向 4.4 ms |
| 技能编排 | 百毫秒 | 每步 | 单层 0.07 ms |
| 任务级推理 | 秒级 | 异步 | 单层 254 ms 级 |
| 整链（端到端） | — | 异步消费 | 中位 415 ms / 最大 13 s 级 |
| 力觉采集 | 10 kHz 采样 | 降采样到 50 Hz | 采样不进拍 |

数字全部取 `reports/perf_report_*.md` 这类逐层实测报告；**每行必须写"实测"还是"预算"**，两者混排会被当成同一口径。

## 2 端侧需求测算（三笔乘除法，必须现算并写进正文）

1. **权重规模**：参数量 → INT8 权重 ≈ 参数量 MB（20,976,792 参数 ≈ 21 MB，常驻 <1 GB 量级）。
2. **单件拍数**：单件节拍 ÷ 拍周期（3.6 s / 20 ms = 180 拍）。
3. **单件模型占用**：拍数 × 单次前向（180 × 4.4 ms = 0.79 s = 单件的 22% ⇒ 「每拍都算」在算力上成立）。
4. **反证句（最值钱）**：若同步串行跑整链（180 × 415 ms = 74.7 s），是 3.6 s 目标的 **20.7 倍** ⇒
   结论落成「瓶颈不是算力，是调用时序：秒级推理必须异步，控制侧只在 20 ms 拍内收口」。

## 3 端侧平台选型（表：档位 / AI 模组 / 算力 INT8 / 内存 / 相机路数 / 力控）

- **按「内存 + 接口路数」选档，不按 TOPS 选**：多模型常驻（感知+编排+预测）时 8 GB 档余量不足，取 32 GB 档；
  TOPS 只当兜底说明。
- 🔴 **档位名不要用 L2/L3/L4**（与内部引擎分层编号撞车，读者会串味）：写「基线档 / 增强档 / 旗舰档」，
  并在文末关键词扫描时注意 `GMSL2` 里的 `L2` 是假命中。
- 模组采购价不代填：写「按供应链报价回填，已含在硬件目标成本中」。

## 4 端侧模型延迟参考（表：模型 / 参数量 / 部署位置 / 延迟）

用来论证「进拍的是 5~50M 级模型」：52M→8.4 ms、14.7M→<5 ms、21M→4.4 ms、450M→215 ms（走 gRPC）。
一句话收口：秒级以上延迟的模型只能做任务级复核，不能进拍。

## 5 算力分工（表：角色 / 部署位置 / 承担）

训练机（出量化权重）· 端侧主节点（引擎服务/页面/网关/落盘）· 机器人侧（实时闭环，只有它进拍）· 开发编排（画布/AR/报告）。
**用职能名，不写内部机型代号**（`550A/550C` 这类只在内部台账里出现）。跨界只走既有隧道，不新开端口。

## 6 瓶颈与处置（表：瓶颈 / 证据 / 处置）

必含三类：①秒级推理的异步化（缓存直通 + 提前一拍预测）②内存常驻（同刻只允许一套模型进程，超限即 OOM）
③**端侧未做同口径实测** ⇒ 列为第一个里程碑的复核判据（现有实测都在工作机，别写成 Orin 实测）。

## 7 结论段（三句）

模型多大（21 MB / 4.4 ms）· 算力档位余量（275 TOPS 档）· 真瓶颈是什么 + 复核点。**不写「TOPS 富余 N 倍」这类没实测的倍数**，
只写可核的比值（占拍百分比、相对目标的倍数）。

## 坑

| 坑 | 症状 | 修法 |
|---|---|---|
| 把工作机实测当端侧实测 | 表格写着 254 ms，读者以为 Orin 上就这么快 | 每行标设备与口径；端侧没测就写「待 M1 复测」并列成判据 |
| 只给 TOPS 和参数表 | 用户读完还是不知道够不够 | 必须有第 2 节的乘除法与 20 ms 拍账 |
| 与引擎分层编号撞名 | 出现「L3 增强档」「L2 基线档」 | 改职能/档位名；扫关键词时排除 `GMSL2` |
| 派生的乘除法不写过程 | 读者自己一乘发现对不上 | 正文把 `180 × 4.4 ms = 0.79 s（22%）` 这类算式写全 |
