# 整机外形四视图渲染（URDF + 厂家 STL）

用途：方案 PPT / 交付文档里的机器人外形、结构、尺寸、正面/侧面/俯视/透视 —— 图要能当评审依据，不是示意图。

## 先数部件，再动手画
🔴 **「机器人 = 一条臂」是想当然**：产线工位上的本体常是**混合机型**（左右双臂 + 顶视相机立柱 + 底盘箱体 + 轮 + 作业台）。
只按单臂 URDF 出图，用户一眼就打回（原话：「是有左右臂的，有顶视相机的，有底盘箱体的。这些都没有」）。

正确做法：去**产品自己的 3D 场景定义里把安装几何常量抄出来**（AR/3D 页面、场景 JSON、仿真 env 里都有），一般长这样：

```python
LARM = {"off": [0, 0.5, 0]}          # 左臂相对右臂的平移 (m) ⇒ 臂间距 500mm
CHS  = {"L": 0.600, "W": 0.800, "H": 0.750,   # 箱体 前后×左右×落地总高
        "HB": 0.680, "wr": 0.075}               # 本体高 + 轮半径（轮露出 H−HB）
TCAM = {"y": 0.25, "r": 0.070, "h": 0.328}    # 顶视立柱：在臂中线, 直径, 高
```

先列一张「部件 → 数值 → 出处（文件:行）」表，**每个数都能回到真源**。数量、安装面高度（常是箱体顶板 z=0）、地面 z、桌面高度都属于外形的一部分。

## 渲染管线（无 GL、可在工控机上跑）
1. **STL 单位必查**：厂家网格常是 **mm**，URDF origin 是 **m**。读入后先打印 bbox，量级 >10 就 `×0.001`。
   混用会渲出 272 米高的机器人，而脚本不报错。
2. **FK 用 URDF 真值**：joint `origin(xyz,rpy)` + `axis` 逐级连乘；多臂按 `LARM.off` 平移到各自安装位。
3. **光栅化自己写**：正交投影 + numpy z-buffer（2× 超采样后降采样），比 pyrender/trimesh 稳 —— headless 机器常 `gladLoadGL error`，
   取图直接失败且难查。着色用 `abs(n·L)`，与三角形绕向无关。
4. 🔴 **相机基换向决定图是不是倒的**：世界 +Z 朝上时用
   `S = [[0,1,0],[0,0,-1],[1,0,0]]`（相机 x→世界 y，相机 y→世界 −z）。写成 `+z` 会让**四张图全部上下颠倒**：
   箱体在上、臂朝下，而长宽比、墨量、KPI 全部正常，只有人眼能发现。
5. **尺寸线要画在画布内**：标注坐标由投影后的 `lo/hi` 与 `scale/off` 反算，右下标注很容易落在 `xlim` 外被裁掉。
   先把图像数组 **pad 右/下 200/110 px 白边**再画，不要改坐标。
6. **中文字体**：`rcParams["font.sans-serif"] = ["Noto Sans CJK SC", …]`（`/usr/share/fonts/opentype/noto/`），
   否则标题与尺寸数字全变方块。

## 自检（脚本一定要能自己判对错）
- **长宽比判据**：每个视图墨迹 bbox 的宽高比必须等于该视图方向的包围盒投影比（正视 = Y/Z、侧视 = X/Z、俯视 = Y/X）。
  差 → 投影轴或 pad 错了。
- **ASCII 缩略图**：把图降采样到 30×60，按墨密度映射 ` .:-=+*#%@` 打印。两条臂、箱体、立柱、轮是否在应在的位置，一屏就能看出来，
  比盲发图片可靠。
- **标注带墨量**：右/下边缘区域的墨迹非零，证明尺寸文字没被裁。

## 尺寸口径怎么写
- 总长/总宽/总高 = STL 在**指定姿态**下的轴对齐包围盒（mm）；表头必须写姿态（全零位 / 作业姿态）与**地面/安装基准**（如箱体顶板 z=0、地面 z=−750）。
- 整机总高 = 地面到最高点；与「本体高」「臂高」分开列，别只给一个数。
- 实测出来的数（臂展、末端高度）写实测并给姿态角；额定值/图纸值单独一栏。
- **未标定的量（相机手眼外参）不许用估计值顶**：写「未标定」+ 标定步骤与所需样本数。

- 图落 `docs/6-开阳-工程落地/figs_*/`，渲染脚本 `tools/render_<机型>_views.py`，拼图脚本 `tools/make_*_sheet.py`；
  改图改脚本重跑，**不手改 PNG/PPTX**。
- 发飞书等 IM 通道时：先发一张四视图拼版（带标题与口径），再发单张；文字里按「部件 → 数值」列，不写过程。
