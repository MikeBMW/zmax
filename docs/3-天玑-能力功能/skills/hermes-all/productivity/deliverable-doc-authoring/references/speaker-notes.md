# 逐页演讲备注（PPT 备注栏 + 可打印讲稿）

场景：百页级技术册交付后，用户说「每页都要写演讲备注，播放的时候能照着念，面向产品、技术和市场」。

## 一、硬判据

| 项 | 值 |
|---|---|
| 每页字数 | 70–130 字（念出来 20–30 秒） |
| 全册时长 | 页数 × 22 秒 ≈ 分钟数（288 页、均 100–130 字实测 80–100 分钟） |
| 覆盖率 | 100%，含封面/篇章页/结语 |
| 可念性 | 无半句截断（「…（45.87」）、无符号串、无 markdown 标记、无 ①②③ 圈号 |
| 分众 | 产品听「买哪一档、边界在哪」；技术听「证据与取舍」；市场听「数字与口径」 |

写法三段：**这页讲什么 → 一个能记住的结论/数字（带口径）→ 一句过渡**。
过渡句不要每页都放，按页序 `idx % 4` 或按篇控制，否则念到第二十页就出戏。

## 二、生成位置（决定会不会丢）

- 在 **builder 里随页写**：`s = L.<kind>(...)` 之后立刻 `s.notes_slide.notes_text_frame.text = note_for(...)`。
- 不要在构建后按 `enumerate(pr.slides)` 贴备注：页序一变就全错位，而且下次重建备注全没。
- **合成页要单独写**：封面、篇章页、结语是 builder 自己造的，不在内容表里（collect 阶段已按 `k in (cover, section, quote)` 滤掉），
  漏了就是「288 页里有 10 页没备注」，而字数统计看上去还挺正常。

## 三、按页型的话术表

| 页型 | 开场 | 干货句 |
|---|---|---|
| `table` | 「这张表横着是 X、Y、Z，竖着是几组对照」 | 「建议只盯两行：A 和 B」+ 页脚结论 |
| `bullets` / `cards` | 「这页讲 N 件事：A、B、C」 | 第一条的解释句 + 页脚结论 |
| `bigstat` | 「先给三个数：11.468 s 稳态单件节拍；314 件/h 节拍产能；0.105 元单件成本」 | 口径句（两班 16 h、OEE 0.85） |
| `layers` | 「从上到下是 L5…、L4…」 | 「最上面一层是 X，负责……」 |
| `timeline` | 「N 个节点，从 1948 到 2022」 | 「中间这一步是……」（+ 页脚结论） |
| `formula` | 附录页才说「符号不用念，只听结论」；业务页说「这一页给的是量化关系，会上只念结论」 | 页脚结论优先，没结论才用最后一行 |
| `nodeblock` | 「左边 N 条输入，右边 M 条输出，中间是功能本体」 | 它在节拍里的位置 / 是否进记忆路径 |
| `funcmap` / `figures` | 「左边进，中间分层处理，右边出」/「看图，A 和 B」 | 页脚结论或图注 |
| `cover` / `section` / `quote` | 固定话术 | 每篇一句过场：这篇讲什么、为什么排在这里 |

## 四、重点页必须手写（override 表）

模板生成出来是「结构对、没人味」。选 10–15 页整段替换，key 用**标题前缀**匹配：

- 封面、导读、每个新篇的开篇
- 被追问最多的技术判断页（选型、对比表、延迟账、产能账、单一大模型为何不行）
- 证据篇开篇、关键实验页
- 收尾

override 里可直接给对外的硬口径，例如「看最后一行：只有 JEPA 那列写‘可’，我们写‘是’，其余四条是‘否’或‘研究级’。
这不是说它们没价值，是说它们的价值在训练侧和场景侧，不在控制环」。

## 四·补、主题一致性：改了标题不等于改了备注（全篇重写的做法）

判据：**封面备注的第一句必须直接说出册子的主题**，并且每页结尾都有一句把该页扣回主题的「镜头句」。
只换封面标题、备注还是「今天用一小时把这台机器人讲透」 ⇒ 用户当场退回（原话：「第一页，note 提示你也没有说啊……全篇重写，主题要明确」）。

三层都要改，缺一层就读出「没改」：

1. **封面备注**（3–5 句）：主题是什么 → 为什么核心是它（用客户听得懂的因果） → 为什么形态是它 → 全册怎么走 → 随时打断我。
2. **篇章过场**（`PART_TALK[part]`）：每篇一句「这一篇在主题线上负责什么」，不要只说「这一篇讲 X」。
   例：整机篇 → 「先讲它，因为这台机器就是世界模型的被控对象：动作空间、精度、节拍，都是模型的输入约束」。
3. **每页镜头句**（`LENS[part]`）：按篇配置 2–3 句，`idx % len` 轮换，作为备注的最后一句。
   好处是全册像一个人讲的，又不会念到第二十页就重复；缺点是**篇号是索引键**，重排篇序必须同步改表（见 SKILL.md 同名坑）。

镜头句写法：不复述本页内容，只回答「这一条对主题意味着什么」。
`整机`：这台机器是世界模型的被控对象，机构边界就是模型的能力边界。
`能力`：能力的每一级，本质是世界模型能承担多大的不确定性。
`实证`：证据只回答一个问题——贡献了什么、贡献了多少、什么条件下、几 seed。
`经济`：成本账里，省的是调试与换型时间，不是硬件钱。

## 五、中文清洗与截断（都是踩过的）

1. **归一化空白用 `re.sub(r"\s+", " ", t)`，绝不能 `\s+ → ""`**：会把 `OpenAI Sora` 变成 `OpenAISora`，
   既难念，也让 override 的标题前缀匹配不上（改了空格后那几页又变回模板）。
2. `｜`、书引号统一成逗号；去掉 ①②③④ 圈号（念成「圈一采集」很怪）。
3. **截断不能切在 token 中间**：先按 `。；` 截句；仍超长就在最后一个 `，、：` 处断开并补「等」。
   反例：「11.468 s 是稳态单件节拍（45.87」——括号里的数被切一半，念出来是错的。
4. 拼接一律 f-string 或占位符 `.replace()`；**不用 `%` 格式化**（正文有 `%`、`*` 会直接抛 `ValueError`）。
5. 数字与单位之间留空格（`11.468 s`、`20 ms`），念稿的人不会念成「十一点四六八s」。

## 六、校验（脚本 + 抽读，缺一不可）

```python
notes = [s.notes_slide.notes_text_frame.text.strip() for s in pr.slides]
assert all(notes), [i + 1 for i, t in enumerate(notes) if not t]   # 覆盖率
print(len(notes), min(map(len, notes)), sum(map(len, notes)) // len(notes), max(map(len, notes)))
```

抽读至少 8 页，覆盖：篇章页、表格页、公式页、方框图页、附录页、结语。抽读判据只有一条：**念出来顺不顺、数字对不对**。

## 七、可打印讲稿（docx → pdf）

- `python-docx`，正文宋体 + `w:eastAsia`，A4 边距 2.0/2.2 cm。
- 每个篇头一个加粗小标题（`第 N 篇　篇名`，13pt 深蓝）；每页三行：
  `P023　2.05　表格标题`（9.5pt 加粗棕色）→ 备注正文（10.5pt）。
- 文本**从 pptx 的 notes 直接读**，不另存一份 —— 两份文本一定会分叉。
- 导出后 `soffice --convert-to pdf` 并 `pdfinfo | grep Pages` 核页数（288 页备注 ≈ 34–40 页 A4，随均字数变化：均 104 字 34 页、均 130 字 39 页），
  `pdftotext` 抽一页看中文是否成串。

## 八、坑

| 坑 | 症状 | 修法 |
|---|---|---|
| 备注写在构建后处理脚本里 | 重建一次全丢 / 页序一变全错位 | 写进 builder，随页生成 |
| 只给内容页写 | 10 个篇章页备注为空，统计看不出 | 封面/篇章/结语在**建页处**写 |
| 每页都加同一句过渡 | 念到第二十页就出戏 | `idx % 4` 或按篇控制 |
| 全局去空格做归一化 | 英文名连成一串，override 失效 | 折叠空白，不删除 |
| 按字符数硬截 | 数字/括号被切一半，念出来是错的 | 断在标点并补「等」 |
| 只写模板不写重点页 | 通篇「本页讲…」骨架感，用户会退回 | 10–15 页手写 override |
| 只改封面标题，备注仍是旧主题 | 用户翻到第一页就说「你也没改」 | 封面备注 + 篇章过场 + 镜头句三层同改 |
| 层名/标签带括号直接念 | 截成「L3 技能层（百毫秒…」，听着像坏字 | 念之前 `re.sub(r"[（(].*$", "", name)`，括号里的量单独说 |
| 镜头句太长、每页都一模一样 | 像口号复读，听众出戏 | 每篇 2–3 句轮换，一句 ≤30 字，只讲「对主题意味着什么」 |
