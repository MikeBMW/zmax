# 从既有单页 3D 派生「新场景页」

用途：用户说「仿照这个场景再做一个场景页，同样的机器人和桌子，具体操作我后面定义，你先把场景画好」。

## 不另写渲染器

另写一套 = 两套几何迟早画得不一样，用户一眼就看出「和原来不一样」，而且以后改一处要改两遍。
做法是**复用同一份 HTML**：在脚本最前面按 `location.pathname` 置一个场景标志（与既有 `/ar3d` 的
`vrfull` 判定同一处，顺手让新路径也进 `__BARE`），只换三样：场景默认值、左栏白名单、标题。

- 版式标志必须在脚本最前面定，否则页头/按钮会先闪一下再消失。
- 场景初始化函数在异步 init 末尾调用一次即可；函数声明会提升，放在 init 之后定义也安全。

## 场景默认值：幂等设值，不要 toggle

- 逐个赋 `true` 并同步按钮 `classList.toggle('on', true)`；`click()` 会把本来就开的关掉。
- 特别注意被原页面**默认关掉**的元素（如实验桌 `TAB.show=false`）：新场景里必须显式打开，
  否则用户看到的第一眼就是「桌子没画」。

## 左栏白名单：按「保留祖先链」逐块判

只按按钮逐个隐藏会留下非按钮残留：输入框、状态文字（「游标 215/215」「完成 1 段」）、
复选框（「真机也走」）、整块卡片（左臂位姿）。

1. 取白名单按钮集合（只要 id 在集合里就留）。
2. 自每个按钮向上走父节点到容器根，收集成**祖先链集合**。
3. 从容器根递归：在链上的元素继续下钻，不在链上的一律 `display:none`。
4. 最后把白名单按钮自身恢复显示（防上一轮误伤）。

- 异步渲染的区块（fetch 回来才有）要**多拍几次** trim（200/600/1500/3000/6000ms），晚到的按钮又会露出来。
- 容器外的面板（底部回放条、生产演练 dock、脚注）单独按 id/文案关，不要指望白名单覆盖。

## 取景：自动取景只算臂的点云

`vrFitBox` 只按臂点云算包围盒 ⇒ 大件（1600mm 长的桌子）会被画布边缘切掉（实测左边 -5px）。

- 新场景页固定机位并关 `VR.auto`（否则每帧又跳回去把大件切掉）。
- 机位用**投影自检**选，不靠眼睛：把所有大件（桌/箱体/相机/臂点云极值）角点投影，
  要求全部落在画布内且留边 ≥14px，从小到大搜 `dist` 与目标点，取第一个满足的。
- 判据要留证：写出各角点的屏幕坐标与「是否全在画布内」。

## 服务端：页面路径是硬编码白名单

- 加新路径（`/tray`、`/baipan`…）必须改路由并**重启**；页面热读只对已存在路径生效。
- 重启前先读 `/proc/<pid>/cmdline` 与 `environ`（如 `ZMAX_REPO`、`ZMAX_PLAN_SPEED_MM_S`）和日志路径，
  按原样重起，别顺手改参数；重启后立刻验新旧两个路径都 200、md5 与磁盘一致。
- 只换代码不换参数的重启脚本要带「旧进程不退就中止」的等待，别强杀。

## 交付前自检（用户会逐项核对）

- 场景元素逐个插桩计数（桌/箱体/地面/顶视相机/双臂），外加几何关系口径
  （桌在箱体 +X 前侧、桌面与箱顶同为 z=0、两臂间距、相机立柱高度与 1 轴同高）。
- 回归：原页面（`/ar3d`）标题、按钮、自动取景必须一字未变 —— 新功能一律加在场景标志分支里。
