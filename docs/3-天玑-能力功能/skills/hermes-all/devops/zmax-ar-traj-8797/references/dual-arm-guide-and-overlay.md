# 双臂引导绘制 + 画面叠加清理（tcp-ar.html / :8797/ar3d）

## 左臂只有 URDF 外形，没有控制器

- 摆位姿只用**位置 IK**（`ikTool1`）；6 自由度位姿 IK（`ikTool1Pose`）在这套 URDF 上不可靠——用右盘已知目标做对照也偏 330mm 级。
- IK 种子必须取真机示教抓取臂形（`zmax_data/rokae_sdk/real_traj_absj.json` 抓取帧的 q），并限制每关节偏差 ≤0.5rad。随手给种子会挑出大关节角，画面里就是「左臂躺下」。
- 只承诺位置：FK 对目标可到 0.01mm 级，姿态不是目标姿态，必须写进 note，别让人误读成可达姿态。
- `larmGoToPose` / `__LARM_GO__` 是纯前端仿真，不下发真机；跨机真值另走 `zmax_data/ss_live/left_arm_pose.json`。

## 3D 引导框怎么画才不被读成「偏了」

- 原点 = 模块体中心，框以原点**对称**展开 ±L/2。从原点单向拉长会让人看成位姿偏上/靠前。
- 预抓圆默认不画（`show_pre=false`）：它比件高约 40mm，会被当成位姿高度。
- 槽位几何优先取 AR 围栏盒（画面画哪个、引导就用哪个），`tray_slots_14.json` 只作回落；右盘两套编号同排 x 差约 158mm，混用会撞。

## 删除黑底文字条

- 文字底板是 `rgba(0,0,0,.6~.9)` 的小长条：在 2D ctx 上包一层 `fillRect`，判据「填充色为黑半透明且高度 ≤26px」就跳过，文字照画。
- 必须**逐画布**都包（vid / ov / loupe / vr 四块），只包主视图会「换个图层又冒出来」；加载后再补一次定时包，覆盖后建 canvas。
- 验证用像素打点：画一条黑条取样点颜色不变 ⇒ 拦住；再画一条红条颜色变了 ⇒ 只拦黑色，没伤到别的图层。
- 留逃生口（如 `window.VR_TEXT_BAR=1` 恢复黑底），调试时还要用。
