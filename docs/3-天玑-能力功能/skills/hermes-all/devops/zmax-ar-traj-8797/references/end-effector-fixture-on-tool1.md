# 在末端 tool1 上加夹具 / 夹爪 / 工装几何

需求形如「在 tool1 坐标圆心为中心，安装两个工装夹具，既能夹方盘又能夹 tray 盘，尺寸你来设计，形状参考大寰」。
做法分四步：取帧 → 自建正交基 → 画任意朝向的盒子 → 用可量判据验收。

## 1. 取帧：一律 `_frameOf`，从机器人要再转 180°
```js
var t1=_frameOf(LINKM,'tool1');                 // → {origin, x[], y[], z[]}（米）
// 从机器人 = 右臂 FK 绕竖直轴转 180° 再平移 ⇒ origin 与三轴同样被转
var o=[SLAVE.x-t1.origin[0], SLAVE.y-t1.origin[1], t1.origin[2]];
var z=[-t1.z[0], -t1.z[1], t1.z[2]];            // x/y 分量取反，z 不变
```
`LINKM[link]` 是 `{R,t}` 不是 `{origin,x,y,z}`；直接读 `.origin` 得 `undefined`，套在 `try{}catch{}` 里就成了"不报错、什么都不画"。

## 2. 不要拿末端自己的三轴当工装基准
**坑（实测）**：`tool1` 的 X 轴几乎竖直（它是模块头的轴，实测方向 ≈ `(-0.17,-0.31,0.93)`）。
直接拿它当横梁方向 ⇒ 520mm 的梁被画成**竖着的**，看着像一根杆，而夹具必须"梁水平、指尖朝下"。
做法：用工具自己的语义建正交基，靠一块直角转接板吸收朝向差（现场也是这么装的）：
```js
var hl=Math.hypot(z[0],z[1])||1e-9;
var B=[z[0]/hl, z[1]/hl, 0];     // 朝工件 = 末端轴的水平分量
var A=[-B[1], B[0], 0];          // 横向（沿盘宽，水平）
var C=[0,0,1];                   // 竖直向下（局部 +C = 往下）
```
局部点 → 世界：`o + (A*lx + B*ly - C*lz)*0.001`（几何用 mm、世界用 m，换算只在这个函数里做一次）。

## 3. 画任意朝向的盒子：自己排面序（渲染器没有深度缓冲）
```js
function gBox(g,pr,W,c,s,fill,edge){      // c=中心, s=尺寸, 均 mm
  var P=[],D=[];
  for(var i=0;i<8;i++){
    var q=pr([ W.o[0]+(W.A[0]*(c[0]+((i&1)?.5:-.5)*s[0]) + W.B[0]*(c[1]+((i&2)?.5:-.5)*s[1]) - W.C[0]*(c[2]+((i&4)?.5:-.5)*s[2]))*0.001, /* y、z 同理 */ ]);
    P.push(q); D.push(q?q.z:0);
  }
  var F=[[0,1,3,2],[4,5,7,6],[0,1,5,4],[2,3,7,6],[0,2,6,4],[1,3,7,5]]
        .map(f=>({f:f, d:(D[f[0]]+D[f[1]]+D[f[2]]+D[f[3]])/4}))
        .sort((a,b)=>b.d-a.d);            // 远 → 近
  …按 F 顺序 fillPath + 可选 1px 描边…
}
```
- 盒子的 6 个面**必须自己按深度排**，否则同一个夹具内部就会前后错乱（整套渲染都是画家算法）。
- 细窄段（指尖、拉环）不要描边：4~6px 宽的面，1.1px 棱线会把填充吃光。

## 4. 选型：行程按"最大 − 最小"算，两只对置就把行程翻倍
大寰 PGI-140-80（选型手册 CN2303 / PGI 数据表）：单侧夹持力 40~140N、**总行程 80mm**、本体 95×67.1×86、
重 1kg（不含指尖）、最大推荐负载 **3kg**、允许力矩 Mx/My/Mz 各 7N·m、Fz 300N、IP54、开闭 1.1s。
- 手册口径：**行程是有效行程**，夹大件靠专用指尖，只要"最大尺寸 − 最小尺寸 ≤ 行程"就能用。
- 要夹两种盘：方盘 230 → 托盘 380，差 **150mm**；单只 80mm 不够，**两只对置共 160mm** 正好覆盖 ⇒ 一套工装两种盘。
- 负载校核（必须报给用户，别只说"能夹"）：两侧各 140N、铝指尖对塑料盘壁 μ≈0.25 ⇒ 约 70N ≈ 7kg 名义；
  单盘（方盘 0.6kg / 托盘+30 模块 ~1.4kg）安全系数 >4，但**8 层堆叠 ~7kg 超 3kg 推荐负载** ⇒ 要换 PGHL-400-80（单侧 400N）或分两次搬。
- 用户说"两个工装夹具"时，优先做成**同一套对称双爪**（不是两个各自不同尺寸的夹具）：一个能覆盖两种尺寸的机构更容易做对，也更好解释。

## 5. 本轮采用的设计（可直接复用/微调的数值，mm，原点=tool1 圆心）
```
转接法兰  120×120×14      贴 tool1 法兰面（-Z 侧）
横梁      520×80×26       水平，沿盘宽方向（6 系铝）
夹爪本体   95×86×67  ×2    挂梁下，随跨度沿导轨各滑 75mm
L 指尖    厚14×宽70×下探60 + 底部内勾 26×70×12
指尖间距  230（方盘）/ 380（托盘）—— 工作面就是那条绿色虚线
指尖最低点 tool1 下方 169mm
```
按钮做成三态循环：`230 → 380 → 关`，文案跟着跨度走（`🧰 夹具 230`），并进 `KEEP` 白名单 +
`html:not(.sceneTray) #bGrip{display:none!important}` 反向门控（`/ar3d` 不许出现）。

## 6. 验收判据（都是可量的，不靠看图）
- 梁两端世界 z 相同（实测差 **0mm**）、梁长 ≈ 设值（520 → 跨 516mm 投影）；
- 指尖间距按 `span` 精确跟随（切到 380 后实测水平距离 380mm）；
- 指尖最低点低于 tool1 的深度（实测 169mm），否则说明基向量方向反了；
- `GRIP.show` 开关差分（**等一拍**）非零且 bbox 落在 tool1 屏幕位置附近（实测 2964px，区域 347,231~472,304）；单帧耗时不涨（实测 3.8ms）。

回复里要主动说清：真做需要 tool1 法兰孔位图（M6）、指尖悬臂下的重心/惯量与导轨规格复核；
并把"堆叠超载"这条单独点出来，别让它听成"一个夹具能搬走整摞"。
