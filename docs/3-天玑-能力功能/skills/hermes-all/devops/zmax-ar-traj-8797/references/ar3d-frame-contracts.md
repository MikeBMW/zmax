# ar3d 绘制契约: 帧原点 / 模块几何 / drawVR 长链容错

## 三种"模块中心"口径, 混用就错位半个身长

| 函数 | 参数语义 | 体心 |
|---|---|---|
| `drawModuleAt(g, pr, O, AX, ...)` | **O = 模块头部中心**, `AX=[x,y,z]` 三轴 | `O + AX[2]*(L/2)` |
| `drawModuleBox(g, pr, ...)` | 内部取 `TCP.frames.tool1.origin` = 头部中心, sgn 由 tool0(法兰)侧定 | `origin + AX[2]*(L/2*sgn)` |
| `drawFlatModule(g, pr, c, ...)` | **c = 体心**(直接按 c±L/2/W/2/T/2 画 8 角) | `c` |

**tool1 原点 = 光模块头部中心**, 本体从模块头朝法兰方向长出去。
把 `tool1.origin + [L/2,0,0]` 传给 `drawFlatModule` 等于把头部挪到 L/2 处 ⇒ 整体退半个身长 ⇒ 画面上就成了"以尾部为中心"。
判据: 两块同物体的体心必须逐分量相等, 差 `0/0/0 mm`, 不是"看着差不多"。

`TCP.frames.tool1` 的结构是 `{origin, x, y, z}` —— **没有 `R`**。
下游需要旋转矩阵时自己按列拼: `[[x[0],y[0],z[0]],[x[1],y[1],z[1]],[x[2],y[2],z[2]]]`(`_cols(R)` 返回三列 = 三个轴)。

## 本体朝向必须同号

`drawModuleBox` 用 `sgn = sign((tool0.origin − tool1.origin) · Z)` 决定本体朝哪一侧长。
另一处绘制若固定用 `+AX[2]`, 遇到 `sgn=-1` 就成"头对头、身子朝相反方向", 看着像双倍长的模块。两处必须同一判据。

## drawVR 是一条长链: 中间 return / throw 会砍掉后面全部元素

症状是**不报错**, 但桌子、方盘、模块、围栏、坐标轴成片消失 —— 因为异常或 return 发生在链的前段, 后面根本没画到 canvas。比直接报错更难查。

铁律:
- 在 `drawVR` 任何中间位置**禁止 `return`** 当"没数据就跳过"。没位姿就给画在原点、不会崩的安全占位 `{t:[0,0,0], z:[1,0,0], R:[单位阵], _none:true}`。
- 所有从真机位姿取的字段都要兜底: `_cols(_rpT1.R || [[1,0,0],[0,1,0],[0,0,1]])`。
- 改完必须回读验证三件: 无 JS error + 关键开关对象在场(`TPAN*.show` / `TAB` / `MOD*.show`) + canvas 数量正常。只看"页面打开了"不算。

## 新变量名别撞已用名

同一作用域里 `_rpC` 之类短名常已被占用(颜色数组、坐标数组)。加新变量前 grep 该名在本函数内的出现, 撞名不报错, 只会让颜色变成数字、静默画错。

## 不要在三维画面上压文字牌

42px 高、黑底白框的"尺寸牌 / 状态牌"横在画面上会挡视线。尺寸与状态另有承载(`🧪 实验桌` / `📦 箱体` 按钮、顶部开关 on/off), 画面上只留贴着模型走的尺寸线(dimension line)。

## 视角是用户的观察状态, 不许被逻辑改写

单步 / 刷新 / 自动对齐游标之后视角不要跳回默认: `VR.tgt / VR.dist / yaw / pitch` 属于用户当前观察状态。"对齐游标"只读同步帧号, 不改视角。

## 同一物体只画一次

真机位姿(`TCP.frames.*`)和幽灵臂/回放位姿(`PREV.M.*`)是两个来源, 同时各画一份就会出现"同一模块两个、错开一截"。真机位姿可用时以真机为准, 幽灵臂只做兜底。
