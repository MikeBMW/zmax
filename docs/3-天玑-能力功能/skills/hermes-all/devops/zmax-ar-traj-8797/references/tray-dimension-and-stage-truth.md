# 托盘/方盘尺寸与"当前阶段"的口径 (ar3d / tray 页)

> 读这一篇的时机: 老倪说"按方盘的尺寸画 / 尺寸我确认了 / 现在还是插入阶段你显示拔出" —— 改 
> 4#方盘几何 或 改阶段显示之前。SKILL.md 已到尺寸上限, 新增口径一律落在这里。

## 铁律 1: 标称尺寸为准, 相机反推只能当核对

用户/图纸确认过的标称(例: 4# 方盘 315×230×40 · 盘内光模块 149.7×22.58 · 2 排 × 8 个)是**唯一依据**。
相机像素反推只能用来**核对**, 一旦冲突, 先怀疑自己的标尺层级(深度/平面/外沿 vs 内腔), 不要改标称去迁就实拍。

- 排布可行性用**内腔**算: 壁厚 5 ⇒ 内腔 220×305; `8×22.58=180.6 ≤ 220`、`2×149.7=299.4 ≤ 305` ⇒ 装得下且居中。
- 要说"尺寸不会被别的按钮/动画覆盖"之前先搜一遍运行时写入:
  `grep -n 'TPAN[A-Z0-9]*\.\(L\|W\|H\|cx\|cy\)\s*=' tools/web/tcp-ar.html` —— **零命中**才能下这个结论。
- 老倪说"尺寸我确认了"时, 他要的是**按标称画**, 不是再拿相机量一遍; 回话只给两条硬数字: 定义值 + 投影范围 mm。

## 铁律 2: 盒体厚度要核对"底面与顶面是否取自同一基准"

典型 bug: 顶面 `zt = T.H`(40mm), 底面写死 `zb = 0.008`(桌面板厚) ⇒ 屏幕上那个盘只有 **32mm**, 差 8mm。
肉眼看不出来, 但与标称不符, 而且**只有回读数值才能发现**。

- 定式: `zt = H + z0` / `zb = z0`; 桌面板厚另设一层, 不许混进盒体。
- 验收: `tpanRange(T)` 回读 `x1-x0` 与 `y1-y0` 必须精确等于 `W` / `L`(毫米), 再谈外观。
- 多尺寸互校: 盘宽/盘深/盘内标尺物体各自换算, 若互相矛皾(算出的盘宽 481mm 而标称 315mm) ⇒
  是标尺层级用错, **不是实拍与图纸不符**。

## 铁律 3: "与实拍不一致"拆成 尺寸 / 颜色 / 位置 三件事分开回

- 实拍是**哑光黑腔 + 白或浅灰翻边**; 渲染若是棕色系(`#8a5a2b` / `#4a2f16` / `#e0b070`) ⇒ 该说"外观与看到的不一致",
  但这**不等于尺寸错**。改颜色与改尺寸分开报, 别混成一句"改了"。
- 三个同 SKU 的盘(左上/中/右上)要**一起改**, 并留一句"要退回原色说一声", 否则现场会以为整排盘被换掉。
- 渲染看着"不像方形"时先给透视这条路: 315:230 在斜视下会被压扁 ⇒ 用正上方机位或"对准"再量, 别急着改 L/W。

## 铁律 4: 阶段/节拍显示只认真机游标 + 几何, 不认仿真时间

反例(真机在插入, 页面显示"拔出"): `mtNow()` 在 `PLANT.on` 分支里按 `PLANT.simT % cycle_s` 取块 ⇒
**时间轴自己转**, 与真机进度脱钩。

正确来源优先级(固定):
1. **真机游标** —— `/api/arm/step_traj/status` 的 `cursor` 落在哪一段;
2. **该段的几何证据** —— TCP 与孔口/到位坐标的关系;
3. 才是状态空间指令里的 `mt_id`。

- 段名不许只按索引拍脑袋, 必须用**几何**交叉校验: 孔类动作的判据是 `x` 落在"下口 → 插到位"区间
  (例 761.3 → 811.6; 实测 TCP `x=776.2 / y=228.0 / z=193.0` ⇒ **在孔内**, 不可能是"拔出")。
- 老倪对着屏幕说"现在还是插入阶段"时: 先量游标 + TCP 再动手; 动手前把**完整段表**(16 段全列)贴给他确认 ——
  他会自己指出哪段对不上; 替他猜只会改错一处再来一轮(他随时会说"等等, 我再看看")。
- 段名一改要**三处同步**, 否则页面/报告互相打脸: `tools/replay_derive.py` · `tools/ss_meta_task_ar.py` ·
  执行器落盘的 `_cap.segs`(`zmax_data/rokae_sdk/traj_step_out.log` 尾部可读到当前生效的那份)。

## 铁律 5: 声称"毫米级对齐"前先读手眼残差

`zmax_data/calib/handeye_tcp_cam.json` 的 `residual`(`axxb_rot_deg` / `axxb_trans_mm` / `consistent_trans_mm`)就是闸门。

- 实测残差 **12.5° / 92.4mm** ⇒ 反投影误差几十毫米, 比"厚度少 8mm"大一个量级 ⇒ **如实说做不到毫米级对齐**,
  更不要拿这种外参去校准标称尺寸。
- 要毫米级只有两条路: 重标(用已有轨迹配对数据即可, 不必新增动作), 或"标称尺寸 + 现场确认落位"。
- 对外口径三句分开: 尺寸按标称 · 外观按实拍 · 位置受外参限制 —— 别让一句"改成你看到的样子"盖住精度缺口。
