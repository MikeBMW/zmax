## When to Use (触发 · 何时用)
要把真机工件调进某台相机的视野/对准某个特征, 靠"拍照 → 小步移动 → 再拍"收敛。
已有一件成熟范本: 10082 金手指的 `tools/aoi_gold_servo.py`(`check` / `teach` / `calibrate` /
`serve`, 母版是它); 10083 侧面检测照它同构建。
臂侧发货机制(解锁序列/闸门/速度换算)看 `real-arm-motion-control`; 检测服务接口看 `zmax-aoi-service`。
本技能只管**闭环本身的亏法顺序**。10083 侧面检测的通道/常量/工具/参数真源见
`references/aoi-surface-10083.md`。

## 顺序 (不许跳, 跳哪一步都会白干)

0. **前置** (缺一不动): 臂 `operation_state=idle` + `mode=automatic` + `power=on`;
   真动已授权(8793 两步授权, 窗口 300s, 默认未授权); `tools/motion_beep.py` 已在跑(警报在先);
   一次只发一条运动指令。
1. **只读基线**: 真值帧龄 + 静止(2s 漂移 ≈ 0); 调一次检测程序, 读**它自己的判据/分数**(不是我自己看图)。
2. 🔴 **先证反馈通道** —— 最容易跳过, 跳过就是拿噪声当偏差动机器人:
   - **统一口径取图**: 每次都是“触发检测 → 读结果 → 再取图”;
     **绝不用实时抓帧与检测帧混着比**(光照/曝光不同 ⇒ 假位移), 也不要把不同时刻的帧当同一帧比。
   - **帧有效性门**(任一条不满足 ⇒ 本次测量无效, 不得据此下发):
     与上一帧差异 < 阈值 · 过曝(高亮)像素占比在 ~[1%,35%] · 特征中心距目标 ROI ≤ ~600px ·
     相邻帧特征位移 ≤ ~80px(超了 = 换了场景, 不是臂动了)。
   - **触发失败要重试到成功**: 取图接口会间歇失败(5xx); 失败时返回的图可能是**上一次成功的缓存帧** ⇒
     拿它算出的“位移”与当前位姿无关。
   - **验收: 两次静止测量** —— 臂不动、两次量到的特征位置几乎一致 ⇒ 通道可用;
     不一致 ⇒ **只报通道问题, 不动机器人**。
3. **标定 (真动 2 次)**: 同轴、每次 **≤2mm**、其余轴不动; 两次都用**有效**测量 ⇒ 得出 px/mm 与
   "图像上下 ←→ 基座哪一轴 + 符号"。**不猜方向**; 若两次位移 < 3px(测不出比例) ⇒ 换另一轴重试, 别加大步长硬凑。
4. **闭环**: 单步 ≤2mm · 单轴累计 ≤15mm · 迭代 ≤25 · 收敛 ~12px · **跳变闸 3×**
   (一步后位移 > 3×标定量 = 异常, 立即停并报)。
   目标偏差远超累计限幅时 **不许加大步长** —— 要么先按两点转移铁律(垂直抬 ≥50mm → 横移 → 到目标上方 → 垂直下落)
   把工件送到观察位附近再伺服, 要么交现场人做; 直接拿微调去补百毫米量级的差既无效也不安全。
5. **停与报 (fail-closed)**: 收敛 / 超限 / 迭代到顶 / **判据不可靠**(检测程序自己说没拍到位、
   或分数低于门限) 任一 ⇒ 停。
   汇报**分两栏**, 不许混: ①运动链(授权 armed · 警报在跑 · 微动前后真值差 · 是否复位)
   ②反馈链(触发成功率 · 判据字段原文 · 特征是否落在 ROI)。混在一起现场会把"反馈坏了"误读成"臂坏了"。

## 铁律
- 判据用**检测程序自己的输出**(judge/score/defects), 不用我自己阈值算出来的图 —— 我算的好不等于工件对。
- 每步后回读真值; 相对步进按**当下实测**位姿算目标; **上一条未起步前不得发第二条**(两条在途会互相覆盖目标)。
- 限幅/收敛/tol/重试次数写**单一真源 JSON**(如 `data/config/*_params.json`, 每项带 value·unit·range·说明·代码位置),
  不散在命令行常量里; 默认 dry, 只有显式授权才真动。
- **反馈不可信时宁可只做最小验证步然后停** —— 这不叫保守, 是唯一正确的选择。
- 诊断期可用**最小的、双向可复位**的微动(1~2mm, 慢速, 先抬后降)同时验运动链与反馈链; 做完**退回原位**才算收尾。

## 坑
- 抓拍间歇失败 + 服务端返回缓存帧 ⇒ 假位移(先用有效性门卡住)。
- 不同曝光/光照的帧互相比较 ⇒ 假位移(所以必须同一口径取图)。
- “图像里特征动了”不等于“臂动了” —— 先看真值; 反之“判不出”也不等于“位置错”(可能只是曝光/光窗状态变了)。
- 相对步进累积漂移 ⇒ 长距离循环用绝对位姿, 不要靠一串相对小步。
- 只看“已下发”就下结论 ⇒ 必须看真值位姿前后差。
