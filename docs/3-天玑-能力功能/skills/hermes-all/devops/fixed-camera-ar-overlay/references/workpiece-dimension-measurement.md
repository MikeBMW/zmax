# 单目测工件尺寸: 能测几维、尺度从哪来、怎么防假数

给工件(光模块/SFP/QSFP 类细长件)出长宽高时, 先想清楚这三件事, 否则量出来的数会又像又不对。

## 1. 一个视角只有 2 个自由度

一个相机只能定**两条可见棱**。细长件通常是「长 + (宽或厚)」, 第三个维度**必须**换视角或拿深度:

| 情形 | 能测 | 不能测 |
|---|---|---|
| 侧面正对镜头 | 长 L · 厚 T | 宽 W(朝镜头, 无纹理/无台阶就无从下手) |
| 顶面斜看 | 长 L · 宽 W | 厚 T |

交付时必须逐维标注来源: **实测 / 标称 / 未直测**, 三者不许混写。用户要的是“你量了”, 不是“你查了”。

## 2. 尺度(mm/px)只有两个合法来源

- **已知距离**: `mm/px = Z / f`。Z 要么来自深度传感器, 要么来自“工件此刻正被夹在 tool1 上”这一前提下的手眼距离。
- **位移法**(无深度也能绝对量): 同一静止工件, 相机沿已知位移 Δ 拍两帧, 视在尺寸 w₁→w₂ ⇒
  `Z₁ = Δ·w₂/(w₁−w₂)`; 再代回 `mm/px`。它同时把未知的 f 与未知的 Z 一起解掉。

🔴 **最常犯的错**: 工件**平放在台面上**时仍拿“手眼算出的 244mm”当 Z。那个 244mm 是**夹爪尖到相机**的距离,
只在工件真的夹在 tool1 上时才对得上; 工件躺在桌上时 Z 未知, 套 244 会把长度系统性算大或算小。
先确认工件空间位置, 再选尺度来源。

## 3. 提高对比 ≠ 降低假阳性

- **换深色底板**是最省事的一步: 实测暗像素(<60)从“大片”降到 3%、亮目标(>150)占 19%, 边界立刻干净。
- 但“最亮细长块”这个判据本身会抓**亮度斜坡**: 底板明暗过渡、折痕高光、白纸边缘都是细长、都够亮。
  判据: 比较**框内 vs 框外**的亮度均值/标准差 —— 实测 130.2/14.7 vs 131.2/14.8 = 零差异 ⇒ 框里根本没东西。
- **多档阈值一致性**是最便宜的闸: 同一候选在 th=160 与 180 下给出同一 bbox(±2px) 才算实体;
  阈值一变候选就换位置 = 抓到的是渐变不是边界。

## 4. 端点与被遮挡段

沿长轴做行/列亮度剖面找**台阶**定端点; 一端被夹爪/拉环咬住时只能给「**可见长**」, 不许当全长报。
端面判定要用放大图或视觉复核(±5px), 因为暗侧与接触阴影亮度接近。

## 5. 跨视角互证(最强的自检)

同一个零件两次成像(不同机位/不同底面):

1. **长度像素应基本一致**(实测 83px vs 81.5px, 差 1.8%) —— 差太多说明其中一次不是同一个件或被截断;
2. **长宽比对型号表**: SFP+ 56.5×13.4=4.22 · QSFP28 72×18.4=3.92; 实测比例落在两者之间就说“仍待定”,
   不要为了收口硬选一个型号;
3. 两次看到的**是不同的一组相邻面**(一次顶面+侧壁、一次纯侧面)时, 两维各自可信, 第三维仍缺。

## 6. 结论怎么写

```
L 56.5mm —— 实测可见 50.2mm + 被夹尾段, 与标称一致
T  8.5mm —— 未直测(该视角看不到厚度), 标称
W 13.4mm —— 未直测, 靠长宽比 4.2:1 旁证
```
把“缺哪一维、为什么缺、怎么补(换视角 / 位移法 / 双机 PnP)”写在结论里, 比给一个漂亮的假三元组有用。
