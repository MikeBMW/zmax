# 流形层 / 记忆层怎么接进 L2·L3 (画布拓扑 + 实测状态)

回答「流形引擎、性能流形、接触流形如何与 L3/L2 对接」「各层记忆怎么共享」时的固定口径。
**拓扑从 `flows/state_space_obs.json` 读，不要凭印象**；拓扑只证明声明，联通与否按上文端口级验证器实测。

## 流形层 = 一个母体 + 两个子流形 (不是三个平级节点)

`ss_mani_eng` (流形引擎) 吃 6 路、吐 5 路:

| 端口 | 来自 | 含义 |
|---|---|---|
| in1 | sssensor | 43D 状态 x |
| in2 | ssobs | SU(2) 统一状态 → 群约束 |
| in3 | sscalib | 几何标定 → 度量/势场参数 |
| in4 | sslat | 潜坐标 |
| in5 | ss_moe | 阶段先验 → 条件化 |
| in6 | n_calib_mani | **M = 状态空间结构参数 (等效惯量, 默认 1.0, 0~8)** |

| 端口 | 去向 | 含义 |
|---|---|---|
| out1 | n_intent_direct / ssintact_dec | 驱动扭矩 T_drive = M·(−∇Φ) 6D + 意图 Δz |
| out2 | ssmani_exp | 流形坐标 p + 测地线 γ |
| out3 | ssmani_c | **接触流形势能 Φ_c**(分给接触流形) |
| out4 | ssmani_p | **性能流形代价 V_p / η**(分给性能流形) |
| out5 | sssched | 动作指令 a(解码器输出) → L2 调度 |

分工: **引擎算势能与梯度, 按性质分给两个子流形做局部计算**。

- 接触流形 `ssmani_c`: in1←潜空间 z · in2←Φ_c · in3←M; 算 `e∥`(测地线进度)/`e⊥`(离流形漂移), `V=½‖e‖²`
- 性能流形 `ssmani_p`: in1←潜空间 z · in2←V_p/η; 算 `δ=光模块头−孔底`, `V_p=½δᵀWδ`, `η=exp(−V_p/σ²)`
- 两者 + `sslat`(潜空-流形) **一起汇到 `ssdec.in5`** = 与 L2 动作生成层的唯一接口
  (`flow_matching_impl.py::_l4_in_summary`: in1 潜空间 z/L4 条件, in5 接触/性能流形坐标)

## 记忆层 = 四条通道 (不是一条总线)

1. **垂直叠加 → 一个意图**: `ss_mem_l2`(Φ_SK 技能势场) · `ss_mem_l3`(Φ_process 流程势场) ·
   `ss_mem_l4`(Φ_global 工作空间势场) 全汇 `ss_mem_field`, 在引擎当前状态处算 Φ 与 **−∇Φ** → `sssched.in1`
2. **图谱建链**: L2/L3/L4 → `n_mem_links` → `ss_mem_share.in7`
3. **总装中枢**: `ss_mem_share` 吃 7 路 (三层记忆回馈 + `n_eng_mem` + `n_vlm_llm` + 图谱), out1 反向下发给
   L4/L3/L2 + `ssllm` + `ssreason` + `ssfeat` —— **中枢不存内容, 只汇总再分发**
4. **直接赋能 (最快)**: `ss_mem_l2` → `ssff.in1`(标杆 u_ff 快通道, 权重 30%) 与 `sssk1..8.in3`(每段通道参数 r/L/单拍/标杆/点位)
   ⇒ 「肌肉记忆为什么快」= 它不经过势场叠加, 直接喂前馈与原子技能

实现位置: `src/lerobot/memory/mem_nodes.py` (71/150/203/257/511 行起), 不在 `middleware/nodes/impl/`。

## 这类节点的断点特征 (实测, 与 L2 主干同构)

- 接触/性能流形: 转调壳指向 **不存在的** `impl/ss_mani_p.py`; 真实现一直在 `ss_mani_c.py`(按 `"接触"/"性能"` 分流),
  却没有任何注册引用它 ⇒ 两个节点点了必崩。
- 记忆层: `return _out if isinstance(_out, dict) else True` ⇒ 值有、键名不是 `out1` ⇒ 画布端口全空。
- `n_calib_mani`: 扁平 `_NodeOut` ⇒ out1/2/3 全空 ⇒ 引擎拿不到 M。
- 子图实测: 20 节点/45 边 **20.0% → 64.4%**; 残 15 条中 11 条需引擎播放态、3 条 `ss_moe` 建设中、
  1 组 `sscalib` 只打日志不交结构化数据。
