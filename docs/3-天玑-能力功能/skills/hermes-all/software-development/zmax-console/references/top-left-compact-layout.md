# 侧栏 / 左上角“空间减少”—— 只留版号也不许清一屏

（搜索锚点: 左上角 / 返回首页 / 版本显示 / 空间减少 / 侧栏紧凑）

## 用户口径
「左上角『← 返回首页』上面的空间太空旷了，只有一个版本显示 ⇒ 空间减少，只要显示版本即可」。
这不是让你删信息，而是**同样的信息占更少高度**；界面铁律仍是字少/不挤/不截断。

## 五参数同时改，少一个都看不出效果

那一块通常是一个 `QHBoxLayout`（`◀` 收起键 + 版本 `QLabel`）压在 `QVBoxLayout` 顶部，外层是侧栏布局。
只改字号会被行高与边距吃掉，看上去“没变”。

| 参数 | 改前 | 改后 | 为什么必须一起改 |
|---|---|---|---|
| 版本字号 | 19px（weight 600） | 13px（weight 600） | 字是块高的主项，但不唯一 |
| 版本行高 | 跟随字号 | `setFixedHeight(20)` | 固定住，避免字号变了 Qt 又按字体行距撑开 |
| 收起键 | 宽 34 | `setFixedSize(26, 20)` + 字号 15→11 | 否则一列里它是最厚的那块 |
| 外层 contentsMargins | `(12, 16, 12, 16)` | `(12, 8, 12, 10)` | 上边距就是用户眼里的“空旷” |
| 卡片间距 setSpacing | 8 | 6 | 同一列，口径要一致 |

实测：块高约 60px → 约 34px（上边距 8 + 行 20 + 间距 6），省下的高度留给下面卡片。

## 侧栏宽度参与计算 ⇒ 缩字号后要重算，不能变窄

侧栏宽度取 `max(最小宽, 收起键宽 + spacing + 版本 sizeHint + 内边距 + …)`，版本字号一变 `sizeHint` 就变。
改完把算式里的常数（收起键宽 34→26）同步改掉，并确认结果仍 ≥ 最小宽；
不要把最小宽调小来“配合”紧布局 —— 那会让别的卡片被截断。

## 不改代码就不能验，别硬开 GUI

运行纪律是**只可停不可起**，改完布局不能自己启控制台截图验收。交付口径：
- 报 before/after 参数表（上面那张）+ 换算出的块高（可复核，不是感觉）；
- 明说“重启控制台后才看得到，我不动在跑的进程”；
- `py_compile` 必须跑：布局写错编译层不报，启动时才炸。

## 坑
- **patch 样式块要整段替换**：`setFixedWidth` + `setToolTip` + `setStyleSheet` + `setFont` 是一块，
  只改 `setFixedWidth` 会留下“宽度 26 + 字号 15”的拼接，视觉上就是挤。old_string 带全整块，改完 `py_compile`。
- **别为腾空间删掉收起键/标题**：他要的是“只显示版本”，不是“没有功能”；控件可以变小，不能消失。
- **版本号本身不同步这里**：侧栏/状态栏/关于框的号都走 `bump_version.py` 一套（见 zmax-release-versioning）。
