# docs 七星结构 (Z-MAX) — 归属判定与只读规矩

与配置中心七阵同源, 唯一依据 `tools/gui/ss_seven_stars.py`(星名/次序/主司/定义都写在那一个模块里)。
`docs/` 顶层只允许 7 个文件夹。

| 星 | 文件夹 | 定什么 | 收什么 |
|---|---|---|---|
| 一 天枢·贪狼(木) | `1-天枢-产品边界/` | 定边界 | 产品等级与形态、硬件平台、技术协议、SOR 供应商要求、交付包、专利、竞品 |
| 二 天璇·巨门(水) | `2-天璇-作业任务/` | 定作业 | 任务与工序、AOI/AR 场景、工位定义、抓取放置流程、插拔状态机 |
| 三 天玑·禄存(土) | `3-天玑-能力功能/` | 定能力 | 功能单元、特征库、原子技能、能力清单 + `skills/`(Hermes 技能镜像) |
| 四 天权·文曲(水) | `4-天权-模型算法/` | 定算法 | 模型与训练、策略、流形引擎、感知算法、INTACT/L4、LoRA |
| 五 玉衡·廉贞(火) | `5-玉衡-指标验收/` | 定指标 | 节拍/UPH、评测分析、实验结论(含负样本)、`test-reports/` |
| 六 开阳·武曲(金) | `6-开阳-工程落地/` | 定落地 | 架构与接线、参数与配置、部署运维 `ops/`、现场补丁 `patch/`、接口规范、数据地图、状态快照 `data_snapshots/`、发行 `release/` |
| 七 瑶光·破军(水) | `7-瑶光-记录追溯/` | 定记录 | 交接与收工、事故台账 `incidents/INCIDENT-INDEX.md`、复盘、版本小结、工程记忆 `memory/` |

## 一句话归属判定

1. 说**卖什么、边界在哪** → 天枢
2. 说**这道工序怎么干** → 天璇
3. 说**某个功能/技能怎么用** → 天玑
4. 说**模型怎么训、怎么算** → 天权
5. 说**多少秒、多少毫米、达标没有** → 玉衡
6. 说**接口怎么接、参数在哪、怎么部署** → 开阳
7. 说**谁在何时做了什么、出了什么事** → 瑶光

判不准就看主司; 一份文档只归一颗星; 找不到归属说明它还没想清楚, 不要为它新开目录。

## 三条只读规矩

1. `3-天玑-能力功能/skills/` 与 `7-瑶光-记录追溯/memory/` 是 `~/.hermes` 的**镜像** —— 要改改源(同步脚本在 `tools/`), 不在 docs 里改; `memory/` 还被工程记忆模块真读, 别改名。
2. `6-开阳-工程落地/data_snapshots/` 是证据快照, 按日期冻结, 只增不改。
3. `5-玉衡-指标验收/test-reports/` 里被 `verification_layer` 按路径校验的文件, **缺文件即判 FAIL**, 不许改名挪位。

## 命名

```
方案    <主题>_<YYYYMMDD>.md
记录    <YYYY-MM-DD>_<主题>.md
事故    INCIDENT-<YYYYMMDD>-NN-<主题>.md
交付    带版本号或客户名, 不加日期后缀(日期用 mtime)
快照    data_snapshots/<YYYYMMDD>_<版本>_<主题>/
```
