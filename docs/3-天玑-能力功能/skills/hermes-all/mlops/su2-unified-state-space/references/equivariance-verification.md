# 对称性「真实现」四项硬检验

用途：当有人说「我们用对称性/群等变做泛化」时，把这句话拆成可测命题当场量。
过了才敢写进竞品分析/对外材料；不过就是真实缺口，不许吹。
脚本：`~/zmax/tools/ss_symmetry_equivariance.py`（真机 400 帧 → SU(2) 流形，一次跑完四项）。

## 数据与前提

```
轨迹: ~/zmax/data/database/zmax/sources/canvas/ss_traj_last.json   (400 帧 × obs43)
引擎: ManifoldEngine(manifold_type="su2", latent_dim=16, state_dim=43, action_dim=4, manifold_M=3.643)
      + models/manifold_engine.npz
投影: p = engine.project(row)["p"]  → 4 维单位四元数（若维数≠4，群作用只能取前 4 维，行为会失真）
预测: lerobot.manifold.orbit_predict.OrbitPredictor(manifold="sphere")
```

`M` 必须取**常驻引擎实际用的值**（当前 3.643）。阈值是给某个引擎调的，换 M 等于给另一个引擎调参。

## 四项命题

| 编号 | 命题 | 量法 | 判据 | 不过说明什么 |
|:--|:--|:--|:--|:--|
| E1 | 等距性 | 左乘群元素 q_g 前后，相邻点测地弧长的相对差 | < 1e-6 | 群作用实现错（不是数学问题，是代码问题） |
| E2 | 预测等变性 | `dist(predict(q·p,k), q·predict(p,k))` 归一化到步长 | < 1e-4 | 表示里混进了绝对方位/绝对坐标，跨位姿会掉 |
| E3 | 判定不变性 | 旋转后 `valid` 标志翻转数 + `err_rad` 相对漂移 | 翻转 0 且漂移 < 1e-9 | 判据依赖绝对方位（最隐蔽，会让换工位失效） |
| E4 | 零样本换位姿 | 同段一步预测误差 vs 整段旋转 90° 后的一步预测误差 | 惩罚比 < 1.5 | 换位姿要新数据，「对称性可替代数据」不成立 |

E4 是唯一有商业含义的一条：它直接对应「换工位/换朝向要不要重训、重标定」。
E1–E3 是它的前置条件，通常一起过或一起崩。

## 实测基线（回归参考，真机 400 帧）

```
基线 symmetry_residual: speed 0.00214942  drift 0.186  accel 0.0366  bend 21.28
E1 等距性        2.470e-09      PASS
E2 预测等变      6.477e-06      PASS
E3 判定不变      漂移 0.000e+00，valid 翻转 0/400   PASS
E4 零样本换位姿  同段 0.0778×步长 → 旋转90° 0.0648×步长，惩罚 0.83×   PASS
```

E4 的 0.83× 是最强的证据形态：**旋转 90° 后误差比原轨迹还低 17%** ⇒ 表示里没有任何「这个朝向」的绝对量。
换位姿不需要新数据，靠群作用传递。这一句可以直接写进对外材料，且可复跑。

## 坑（三个都会给出「假的 FAIL」或「假的 PASS」）

1. **四元数双覆盖 q ≈ −q**：比较前**两侧都要归一到 w≥0**（`canonsafe()`）。
   只归一化一侧 ⇒ 目标点是反号四元数 ⇒ 测地距离算出 π ⇒ 假误差 965×（实测踩到）。
   任何「两个四元数差多少」的比较都先过这一步。
2. **闭环外推必漂**：量「速度场能否跨位姿迁移」必须**开环一步**——每拍都用真实历史估速度，
   只预测下一步。闭环多步会把累积漂移当成不可迁移（实测同段误差从 0.078×步长 涨到 57×步长，
   结论会完全反过来）。区分「模型不准」与「闭环漂移」是两类问题，别用一个口径量。
3. **float32 引擎地板**：阈值写 1e-12 会把正确实现判成 FAIL（实测 E1 地板 2.5e-9、E2 6.5e-6，
   都是步长 2.1e-3 下的绝对量 5e-12 与本征累积）。判据用 E1 < 1e-6、E2 < 1e-4，并在注释里写清
   「这是数值等价，不是精确恒等」。
4. **误差一律除以中位步长归一化**（`err_rel`）。绝对误差随速度/尺度漂移，换一段轨迹就不可比。

## 能证明什么、不能证明什么（诚实边界）

- 证明：**表示层与判据层**对群作用等变 ⇒ 换位姿不需要新数据。
- 不能证明：执行层任务成功率。等变 ≠ 抓得到，还要另测「同一任务在 N 个对称位姿下的首次成功率一致性」。
- 不能证明：跨本体。换臂后运动学/力控不同，对称性只保证几何关系，不保证新本体动力学（那是 TCT 的事）。

写对外结论时按这三层分开说，别用「对称性解决了泛化」一句话盖过去。
