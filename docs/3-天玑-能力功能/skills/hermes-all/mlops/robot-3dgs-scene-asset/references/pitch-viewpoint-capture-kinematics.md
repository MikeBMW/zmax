# 俯仰/斜视视角的采图运动学(给重建喂多视角)

只给平移视差(横线来回走)时, 孔口内壁、立面、遮挡背面全是"看不到的东西", 重建只能拿同一面糊出来。
补俯仰是必须的 —— 但**手腕怎么转**有两个坑, 转错一次就是真撞工装。

## 一 · 要转的是 TCP, 不是法兰

工具从 tool0 到相机/TCP 有长度 L(从 URDF 取, 本机实测 259.8mm)。

- ❌ 固定法兰位置只改姿态: 工具尖沿圆弧走, 位移 = `L·sinθ`。12° ⇒ **54.1mm**(足以撞面板)。
- ✅ 绕 TCP 点转: 法兰必须跟着平移

```
p_flange_new = p_tcp_target − R_new @ [0, 0, L]
```

把 `(p_flange_new, R_new)` 交给 IK 得 6 关节角, 再 `MoveAbsJ`。修正后同一 12° 的 TCP 漂移从 54.1mm 降到 **3.8mm**。

## 二 · 只在关节空间下发姿态

控制器 `cartPosture` 的 rpy 在 |角|≈π 附近**表示歧义**(同一姿态多种等价欧拉写法), 按 rpy 增量下发会把臂甩出去。
定式: URDF FK → 绕 TCP 点改姿态 → IK → `MoveAbsJ`; 平移段仍可用笛卡尔, 但 rpy **只原样回传实测值**, 绝不自己加减。

## 三 · 规划期就要打出的四个数

1. `max_dj_deg` — 相对基准的最大单关节变化(跳构型就在这一步暴露)。
2. 位姿误差(mm/°) — IK 残差; 超 5mm 就换角度。
3. 面板间隙(mm) — 最近连杆/工具到工装面的距离。
4. TCP 变化(mm) — 下发后**实测**, 不是算的; >25mm 立即停。

不可达时**换符号/换更小角度**, 不要"加大角度硬试": 实测 +12° 的 IK 误差 110mm/13.8°, 而 +6° 是 0.01mm。

## 四 · 采集参数(已验证可用)

- 俯仰档: `0° / −12° / +6°`(正向受关节限位, +8/+10 不可达)。
- 每档沿同一横线来回扫, 每段核: 关节误差 ≤0.5° · 每段 TCP 偏差 ≤2mm · |ΔF| ≤25N。
- 取图 10Hz, 用 STOP 文件收工; 3121 帧 / 3106 唯一 / 269MB 可训有效集。
- 每帧相机位姿 = TCP 真值 × 手眼外参; 建集时逐帧回算 `|t|` 看是否常数(实测 244.1mm ±0.1)才算位姿可信。
