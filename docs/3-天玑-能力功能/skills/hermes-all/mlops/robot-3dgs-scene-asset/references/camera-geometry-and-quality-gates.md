# 相机几何口径 与 3DGS/VLM 质量门

## 1. 标定分辨率 ≠ 流分辨率，换算不是等比放大
标定文件常是 640×480(4:3)，实际流是 1280×720(16:9)。直接 ×2 换算内参会让投影整体偏移约 100px。
正确口径：与标定等比的那一块是 ×1.5（640→960 / 480→720），横向再多加裁切偏移。
实测 1280×720：fx 591.1 fy 590.2 cx 637.7 cy 358.0（由 640×480 标定 ×1.5、cx +160 得）。
判据：拿已知 base 点（插口口沿、面板角）投影到画面，落在目标上才算 K 对；偏一片就回查是不是 ×2。

## 2. “轮廓糊不糊”要用梯度量，不要用 PSNR
PSNR 是整幅平均，暗色工件轮廓塌了它几乎不动。取真值与渲染图在工件边缘的梯度幅值对比：
实测 真值 5.3~5.7 → 渲染 0.8~1.4（掉约 6×），同时颜色从 (27,58,41) 被冲淡成 (35~65,58~70,41~65)。
掉 3× 以上就判定“轮廓丢”，此时先查致密化/剪枝，不要先调学习率。

## 3. 剪枝过狠是“糊”的头号原因
refine-stop 之后高斯数从 117678 剪到 34515，细节随之塌。放宽手段按性价比排：
① refine-stop 推后（3500→4200）② grow_grad2d 调小（2e-4→1.2e-4）③ prune_opa 调小（5e-3→3e-3）。
反向坑：致密化阶段 PSNR 会先掉（实测 20→11，高斯涨到 13 万），必须看 refine-stop 之后的数再判优���。
跨数据集/跨留出集的 PSNR 不可直接比（留出里混了斜视就天然更低），必须同集同视角对照。

## 4. 用几何真值给 VLM 的框定性
VLM 给像素框后，用 TCP 真值 × 手眼外参 × K 把已知 base 点投影到同一张图，量两者偏差。
px→mm 换算：z / fx（300mm 距离、fx 591 ⇒ 1px ≈ 0.5mm）。
结论口径：偏差 ≤10px 的框只够“粗定位/去那看”，框本身 ±18~25mm，不能做毫米级导向；要导向必须配深度+重标内参。

## 5. VLM 提示与输入的两个坑
- 提示里写“画面里应该有两个X”会诱发假阴性（实测直接回“未见明确X”），只描述目标特征、不预告数量。
- 小图先放大 2× 再喂，检出率明显不同（640×480 无检出 → 1280×960 检出两个）。

## 6. 相机只绑 127.0.0.1 时，页面取图要走代理
隧道出来的相机端口外网不可达。在已有 web 服务里加一条代理路由（同源），页面才能用；同时把跨端口取图改成 服务端代取。
