# 3DGS 渲染"轮廓糊"的量化诊断 (不是看 PSNR)

适用: 真机采集 → 3DGS 训练 → 渲染里薄片/低对比物体(绿色工装、金属笼、导线)边界发虚,
而 PSNR 看起来"还行"。

## 判据一: 边界梯度 (唯一能证明"糊了"的数)

在目标区域取 Sobel 幅值, 对比 GT 与渲染同位置:
```
GT 边界梯度 ≈ 5.3~5.7   →   渲染 0.8~1.4     ⇒ 锐度掉 ~6 倍, 这就是"糊"
```
配合颜色一起看(比梯度更直观): GT `(27,58,41)` → 渲染 `(35~65,58~70,41~65)` = 灰绿雾。
先报这两个数再谈原因, 否则"看起来有点糊"无法反驳也无法验收。

## 判据二: 高斯数在 refine-stop 处掉了多少

从日志取 `refine-stop` 前最高点数与结束点数:
```
117678 @2600 步  →  34515 @refine-stop 3500   ⇒ 剪掉 70%,
剩余高斯尺度偏大 ⇒ 边界被大高斯铺平 (这是 silhouette 糊的常见机制)
```

## 处置: 放宽致密化 + 用同一把尺子验收

```
--grow-grad2d 0.0002 → 0.00012    --prune-opa 0.005 → 0.003
--refine-stop 3500 → 4200         --steps 5000
```
- 结果必须**同时**报: 高斯数、留出 PSNR、**边界梯度**。只报 PSNR 等于没验
  (实测放宽后高斯 34515→119905, 留出 19.52→19.38 dB, 即 PSNR 几乎不降而点数翻 3 倍;
  边界梯度是否跟着恢复必须单独量, 未量之前不许下"已修好"结论)。

## 三个会骗人的指标

| 现象 | 真相 |
|---|---|
| `psnr_holdout_db` 跨数据集比大小 | 留出集不同就不可比(带斜视的留出更难, 19.52 与 20.98 不是退步) |
| 训练中途 PSNR 暴跌(如 20.98 → 11.27) | 致密化过冲(10.8万→13.2万高斯), 不是 bug; 只看 refine-stop 后的数 |
| 训练视角 PSNR 高 | 过拟合到那几个视角; 必须报留出 |

## 采集侧的内参口径 (错了全盘皆糊)

标定常是 4:3(640×480), 实拍是 16:9(1280×720): 比值**不是 ×2** ——
垂直等比 ×1.5、水平再 ju 裁切偏移(居中裁 960×720 时偏 160px)。
实测错用 ×2 会让所有投影/相机几何偏 ~100px, 表象与"位姿错"一样。

## 无深度时的现实约束

3DGS 只优化像素差 ⇒ 低对比边界(绿工件 vs 深灰背景)没有几何钉住, 高斯会向两侧摊。
反光/薄结构/低纹理是它的先天短板(见 SKILL.md 三大缺陷)。没有深度监督时**唯一有效手段是多视点**:
俯仰三档 (−12°/0°/+6°, 实测相机姿态差 18°) + 横向 ±120mm; 关节限位会让正向俯仰止于 +6°,
别把不可达当作"再加一点就行"(IK 误差 110mm/13.8° 就是不可达)。
