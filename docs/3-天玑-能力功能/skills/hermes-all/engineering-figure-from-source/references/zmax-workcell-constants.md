# Z-MAX 工位 · 实测常量与坐标系

## 坐标系 (唯一口径)

```
z=0      = 两臂安装面 = 桌面顶     ← 基准平面
z=-0.750 = 地面 (箱体轮底 / 桌腿落地)
```

料盘/槽位与工位常量是**同一坐标系**: 槽中心 z=0.1175 在两处都出现。
⚠️ `ar_mujoco/ar_station.xml` 把 floor 摆在 z=0、台面顶 z≈0.012, 看着像"地面=0", 混用它会把机器人放到地板上。以 web 常量为准。

## 世界坐标系标注规格 (tcp-ar.html 三维帧段, 逐字)

```js
LEN  = {base:0.16, tool0:0.13, tool1:0.13}          // base 系轴长 160 mm
C    = {x:'#ff5d5d', y:'#5dff8f', z:'#5db8ff'}      // 红X / 绿Y / 蓝Z
NAME = {base:'base(世界系)', tool0:'tool0(法兰)', tool1:'tool1(模块头)'}   // 原点白点
```

- 原点 = 右臂底座 `(0,0,0)`; **画在最上层, 不参与遮挡** (AR 页就是这么画的)。
- 轴长 160 mm 会被底座外壳 (半径 ≈194 mm) 完全包住 ⇒ 必须用 `meta` 投影叠在渲染图上层; 图纸上可放大到 240 mm 便于识读, 并在页脚写明"base 系轴长 160 mm, 图上放大"。


相机基正负号速查 (render() 保留更大 camz ⇒ 相机 z 轴指向观察者, 且 image 行号向下=+camy):

```python
z = (eye - tgt); z /= norm(z)          # 指向观察者
y_deg = (0, 0, 1)                       # 俯视时改用 (0, 1, 0)
x = cross(y_deg, z); x /= norm(x)      # 图像向右
y = cross(x, z)                         # 图像向下(世界里) ⇒ 世界向上映到图像上方
```

出图后必跑: `soffice --headless --convert-to pdf` → `pdftoppm -png -r 110 -singlefile` 做预览自检。
朝向自检只用合成探针 (彩色地面 + 立在地面上的方块, 断言方块行均值 < 地面), **不要再用颜色匹配猜上下** —— 暗色件串色会得出相反结论。
