## 定名纪律（这一表最贵的部分）

- 🔴 **老倪纠正过的名字 = 只读**。写进 `PHASES` 后任何自动推断/重构都不许覆盖（`_phase_of()` 先查表、查不到才退回几何推断）；
  也不许因为「我觉得更合理」合并或改名。他说「我刚给你纠正的点不许改，找回来」时，正确动作是**把整张表按帧区间逐行打印回来**
  当证据 + 说明靠什么机制保证不被覆盖，而不是继续改表或解释为什么改。
- 他纠正一个词就**改/合并那一行**，不要在旁边叠一行新的（叠了会同时出现两行同名）。
- **一个词也会被撤回**：他曾让加「拔出」这一行、随后又说「把拔出状态删掉」——正确做法是把它并回 `#36–#39 离开` + `#40 拔出点`，
  不是留一个零宽度的空状态；改完把新序列念一遍给他核。
- 报“某行不见了”之前先看**看板窗口**：清单一次只画一屏（14 行），当前行上方留的上下文行数不够时，
  前面的地标行会被挤出可视区，用户看到的是「抓取点没了」。他说的“找回来”多数是**显示窗口**问题，不是数据被删。
- 自己推的阶段（对位/力控搜索/插入这类）先标「推断·待核帧号」并把帧区间报给他，等他改。
- **不能靠「速度≈0」判定工艺点**：#77 抓取点在关节轨迹里是连续运动的，抓取由夹爪完成。几何只能证「哪里换向」，
  「这里是抓取/检测/废料」必须来自他的工艺口述；名字定错时他不会说"帧号错了"，只会说「你刚才到最下面那个点怎么没停」。

## 用这张表继续跑真机

- 一段一段跑：`ZMAX_RT_I0=<首帧> ZMAX_RT_I1=<末帧+1>`（`js[i0:i1]` 左闭右开，想停在 #9 要给 10），
  `ZMAX_RT_RATE=0.15~0.25`、`ZMAX_RT_VMAX=80~100`，看板相位会连续涨。
- **过渡点不停**（#55/#74），地标点才停（#9/#19/#35/#40/#58/#77/#109）。
- 每段落点核对：多数段 |偏差| <1mm；**个别帧的 `p` 与同帧关节正解不一致**（实测 #74 差 **4.1mm**），
  这是录制数据本身的问题，按关节回放补不回来；要贴点得走笛卡尔伺服，不要反复重跑。
- 报进度时报「哪一段 + 相位百分比 + 落点偏差」，别只报 `err_deg=0.0`（那个只证明跟住了自己发的指令）。
