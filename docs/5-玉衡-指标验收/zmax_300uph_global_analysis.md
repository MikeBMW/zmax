# Z-MAX 300UPH 全局分析报告（2026-10-30）

## 一句话

AR 场景状态空间工程达到 300UPH（实测 307 本地 / 344 状态空间驱动），
但两类"有效性"必须分开：**链路有效性成立，模型因果有效性未成立**。

## 1. 产能

| 模式 | 判据 | 实测 | 窗口 |
|---|---|---|---|
| 本地时钟 | `PLANT.local=true` | **307 UPH** · 11.74 s/件 | 58.7s / 5 件 |
| 状态空间驱动 | `PLANT.local=false` | **344 UPH** · 10.21 s/件 | 51.06s / 5 件 |
| 保守（段表节拍） | `tact_steady_s=11.42` | 315 UPH | — |

驱动同步误差 **−0.075s**（ARCMD.elapsed vs 页面 simT），10 ok / 0 ng。
全程 AR 仿真，**真机零下发**。

口径纪律：20s 短窗口误差可达 ±100%，只用 ≥50s/5 件或累计口径。

## 2. 链路有效性（已证）

修通四处断链：

1. `_SS_STATE["u"]` 全仓库无人写 → L3 输出落盘但不进运行时 → 执行侧恒 0
2. `PURE=False` + 实现 `return True/bool` 双闸 → 节点显示"实现执行"但实际直通
3. `_surface_bypass` 对离线 10083 每次吃满 1s 超时 → AOI 1016ms → **11.3ms**
4. 按钮重复绑定 → 开了立刻关

现状：80 节点 / 异常 0 / 真跑 13 / `u_cmd=[-0.034,-0.0774,-0.0072,0.6]`（第4维被限幅 1.1→0.6）。

## 3. 模型因果有效性（未证）

| 模型 | 计算 | 因果 |
|---|---|---|
| L3 SmolVLA+LEW | `degraded=False` 真跑 878ms | ✅ 进 action（nominal_L3 → u） |
| L4 流形引擎 | 真跑 34.6ms，几何量正常 | ❌ A/B 对照：下游 `ssmani_c` 9 项零差异 |
| INTACT | `trained=true` 热态 32ms | ❌ `l4_cond_injected=False` |
| AOI 旁路 | 有输出 `verdict=gaps_washed` | 接口对齐，下游消费未证 |

流形引擎 A/B（同 probe 同输入，只切 `ZMAX_MANI_ENG_OFF`）：开关生效（34.6→21.9ms），
但直接下游 `ssmani_c` 逐项相同，动作头不消费 L4 条件。

**结论：不能说"流形引擎提升了 300UPH"。** 300UPH 来自段表节拍 + 执行链打通，不是流形贡献。
`nominal_L3` 两组数值差异是模型采样噪声，不作证据。

修法：重训 L3 动作头，把 192 维 `l4_cond` 训成真输入通道，再跑同一 A/B 期待非零差异。

## 4. 检测模型训练（负结果，不部署）

| 模型 | gold 分布内 | aoi_v4 分布外 | judge |
|---|---|---|---|
| 新训 gold_v2 | 12/12 · 0.977 | **0/12** | 0/12 |
| 现役 yolo_ar_peg | 12/12 · 0.887 | **7/12 · 0.679** | 0/12 |

训练集 `mAP50=0.995` 是数据泄漏假象（120 张同场景微扰，置信度全挤在 0.882~0.891）。
新模型分布外完全失效且比现役更差 → **不部署**，现役软链未动。

侧面检测：仅 3 张样张 + 权重加密（`besthousing_zh0128.pt.enc`，解密器只在工控机）→ **无法训练**。

## 6. 未闭环（如实）

1. `l4_cond_injected=False` — L4 条件到不了动作，需重训 L3 头
2. 段表 `arm=none` — 左右臂两张表并行，非同一表标注归属
3. `.23` 离线 — 工控机 10082/10083 远程模型未接
4. L5 三节点 `PURE=False`
5. 检测模型泛化 — 受数据多样性限制
6. `/dev/shm` 被 Chrome 占 16G（已扩到 32G 缓解，未根治）

## 7. 下一步（按依赖排序）

1. 重训 L3 动作头带 `l4_cond` 通道 → 重跑流形 A/B，这是证明流形有效性的唯一正路
2. 多样化采集 + 人工核 val → 重训检测模型
3. 段表加 `arm` 归属 → 证明双臂协同而非各自在动
