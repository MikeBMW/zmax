  · `zmax_data/rokae_sdk/cmd_arm.fifo` → SDK 腿(**只管 move-abs/move-rel**, 不认识 skill)
  · `zmax_data/l2_cmd.fifo` → `l2_daemon.py`(**原子技能/L2.grip_open·grip_close** 走这条)

  几秒后 `/gripper_pos = 1000.0`(全开) ⇒ **夹爪是好的, 是路由错了**。
