# 1. 项目背景与用途

本需求用于采购/定制一套机器人光模块自动上下料系统。系统通过机器人从料盘 (周转盘) 抓取光模块, 放入上料 Tray 盘或目标工位, 完成上料/下料或工位间搬运, 并与现有产线设备对接。

供应商应确保系统满足本规格书规定的功能、性能、接口、质量、安全及验收要求。本规格书由配置中心按当前 System 1 配置导出, 任何配置变更后须重新导出并对齐版本。

# 附录 F. 架构兼容性要求

供应商交付的具身模型只承担「意图/条件 → 动作序列」这一段, 上游接口与下游执行接口均不得改动; 平台内建的层级边界是硬约束, 越界的方案不予验收。

| 层 | 职责 | 与供应商模型的关系 | 接口形态 |
|---|---|---|---|
| L5 | 造数据 / 自主规划 (视觉语言理解、自动标注、自主进化) | 不涉及 — 模型不消费 L5 内部结构 | 意图/条件 (慢决策) |
| L4 | 认知 + 监督 (世界模型预判与恢复、意图解码) | 输入来源 — 模型接收解码后的意图/条件 | 意图向量 + 条件约束 |
| L3 | 调度 / 任务规划 (长程序列规划、VLM 编码、Flow-Matching 动作生成) | 供应商交付主体 — 取放循环策略与序列规划在此层 | 动作序列 (VLA-T 动作 + Z-Flow 引导) |
| L2 | 检测 / 执行 (安全层 + HAL + 运动学 + 原子技能 + 收口闸) | 输出现场 — 模型输出交 L2 执行, 不直接驱动硬件 | 物理指令 (由 L2 饱和限幅后下发) |

F.1 兼容性硬约束 (逐条)

· 输入 = 上游意图 / 条件; 站点几何真值 (K / plane_z / cell_geometry / 盘面槽位) 由 L2·基石执行域提供, 模型不得自带坐标系或标定。

· 输出 = 动作序列 / 策略指令; 底层力控与伺服回路由 L2 收口, 模型不产生底层控制量。

· 模型不产生否决权: 急停 / 限速 / 禁区等安全红线由底层独立收口, 模型只读消费。

· 全部可调量按配置中心三轴 (cfg 可配置 / cal 标定 / dia 诊断) 实现, 不得硬编码 (详见附录 A)。

· 运行状态与事件上报格式须符合接口契约: 阶段 / 成功 / 失败 / 异常码 / 断点 / CT 计时。

· 模型替换对上层透明: 换权重即换模型, 不改调用方代码 (接口契约不变)。

F.2 接口契约 (上游给意图不给轨迹; 坐标真值由底层提供)

【输入】

- Sys-2 (意图/条件): 任务号 + 物料型号 + 目标盘位/槽位策略 + 速度/力上限 (只给意图, 不给轨迹)

- Sys-0 (感知): 目标位姿 T_base_obj (m/rad) · 抓取点/放置点 · 盘面槽位几何与占用状态

- Sys-0 (真值): 相机内参 K · 放置面 plane_z · T_base_cam (标定件, 现场一次标定)

- Sys-0 (图像): 腕部相机 RGB (工作距离 0.1–0.6m, 精度窗口) + 全局定位相机

- Sys-0 (状态): 关节/末端位姿 · 夹爪开合 · 真空压力 · 力/力矩

【输出】

- Sys-0 (执行): 动作块 (位姿序列 @ 推理步频) · 夹爪/真空指令 · 力控参数 (由 L2 势函数收口)

- Sys-2 (上报): 阶段/成功/失败/异常码 · 断点信息 · 单颗 CT 计时 · 料盘空/满事件 · 型号识别结果

【节拍/时延】

- —: 单颗 CT (PVT)  → ≤3.15s

- —: 动作块下发  → ≥10Hz (待实测标定)

- —: 型号识别单帧  → ≤100ms
