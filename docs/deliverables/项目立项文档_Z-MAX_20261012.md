## 1. 立项背景与必要性

### 1.1 业务背景

光模块制造为高精度、多品种、小批量工序。现场作业包括：从满料周转盘逐颗取放光模块至上料 Tray 盘（摆盘）、电口金手指精细插装、光口光纤对接、光学质量检测（AOI）等。现状由人工完成，存在以下痛点：

- **节拍受限**：人工逐颗取放，节拍与稳定性依赖熟练度。
- **良率依赖人工**：对位精度、力控稳定性、端面洁净度难以标准化。
- **ESD / 洁净风险**：精细插装对手工防静电与洁净度要求高。

### 1.2 项目必要性

Z-MAX 具身智能机器人平台提供从感知、决策到执行的全链自闭环能力，可将人工取放/插拔作业自动化，实现节拍、良率、一致性的量级提升。首个落地场景为**泰国模块摆料场景（泰国摆盘 POC）**，作为对外 POC 验证平台能力。

- 客户区块：多模自动化组；试跑现场：旭创霞胜路工厂。
- 产品演进路径：对内 Demo（Z100L）→ 对外 POC（Z100LFd 固定上肢形态）。
- 市场源起：2026-07-14 泰国厂区现场挖掘（多模模块制造具身机器人应用）。

> 背景唯一依据：`config/platform/projects/PROJ-TH-TRAY.json`、`config/platform/zmax_project_bom.json` 的 `project` / `market` 段。

## 2. 项目目标

### 2.1 核心目标（唯一依据口径）

| 目标 | 唯一依据口径 | 唯一依据 id | 阶段 |
|---|---|---|---|
| 取放成功率 | ≥99% | `perf.success_rate` | PVT |

| 连续自主作业 | ≥12 盘周转盘（硬下限 ≥6） | `perf.endurance` | PVT |
| 单颗取放精度 | 单边 ≤1mm · 角度 ≤1°（腕部相机 0.1–0.6m 区间内） | `sys1.kpi.取放精度` | — |

### 2.2 节拍：验收口径与提优目标（二者分开）

本项目节拍存在**两个必须区分**的口径，不可混用：

- **验收口径（唯一依据，硬指标）**：单颗 CT **≤3.15s（PVT）**。该值由 `perf.cycle_s` 定义，并拆解为五段预算 `perf.cycle_split`：取件 ≤0.8 + 转运 ≤1.0 + 对位 ≤0.6 + 插入 ≤0.5 + 判态 ≤0.25 = ≤3.15s。CT 起止口径预先固定：**从吸取离盘到下一位就位**；取中位数 + P95。此为验收依据。
- **迭代爬升口径（初步验收过程）**：双方确认的初步验收标准为「节拍接受迭代爬升（8s/颗 → 3.15s/颗 提优）」——即过程容许分阶段收敛（EVT ≤20–25s、DVT ≤8s、PVT ≤3.15s）。
- **提优目标（非验收口径）**：在 3.15s 验收口径达成的基础上，向 **<3s** 进一步提优。该目标为工程追求值，**不作为合同验收判据**；是否纳入下一版规格须经评审。

> 口径唯一依据：`config/platform/zmax_perf_spec.json`（`perf.cycle_s`/`perf.cycle_split`）；过程口径唯一依据 `config/platform/zmax_project_bom.json` 的 `market.acceptance` 段。

### 3.2 流形引擎主参数 M（度量张量）

流形引擎的主参数为**随状态变化的度量张量** `g_ij(x)`，口径为：

```
g_ij(x) = M · G_ij(x),   det G = 1,   M > 0
```

- **M（标量，现场标定，范围 [0, 8]）** = 度量的整体尺度（等效惯量尺度）。各向同性时 `Γ = 0` 且 `g^{kl} = δ^{kl}/M` ⇒ `a = F/M`，与旧标量语义逐字一致（零回归）。
- **G_ij(x)（det = 1）** = 度量的形状（各向异性方向 + 随状态变化）。联络 `Γ` 对尺度不变 ⇒ **弯曲只由形状决定，尺度不产生曲率**——这是「尺度 M 与形状 G 可分开标定」的数学依据。
- **独立分量数**：`n(n+1)/2`（3→6 · 6→21 · 16→136 · 43→946）。
- **导出量**：联络 `Γ`、曲率 `R`、梯度 `∇Φ`、测地线 `ẍ = −Γ ẋẋ`（有力则 `+ g⁻¹F`）全部由 `g` 导出。
- **健康度**：`H = (1/κ)·λmin`（κ 条件数，λ 特征值），分级 `H>0.5` 优秀 / `0.1~0.5` 良好 / `0.01~0.1` 警告 / `≤0.01` 危险。
- **三种形状参数化**：`isotropic`（G=I，旧行为，零回归）/ `diag`（每轴 n 个参数）/ `full`（一般度量 n(n+1)/2 个独立分量）。

**实现与验证**

- 唯一依据实现：`src/lerobot/manifold/metric_field.py`。
- 配置唯一依据：`config/calib/zmax_manifold.json`（`M` 与 `metric` 段；当前 `dim=3 · mode=diag`）。
- 判据：`tools/verify_metric_main_param.py` —— **实测 23 通过 / 0 失败（PASS）**。

> 复核命令：
