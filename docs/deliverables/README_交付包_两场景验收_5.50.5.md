## 二、核心结论（一句话版）

- **能达标**：两场景由**同一个状态空间工程、只改配置**分别真跑通过——插拔 835 步/终态「完成」，插入到位残差 **0.61 mm ≤ 2 mm**；摆盘 3/3 颗合格、2708 步，取放精度 **Δxy ≤ 0.13 mm / 姿态 ≤ 0.04°**（判据 ≤1mm/≤1°）。
- **未达标（硬指标）**：摆盘节拍实测 **10.64 / 11.55 / 11.62 s**，是 3.5 s 硬上限的 **3.32×**；真空建立 **425 / 538 / 525 ms** 超配方上限 200 ms。
- **证据量不足**：成功率现有 4 次观测 0 失效 ⇒ 95% 置信下限仅 **52.7%**；要判「≥99%」需 **≥299 次连续 0 失效**（验收设计 12 盘 × 25 颗 = 300）。
- **达标路径（改完必须重跑同口径验收）**：① 真空保持 `pick.hold_s` 5.0 s → 0.6~1.0 s；② 接近段末尾**预抽真空**（把真空建立藏进接近时间，不靠放宽判据）；③ 速度档位放开（现 `est=11.0` 硬编码把 `speed_scale` 卡在 1.5×，而需 3.38×），保留加速度限幅；④ 12 盘 × 25 颗连续验收。
