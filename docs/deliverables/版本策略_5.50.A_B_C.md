# Z-MAX 版本策略（5.50.A / 5.50.B / 5.50.C）

文档编号: ZMAX-VSEM-20261013 · 版本: v1.0
编制: Z-MAX 工程组 · 日期: 2026-10-13 · 适用版本: 5.50.x 号段
真源: `VERSION.md`（版本管理规范 · 语义化版本 `主.次.补丁`）

> 本文件定义 Z-MAX 5.50 号段的**版本语义、准入标准与产物差异**，用于统一对外交付口径。
> 版本号段语义由项目负责人（老倪）给定，工程侧据此执行。

---

## 1. 版本语义（一句话定义）

| 版本号段 | 语义 | 一句话 | 目标 |
|:---|:---|:---|:---|
| **5.50.A** | **原型产品发布版** | 做各种**原型创新** | 让新能力「能跑、能看见、能观察」 |
| **5.50.B** | **优化配置版** | 做各种**优化、标定、诊断、配置** | 让能力「可配置、可标定、可复核」 |
| **5.50.C** | **量产交付版** | **量产交付** | 让系统「可复制、可移交、可验收」 |

> 号段内部再按语义化补丁号演进（如 `5.50.1` → `5.50.2` 为开发版迭代）；交付版以号段字母标注（`5.50.A` / `5.50.B` / `5.50.C`）。
> 当前状态：`5.50.1` 已入库（含「交付清单生成器 + 全系统总配置清单(扫描)」）；本批次升 `5.50.2` 开发版，并发布 **5.50.B** 交付版。

---

## 2. 版本号段 · 准入标准

### 2.1 5.50.A · 原型产品发布版（原型创新）

**准入标准（进入该号段须满足）**

| # | 准入项 | 判据 |
|:--|:---|:---|
| A1 | 新原型能力「可运行」 | 每个新能力有可运行核（CLI/节点都行），当场能跑出结果 |
| A2 | 新原型能力「可观察」 | 结果可落盘/可回显（日志/JSON/界面），不是口头描述 |
| A3 | 新原型能力「可 debug」 | 有自检（selftest）或 launch 配置 |
| A4 | 零回归 | 已有判据不回退 |

**产物差异（该号段重点交付）**

- 原型能力的新实现（新模块/新节点/新工具）。
- 架构设计文档（v0.1 级别即可）。
- 自检结果（如 `--selftest`）。

> 5.50.A 实例：流形引擎·自动光学检测（架构设计 v0.1 + 可运行核 `src/lerobot/manifold/aoi_manifold.py`，`--selftest` 5/5）；交付文档（功能说明 / 配置清单 / SOR / 立项 / 任务配置单 / 原型验证测试报告）。

### 2.2 5.50.B · 优化配置版（优化 · 标定 · 诊断 · 配置）

**准入标准**

| # | 准入项 | 判据 | 证据（本版） |
|:--|:---|:---|:---|
| B1 | 能力「可配置」 | 改配置即改功能；配置项有真源键路径 | `config/ss_task_binding.json` · `config/calib/*.json` |
| B2 | 能力「可标定」 | 有标定入口 + 标定判据（含噪声底） | `tools/config_to_M.py`（51/51 PASS）；`zmax_health.json` |
| B3 | 能力「可诊断」 | 每帧输出可判读量（健康度/分级/否决） | `tools/verify_engine_loop.py`（20/20 PASS） |
| B4 | 能力「可复核」 | 关键数字可由判据脚本或扫描回读 | `tools/verify_*.py`（23/20/51/15/14）；`tools/delivery/gen_config_inventory.py` |
| B5 | 配置清单「可交付」 | 全系统总配置清单从在役系统扫出，每个数可回读 | `docs/deliverables/全系统配置清单_5.50.B.md` |
| B6 | 零回归 | 画布结构未破（89 节点 / 184 连线） | `tools/verify_node_cfg_import.py` ⑨ |

**产物差异**

- 配置真源与判据脚本（主参数 M / 健康度 H / 配置单→M 映射 / 配置导入节点 / 数据总线每节点 topic）。
- 全系统总配置清单（扫描件 md+json）。
- 版本策略、功能说明、SOR、立项、索引等交付文档（**5.50.B 交付文档包**）。
- 明确列出「待现场实测 / 待核」项（不掩盖缺口）。

> 5.50.B 实例（本批次）：主参数 M 度量张量（23/23）· 健康度 H 与流形引擎闭环（20/20）· 配置单→M 映射（51/51）· 配置导入节点（15/15）· 数据总线每节点独立 topic（14/14）· 画布工具栏「配置中心独立窗口」· 「元数据MOE门控路由」节点改名。

### 2.3 5.50.C · 量产交付版

**准入标准**

| # | 准入项 | 判据 |
|:--|:---|:---|
| C1 | 主验收指标达标 | 成功率 ≥99%（`perf.success_rate`）· 节拍 ≤3.15s（`perf.cycle_s`）· 连续 ≥12 盘（`perf.endurance`）**现场实测** |
| C2 | 全量指标覆盖 | 真源 `zmax_perf_spec.json` 全部 58 条 `perf.*` 分 EVT/DVT/PVT 有结论 |
| C3 | 现场标定完成 | `T_base_cam` / `plane_z` / `cell_geometry.points` 标定完成（真源非 null） |
| C4 | 可移交 | 安装/迁移/验收流程文档化，配置清单可回读，防呆与安全门固化 |
| C5 | 环境项达标 | F 组 ESD/洁净度/温湿度/安全等级（按现场条件定档） |

**产物差异**

- 量产交付包（可迁移实例 + 安装/初始化流程 + 校验冒烟）。
- 现场标定与验收报告（实测值填充真源 `value` 字段）。
- 量产版配置清单与合格证明。

> ⚠️ **5.50.C 尚未发布**：其准入项 C1–C5 当前均**待现场实测/待标定**。不得在真源 `value` 为空的情况下宣称 5.50.C 达标。

## 3. 版本号段的产物差异（一览）

| 维度 | 5.50.A 原型产品发布版 | 5.50.B 优化配置版 | 5.50.C 量产交付版 |
|:---|:---|:---|:---|
| 关注点 | 原型创新 | 优化/标定/诊断/配置 | 量产交付 |
| 配置真源 | 存在即可 | **有键路径 + 判据** | 现场标定值填实 |
| 判据脚本 | selftest | **成体系（可复跑）** | 验收判据全通过 |
| 配置清单 | 无 | **扫描生成（可回读）** | 量产版 + 合格证明 |
| 指标实测 | 不要求 | **如实标注待实测** | **全部达标** |
| 文档级别 | 架构设计 v0.1 | **交付文档包** | 交付 + 验收报告 |
| 发布形态 | 开发版 | **交付版（对外）** | 交付版（量产） |

## 5. 版本号位置（改版本必同步，真源 `VERSION.md`）

1. `tools/gui/studio.py` — `ver = QLabel("Z-MAX vX.Y.Z")` + `setWindowTitle(...)`（两处）+ changelog 注释前缀
2. `tools/gui/update_checker.py` — `CURRENT_VERSION = "vX.Y.Z"`
3. `tools/gui/version_sync.py` — `zmax_ver = "X.Y.Z"`
4. `tools/gui/docs_sync.py` — `"version"` + `"zmax_version"` 两键
5. `git tag vX.Y.Z` — 打 tag 并 push

## 6. 术语

| 术语 | 说明 |
|:---|:---|
| 开发版 | 号段内的补丁迭代版本（如 5.50.2），用于开发过程 |
| 交付版 | 以号段字母标注的对外交付版本（5.50.A/B/C） |
| 准入标准 | 进入某号段/发布某交付版必须满足的门槛 |
| 判据 | 可复跑的验证脚本，输出 PASS/失败数与明细 |
