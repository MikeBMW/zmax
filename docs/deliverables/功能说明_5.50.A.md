# Z-MAX 功能说明（交付版 5.50.A）

编制日期: 2026-10-13 · 对应开发版本: 5.50.1 · 产品: Z-MAX 具身智能机器人精细操作平台
适用场景: 光模块工厂精细操作（插拔 / 摆盘 / 光学质量检测）

---

## 一、产品定位

Z-MAX 是面向光模块工厂精细操作工序的**具身智能机器人平台**。它以「状态空间」为核心数据结构、
以「配置驱动」为功能切换方式，用一台工控计算机 + 一台珞石机械臂 + 多路工业相机，
覆盖从**上料、插拔、摆盘、光学检测到数据闭环**的完整工序链。

三个设计原则：

| 原则 | 含义 | 在系统中的体现 |
|---|---|---|
| **配置驱动** | 改功能不改代码 | 任务/场景/档位全部由 `config/ss_task_binding.json` 与 `flows/state_space_obs.json` 决定 |
| **逐层收窄可行域** | 上层只给意图与条件，执行永远由最下层收口 | L5 规划 → L4 认知 → L3 调度 → L2 检测/执行，每层只输出本层能担保的结论 |
| **安全由下层兜底** | 稳定性由势函数/守卫保证，不依赖上层正确 | L2 势场 + 逐轴相关性闸 + 运动包络/天花板/抬升闸 |

---

## 二、系统分层与能力

### L5 · 任务规划层（造数据 / 下指令）
- 依据自然语言任务描述生成工序级指令序列；视觉问答由 **DeepSeek 视觉**承担（短提示 + 小 JSON，超时 ≥300s）。
- 输出为**意图与约束**（目标工序、允许动作集合、节拍上限），不下发具体轨迹。
- 交付口径：L5 只保证"指令语义正确"，不担保动作可行。

### L4 · 认知层（INTACT 直驱 / 场景理解）
- INTACT（LeWM）常驻，负责场景与状态的理解与预测；配 **反归一化按 ckpt 训练集同源**，避免尺度错配。
- 输出为物理量（目标位姿/相对偏差/可行性评分），交 L3 调度。
- 交付口径：L4 结论必须能在同一口径下被 L2 复现，否则不作为默认档。

### L3 · 调度层（阶段链 / 档位）
- 按工序阶段链调度：插拔 9 阶段、摆盘 5 阶段；每阶段绑定档位参数（速度/力限/延时）。
- 阶段切换由硬件回执驱动，不靠计时猜测。

### L2 · 检测与执行收口层（模型 + 势场 + 目标）
- **在役模型**：L2 插拔 MLP（409/409 同口径通过）、摆盘链（域外样本 0/852，已如实标注为域外）；
  域守卫（`D_GUARD` / `DOMAIN_SIGMA`）拒绝域外样本进入默认档。
- **势场**：喂入观测 `obs[0:3]`，稳定性由势函数兜底。
- **收口闸**：逐轴相关性 `corr < 0.5` 触发 veto；动作授权只从 8793 页面产生，代发前必须先授权。

### 执行层（机械臂 / 夹爪 / 相机）
- 珞石机械臂：关节运动、末端自转、夹爪开合；默认速度档 speed=8。
- 位置真源 = `tcp_out/latest.json`（50Hz 真值遥测）；**全 0 视为陈旧**，不参与决策。
- 运动安全：包络/天花板/z_floor 硬红线；高抬升须先警示再慢速；"要碰撞"类指令先执行 `agent_all_stop.py`。

### 3.2 状态空间工程
- 画布真源（权威，取自任务绑定工程）`src/lerobot/engineering/flows/state_space_obs.json`：
  **89 节点 / 184 连线**，md5 `0bf580c4d90a3963714e4328ad835345`。
  （仓库根另有 `flows/state_space_obs.json` 一份 251 节点/242 连线的副本，非任务绑定所用；交付以绑定工程为准。）
- 工程库 `data/database/zmax/zmax_engineering.db`（单文件 = 一套工程，支持 `build` / `check`）。
- 节点可插拔：`ss_aoi`（光学质量检测）、`ss_geom_calib`（几何标定）、`ss_task_bind`（任务绑定）等。
- 改画布的四步纪律：`ss_task_bind` → `space-save` → `db build` → 两 check。

### 3.3 流形引擎
- **能量层**：`omega_hz_measured` 只换转速/输出功率，能量保持 τ·循环数（口径铁律）。
- **内稳态层**：环境漂移下的参数自适应。
- **主参数 M**：度量张量 `g_ij(x) = M·G_ij(x)`（`det G = 1`），把"参数之间怎么互相影响"变成可标定的矩阵。
- **AOI 流形**（本版新增）：相机参数流形 / 扫描路径流形 / 缺陷特征流形 + 清晰度·缺陷·覆盖三势场；
  可运行核 `src/lerobot/manifold/aoi_manifold.py`（`--selftest` 5/5；`--calibrate` 只读标定在役相机）。
  **标定须过噪声底**：判据 `跨度 > max(3σ, 1% 基准Φ)`。

### 3.5 AR 增强现实
- 服务：`zmax-traj-ar`（8797）。底图源 4 路 = 状态空间工程视频源（8791：arm / gold / surface）+ 本机 USB 相机。

### 3.6 数据空间（DDS 中间件）
- 话题注册表 `src/lerobot/dataspace/topics.py`；在役 4 个 systemd 服务（agg / pub / ss / loop + probe）。
- 取证工具 `tools/dds_verify_real.py`（`selftest` 证总线 / `pair`+`pair-sub` 证跨进程 / `listen` 查此刻真数据）。
- 实测口径：总线真、跨进程真（15 发 → 16 收）；话题内容为空时如实标注三处原因（源头字段空 / tap 过期 / 跨网写失败），不掩盖。

### 3.7 侧面检测与判据图（本版重点交付）
- **相机**：工控机 OPT **10083**（侧面）；10082 = 金手指顶视。
- **曝光控制**：`GET /exposure` 只读，**写必须 `POST /exposure?us=<微秒>&gain=<dB>`**；档位落盘（重启保持）。
  本版将在役档由 80000us/gain1.8 降至 **20000us/gain1.0**，饱和像素（≥250）43.09% → **4.39%**。
- **矩形刚体动态搜索**（位置会变 ⇒ 搜索任务，不用固定四角）：
  候选 = 画面内每块亮区（不含固定坐标）→ 评分 = 面积占比 × 矩形度 × 对边平行度 → 择优。
  实测：多档曝光下稳定命中同一刚体（倾角 −61.9°，矩形度/平行度 1.00）。
- **判据图摆正**：纯旋转（缩放 1.0）+ 按真实像素尺寸裁剪 ⇒ **零拉伸**；与原图同帧同像素，亮度一致
  （同像素比对：均值差 −0.08 / 中位差 0.0）。
- **交付形式**：① 原图 + 搜索框叠加（标注截取区域）② 按框摆正的判据图（独立文件）。

### 3.8 交付与运维
- **控制台**（PyQt5）：配置中心 / 状态空间画布 / 3D 场景 / 信号分析 / 文档中心；版本位同步 5 处。
- **工位总览与产品大屏**：同一服务（8793）同一份在役状态；产品大屏 JSON 单一数据源（8799 `/dashboard.json`）。
- **手机远程页 + APP**：`ZMAX-Dash.apk`（WebView 壳，手机优先视口）；远程动作受现场授权闸约束。
- **公网只读闸门**：站点 `datadrive.world`，控制页/工位总览/叠加页默认只读；`/gen`、`/api/aoi/*`、`/cmd`、
  `/skill`、`/teach` 等永不放行。
- **技能库**：工序技能原子化沉淀（肌肉记忆层），可复用、可版本化。
- **定时任务**：12 条 cron（磁盘红线守护、L2 守护、安全看门狗等）。

## 四、配置驱动：改配置即改功能

| 要改什么 | 改哪里 | 生效方式 |
|---|---|---|
| 换工序任务 | `config/ss_task_binding.json` → `active_task` | 重启任务执行体即切换（`tools/ss_task_runner.py`） |
| 换 3D 场景 | `tools/ss_scene_switch.py switch <SCN>`（写画布 `ssdata.src_state`） | 控制台/画布/信号窗/3D 窗同时跟随 |
| 调整曝光/增益 | AOI 页面（10082 `/param`、10083 `POST /exposure`） | 落盘保持，重启不丢 |
| 增删画布节点 | 画布编辑器 → `ss_task_bind` → `space-save` → `db build` → 两 check | 不重启，热生效 |
| 换在役检测权重 | 软链 `models/yolo_peg_live.pt` | 检测进程重载即生效 |

## 五、验收口径（不夸大）

1. **每次改动必须同口径对照**：有提升才算成果，未证明提升的不得进默认档。
2. **判据先定后跑**：判据写在前，跑完按判据报数；样本量 <20 不下结论。
3. **量具必须用判据自己的取像口**：`GET /picture?kind=origin&grab=1`（`kind=judge` 是派生缓存图，
   拿它做 A/B 会得出"改了没变化"的假结论）。
4. **如实标注未达标项**：如摆盘链在域外样本 0/852（如实标"域外"）、D405 深度通道待唤醒（0 fps）。
5. **交付件中的数字必须可回读复核**：配置清单由 `tools/delivery/gen_config_inventory.py` 从在役系统扫出。
