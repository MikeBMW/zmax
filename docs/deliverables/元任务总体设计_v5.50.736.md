## ① 元任务定义

元任务 = **一条可执行、可验收、有物理量约束的配置实例**，不是一段描述。定义四要素（缺一即不算元任务）:

| 要素 | 含义 | 唯一依据 |
|---|---|---|
| 配置 | 该功能启用/关闭的参数与开关 (instance) | `config_meta.json::fields.parameters/declared_flags` |
| 执行入口 | 真代码文件/节点 (不是伪代码) | `code_file` / 画布节点 id |
| 验收指标 | 归属迭代阶段的性能指标 + 目标值 | `config/eval/iteration_roadmap.json` |
| 证据 | 判据脚本 + 报告 (可复核) | `tools/verify_*.py` + `docs/eval/*.md` |

## ③ 组成

按层追一层: **L2 执行层** (原子技能 SK01-08 + 物理闸 + 感知/传动) → **L3 规划层** (流形引擎/接触流形/性能流形/DiT 动作头/安全边界, 配置模型) → **L4 自主层** (世界模型/INTACT/LoRA/标定与融合定位) → **L5 意图层** (VLM/LLM 只给意图与条件)。

- L2 元任务: **28** 条 (config_meta `layer=L2`)；其中原子技能 **8** 条
- L3 元任务: **4** 条 (配置模型 → L3 元任务；核验见下)
- L4 元任务 → 配置工单: **30** 条
