# Z-MAX 具身智能机器人平台 · 供应商需求规格书 (SOR)

**项目**：光模块工厂精细操作（泰国摆盘 POC）
**文档类型**：Statement of Requirements（需求规格 / 技术要求书）
**版本**：v1.0
**日期**：2026-10-12
**密级**：对外发放（供应商 / 整机厂）

> 本文件面向供应商与整机厂，用于对齐 Z-MAX 平台在光模块精细操作场景下的功能、性能、接口与验收要求。所引指标均来自工程唯一依据 `config/platform/zmax_perf_spec.json`，标注 `perf.*` 指标 id 与本机构目标值；凡唯一依据 `value` 字段为空者一律标注「待实测」，并给出实测入口，不提供任何未经验证的实测数值。

## 1. 项目背景

光模块制造为高精度、多品种、小批量工序，人工完成周转盘到上料 Tray 盘的逐颗取放、电口金手指插装、光口光纤对接、光学质量检测等作业，存在节拍受限、良率依赖熟练度、ESD/洁净风险高等问题。

Z-MAX 具身智能机器人平台面向光模块工厂精细操作，提供从感知、决策到执行的全链自闭环能力。首个落地项目为**泰国模块摆料场景（泰国摆盘 POC）**，作业内容为将光模块从满料周转盘逐颗取放至 30 槽上料 Tray 盘，并覆盖插拔、光学检测、增强现实（AR）标定叠加与数据闭环等扩展场景。

### 1.1 型号口径

| 型号 | 定位 | 自动化等级 | 主要作业 |
|---|---|---|---|
| Z700 | 精细操作机器人（轮式双臂旗舰） | L4 高度自动化（全自主） | 多工位插拔 + 换型 + 7×24 无人值守 |
| Z700F | 固定式精密插拔 | Fix L2（分段式自动化基线） | 单工位重复插拔 |

> 型号与硬件分档唯一依据：`docs/design/Z-MAX-硬件平台-L2-L3-L4方案.md`（三档总览表）。

### 1.2 对外表述口径

本项目的技术交付内容为「**符合 5 个场景的具身方案技术协议**」，即围绕插拔、摆盘、光学质量检测（AOI）、AR 标定叠加、数据闭环五个场景，约定功能、性能、接口与验收要求。

### 2.2 供货边界（交什么 / 不交什么）

**交付范围**

- L3 动作执行：将上游意图/条件转成可执行动作序列（VLA-T 动作 + Z-Flow 引导）。
- 摆盘取放循环的策略与序列规划（取件 → 转运对位 → 放入 → 判态循环）。
- 多型号 / 多摆放自适应配方选择（12+ 型号、≥6 种摆放）。
- 异常处置与断点续作决策（重试 / 换策略 / 退回安全位）。
- 运行状态与事件上报（阶段 / 成功 / 失败 / 异常码 / 断点 / CT 计时）。

**不在范围**

- 不供相机 / 机械臂 / 夹爪 / 真空等硬件本体。
- 不供站点几何真值（`K` / `plane_z` / `cell_geometry` / 盘面槽位）——现场标定，由基石执行域提供。
- 不供安全红线（急停 / 限速 / 禁区）——动作系统只读消费，不产生否决权。
- 不供 L2 底层力控 / 伺服回路（基石执行层收口）。

> 供货边界唯一依据：`tools/sys1_delivery.py` `SCOPE_IN` / `SCOPE_OUT` 段。

## 3. 分层架构

平台采用四层解耦架构，各层职责与形态如下：

| 层 | 名称 | 职责 | 对应子系统 |
|---|---|---|---|
| L5 | 造数据 / 自主规划 | 视觉语言理解（含 DeepSeek 视觉理解）、自动标注、数据合成、自主进化 | System 2 |
| L4 | 认知 + 监督 | 世界模型预判与恢复（INTACT 直驱）、意图解码、专家自主 | System 2 |
| L3 | 调度 / 任务规划 | 长程序列规划、VLM 视觉编码、Flow-Matching 动作生成 | System 1 |
| L2 | 检测 / 执行 | 安全层 + HAL + 运动学 + 原子技能 + 肌肉记忆 + 收口闸 | System 0 |

记忆体系为五层：L2 肌肉记忆、L3 流程记忆、L4 物理规律记忆，加顶层总装记忆。

> 分层与子系统唯一依据：`config/platform/zmax_platform.json`（`platform.architecture` 与 `subsystems` 段）。
> 功能节点唯一依据：工程库 `data/database/zmax/zmax_engineering.db` 的 `functions` 表（74 条功能节点，编号前缀 `FN-SYS0/1/2`、`FN-PLAT`）。

## 4. 功能要求（按场景）

### 4.1 插拔场景

- 完整作业执行：接近 → 对位 → 下降 → 抓取 → 抬起 → 转移 → 插入 → 完成（原子技能 SK01–SK08）。
- 精细对位：头-孔亚毫米对位，板坐标系定位（免手眼口径）。
- 力控插拔保护：插拔力上限可配，超限即退。
- 宏微复合：宏动定位 + 微调收敛。
- 验收关联能力：`BO_C1` 完整作业执行 / `BO_C2` 精细对位 / `BO_C4` 灵活翻转取放 / `BO_C6` 宏微复合作业。

### 4.2 摆盘场景

- 全局定位相机识别满料周转盘位置与堆叠层数、空 Tray 盘位置、工装位置。
- 二次拍照识别盘内光模块数量/坐标与 Tray 空槽数量/坐标。
- 真空吸附（建立 ≤200ms、保持 ≥5s）→ 安全轨迹转运 → 姿态对准 → 放入 → 判态循环。
- 空盘/满盘上报待人工补料/下料。
- 验收关联能力：`BO_B1` 目标识别定位 / `BO_B2` 空间位姿感知 / `BO_C1` / `BO_C4`。

### 4.3 AOI 光学质量检测场景

- 金手指检测：工控机 AOI 端口 10082，`POST /capture_detect` 受理 → 轮询 `GET /last_result` 取判决（verdict/count/defects/ms）。
- 表面检测：端口 10083，同口径。
- 在役 YOLO 权重在 AR 帧上检测光模块（检出即给像素坐标）。
- 判决 PASS/FAIL + 缺陷数，判据图可导出。
- 验收关联能力：`BO_B5` 光学质量检测。

> 端口与调用口径唯一依据：`tools/aoi_link.py`（`PORTS = {"gf": 10082, "housing": 10083}`）。

### 4.4 AR 标定叠加场景

- AR 底图 = 状态空间工程视频数据源，4 路相机全部在册（真实分辨率独立，标定点像素量纲不混用）：
  - 机器人手臂 RealSense（`arm`，640×480）
  - 金手指检测相机（`gold`，900×332 / 整板原图 1400×1171）
  - 表面检测相机（`surface`，1280×1280）
  - USB RealSense（`rs`，640×480，AR 服务 `:8797` 本机 D435 直连）
- L5 视觉理解：抓取当前底图一帧交 L5 引擎理解，输出场景/拓扑/目标框/模型/耗时。
- 相机系 3D 位姿：深度反投影 + 平面拟合，虚拟坐标架叠加回实拍。

> AR 场景唯一依据：`docs/AR_CAMS_L5_20261012.md`；服务与桥：`tools/tcp_ar_server.py`、`tools/ar_l5_understand.py`、`tools/ar_aoi_bus.py`。

### 4.5 数据闭环（CICD）场景

- 边缘（Orin）采集 → 中转（ECS）→ 训练（4060）→ 静态 URL 部署 → 推理，形成闭环。
- 新能力须有提升证据方可进默认档。
- 验收关联能力：`BO_E2` 边学边练 / `BO_G1` 标准模型接入 / `BO_G3` 事件自动通知。

> 复核命令：
> ```bash
> gui-venv311/bin/python -c "import json;d=json.load(open('config/platform/zmax_perf_spec.json'));print('组数',len(d['groups']),'指标数',sum(len(g['metrics']) for g in d['groups']),'标准',len(d['standards']))"
> # 输出: 组数 6 指标数 58 标准 8
> ```

## 7. 验收方法与标准

### 7.1 引用标准

| 标准 | 内容 |
|---|---|
| ISO 9283 | 工业机器人性能规范：位姿准确度 AP/可重复性 RP（±3σ，同向同参 30 次循环）、路径准确度 ATL/可重复性 RTL |
| ISO 230-2 | 机床/进给轴定位精度与重复定位精度（双向，目标位置往返 5 次） |
| ISO 9787 | 机器人坐标系与运动命名（位姿口径引用） |
| IEC 61300-3-35 | 光纤互连器件端面目检：划痕/缺陷/颗粒判据 |
| IEC 61753 / GR-326 | 光纤连接器光学性能：插入损耗 IL / 回波损耗 RL / 互换性 |
| ANSI/ESD S20.20 | 静电控制程序（表面电阻/接地/摩擦电压限值） |
| ISO 14644-1 | 洁净室洁净度分级（颗粒浓度） |
| ISO 13849-1 | 机械安全控制系统安全相关部件（PL 等级） |

> 标准清单唯一依据：`config/platform/zmax_perf_spec.json` 的 `standards` 段（8 项）。

### 7.2 验收方法（按阶段）

- **EVT（工程验证）**：关节分辨率、升降重复定位精度、手眼标定残差、深度噪声、视觉分辨率、ESD 三项。
- **DVT（设计验证）**：位姿 RP/AP、回差、整定时间、静刚度、双臂同步、末端分辨率、端面间隙、光纤弯曲半径、插装力超调、对位重复性、CT 分段预算、照度适应性、温湿度/噪声。
- **PVT（生产验证）**：CT 终值 ≤3.15s、成功率 ≥99%、连续 ≥12 盘、换型 ≤30min、料位识别 ≥99.9%、IL/RL、端面洁净、安全等级。

各指标所属阶段以唯一依据 `stage` 字段为准（见第 5 节各表「阶段」列）。

### 7.3 验收工具

- 性能指标项及其 `how`（实测方法）字段：`config/platform/zmax_perf_spec.json`。
- 质量门与断言：`src/lerobot/verification/verification_layer.py`（`FEATURES` 共 57 条断言）。
